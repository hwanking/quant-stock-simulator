# 결과 R312 — 제외 사유가 **실패만, 그것도 말없이 넷까지만** 나갔다 (2026-09-16)

'오늘 추천에 올리지 못한 종목' 칸이 중앙 판정의 조건 목록에서 **실패한 것만**, 그것도
`_fail[:4]` 로 **잘라서** 적고 있었다. 둘 다 이 저장소가 이미 고친 적 있는 결함이다.

| 결함 | 같은 모양 |
|---|---|
| 자르고 **잘랐다고 안 적는다** | R301 — 상한 사유 307자가 문장 중간에서 끊겼다 |
| **통과한 것**을 안 적는다 | 사용자가 붙여 넣은 분석문의 *"확인된 사실·유리한 근거"* |

## 1. 만들기 전에 셌다 (R288 의 규칙)

리포트 **87개** · 중앙 판정이 실린 후보 **398개**:

```
잘린 적 있는 후보   16개 (4.0%)      ← 말없이 잘렸다
최대 미충족         5개
오늘(09-16) 리포트  후보 4개 · 미충족 2·2·3·4 · **잘린 것 0개**
중앙 판정의 조건 수  11개
```

**오늘은 0개다.** 그러나 *'오늘 안 보인다'와 '없다'는 다르다* — 16번은 실제로 잘렸다
(R295 의 *"매번은 매번이 아니었다"* 와 R300 의 *"오늘 이 종목에서는 안 보인다"* 의 거울상).

## 2. 고침 — **안 자르는 것**이 가장 짧다

최대 미충족이 5개이므로 전부 적어도 줄이 길어지지 않는다. R301 이 적은 그대로 —
*"자를 거면 잘랐다고 적는다. 더 나은 것은 안 자르는 것이다."*

```
조건 11개 중 **통과 9개** · 미충족 2개
미충족: 비용 차감 기대값 양수(-0.26%) · 신뢰도·전략품질 기준(신뢰 79 · 품질 32)
```

- 분모(조건 수)와 **통과 수**를 먼저 말한다 — 분석문이 요구한 *확인된 사실*이다.
- 조건이 하나도 없으면 그 줄을 **안 만든다**(*0개 중 0개 통과* 같은 말을 안 한다 · §3).
- 이어 붙인 사유는 `_md_safe` 를 지난다(§308 · R295 가 물결표에 당한 자리).

**판정·문턱·조건 수는 안 건드렸다.** 조건 목록은 여전히 중앙 판정 한 곳이 만들고
화면은 **세기만** 한다(§4) — §323 이 그것까지 잠근다.

## 3. 안 한 것

통과한 **항목 이름**은 안 적었다. 아홉 개를 나열하면 정작 읽어야 할 미충족이 묻히고,
이 칸은 이미 `st.expander` 안이라 접을 자리를 하나 더 만들 수 없다(중첩 금지).
**수는 사실이고 목록은 소음이 될 수 있다** — 수만 적었다.
