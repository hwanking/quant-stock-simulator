# 컴포넌트 규칙 (v4 — 2026-08-01)

## '전체 보기' 공통 패턴 (유일 규격)
`요약 N건(3~5) 기본 노출 + st.expander("전체 X 보기 (n건[·필터])")`.
- 모달·드로어는 Streamlit 제약상 expander로 통일한다.
- 적용처: 주요 이슈, 업데이트, 공시, 케이스 스터디, 모델 성과 분해,
  기업 재무(전문가 보기), 사후 검증 패널.
- expander 제목에 반드시 건수를 쓴다 — 숨긴 것이 얼마나 있는지 보여준다.

## 카드 규칙
- 배경 surface / 테두리 border(중립) / radius 10~12px / 여백 20~24px.
- 컬러 테두리 허용처 3곳만: 최종 결론 배너, '높음' 이슈, st.error.
- 한 카드 한 목적, 정보 3단 이하, 동일 정보 반복 금지.

## 상태·뱃지
- 중요도: 높음 neg / 중간 warn / 낮음 tx2 — `{색}22` 배경 + `{색}` 글자.
- 카테고리: hover 배경 + brand 글자.
- 상태 라벨: 정상(tx2) / 경고(warn) / 오류(neg) — 색+텍스트 병행(색맹 대응).

## 문구 지침
- 정제된 서술형: "~합니다/~하세요". 감탄·과장 금지.
- 모든 확률·적중률에 표본 수(n) 병기. n<30이면 '표본 부족'을 수치보다 크게.
- 미산출은 '미산출/미수신/산출 불가'로 — 임의 값·0 표시 금지.
- 반복 문구 삭제: 같은 경고는 한 화면에 한 번.

## 여백 시스템
섹션 간 hr(26px 마진) / 카드 간 8~16px / 패널 내부 20~24px.
숫자는 tabular-nums 우측 정렬, 라벨은 좌측 13px tx2.
