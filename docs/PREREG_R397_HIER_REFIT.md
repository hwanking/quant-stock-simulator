# 사전등록 — 라운드 397: 계층 보정 확률 표를 오늘 원장으로 다시 적합하면 더 맞는가 (측정 전 고정)

작성: 2026-09-30. **이 문서를 커밋한 뒤에 측정한다.**

## 0. 물음과 배경

사용자: *"되돌려 본 판단 늘려야 하는 거 아냐? 확률도 높일 수 있도록."*

- '되돌려 본 판단'(원장)은 2026-08-09 약 5.5만 행 → 2026-09-30 **255,930행**(4.7배)으로 자랐다.
- 그런데 화면의 **계층 보정 확률**(라운드 59 채택 · `case_layers.blended_prob`)이 읽는 운영 표
  `data/hier_prob_tables.json` 은 **2026-08-09 판**(315칸) 그대로다 — 원장이 자란 만큼이 확률에 한 번도 안 들어갔다.
- 먼저 잰 것(측정 전 이미 본 값 · 판정과 무관): 원장이 자라는 동안 적중 **확률 자체는 오르지 않았다**
  (전체 57.4 → 59.2% · 60점+ 블라인드 59.0 → 54.5% · 행 4.7배 · 블라인드 날짜 22 → 82). 행을 더 쌓는 것은
  확률을 **올리지** 않는다 — 이 사전등록이 묻는 것은 *더 많은 행으로 적합한 표가 더 **잘 맞는가***(보정·정확도)다.

## 1. 후보 (고정)

- **옛 표**: 운영 `data/hier_prob_tables.json`(made 2026-08-09 · m=100) — 그대로 읽는다.
- **새 표**: `scripts/gen_hier_tables.py` 를 **코드 한 글자도 안 바꾸고**(출력 경로 인자만 더함) 오늘 원장으로
  돌린 것 — 개발 구간(train+valid) · 판정 완료 · 통계 행(`ledger_view.stat_rows`) · m=100 · 층 L5→L4→L4b→L3→L2.
  운영 자리를 건드리지 않고 `_probe/` 에 쓴다.
- m·층·산식은 두 표가 같다. 다른 것은 **적합에 쓴 행**뿐이다.

## 2. 평가 (고정)

- **표본**: 오늘 원장의 **블라인드** 구간 · 판정 완료 · 통계 행. 두 표 모두 블라인드를 적합에 쓰지 않았다
  (옛 표 basis *"블라인드 미접촉"* · 새 표도 같은 코드). 블라인드는 이 비교에 **한 번** 쓴다.
- 행마다 두 표의 확률을 **같은 칸 열쇠**로 낸다 — 칸 열쇠·예측은 R59 측정 스크립트의 함수
  (`scripts/hier_prob_lab.cells_of` · `predict`)를 **불러서** 쓴다(베끼지 않는다 · R192). 국면 4상태는
  `kospi_index.states`, 업종은 새 생성기와 같은 규칙(원장 행 먼저 · 없으면 패치).
- **재현 확인(판정 전 · 실패하면 측정 중단)**: 블라인드 행 200개에서 위 방식의 옛 표 확률이 운영 함수
  `case_layers.blended_prob` 의 값과 **1e-9 안에서 같다**(칸 열쇠를 같게 만드는 fs 를 심는다).
- **지표**: R59 §2 그대로 — Brier · log loss · 보정이탈(10분위 |평균확률 − 실측| 최대) · 상하위 10분위 실측 차.
  계산은 `hier_prob_lab.score` 를 부른다.

## 3. 판정 (고정 · R59 §2 의 게이트를 그대로 재사용 · 새 문턱 없음)

- R0(싼 것 먼저): 블라인드 판정 완료 행의 **고유 기준일 ≥ 30**(R84·R45 하한). 미달이면 측정하지 않는다.
- **(가) 교체 제안** — 블라인드에서 새 표가 옛 표보다 **Brier 낮고 · log loss 낮고 · 보정이탈 ≤** 셋 다.
- **(다) 현행 유지** — 하나라도 미달.
- 곁들여 적는 것(판정에 안 씀): 날짜 군집 부트스트랩(시드 397 · 2,000회) Δ Brier(새 − 옛) 95% 구간 ·
  60점+ 부분집합 · 국면(BULL·SIDEWAYS·BEAR)별 Brier · 행마다 쓰인 층 수.
- 측정 뒤 기준을 바꾸지 않는다(§2-5).

## 4. (가)가 나와도 이 라운드가 하지 않는 것

- **운영 표를 갈아 끼우는 것은 사람이 정한다** — 판정 중에 읽히는 확률의 재료라 모델 변경이고(버전 ·
  `kind='algorithm'` · R59 가 적어 둔 종류), 2026-11-16 전방 재평가 동결 구간 한가운데다(라운드 350 선례 —
  사용자 결정 + 시행일을 버전 원장에). 이 라운드는 재고 제안까지만 한다.
- m 을 다시 고르지 않는다(R59 의 m=100 그대로 — 고르면 결과를 본 선택이 섞인다).
