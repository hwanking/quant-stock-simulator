## 0. 왜 다시 재는가 — 그리고 왜 이것이 '될 때까지 돌리기'가 아닌가

라운드 131 이 수급 변수 5종을 재고 **전부 미달**로 기각했다. 그 판정은
**그대로 선다.** 이 라운드가 그것을 뒤집으려는 것이 아니다.

다시 재는 이유는 하나뿐이다 — **R131 은 볼 수 있는 것이 적었다.**
그 표본에서 최소 가시 효과가 **8~12%p** 였고, 이건 라운드 129 가 잰
전체 잣대의 하한(5%p)보다도 훨씬 무디다. 즉 R131 은 *"없다"* 가 아니라
*"8~12%p 짜리는 없다"* 만 말할 수 있었고, 결과 문서에도 그렇게 적었다.

그 사이 수집이 커졌다 (2026-08-20 실측):

| | R131 시점 | 지금 |
|---|---:|---:|
| 수급이 붙은 케이스 | 14,269 | **58,806** |
| 수급이 붙은 날짜 | 220 | **1,411** |
| 기록 구간 | 2024-07~ | **2018-06~** |

**이것은 결과를 본 뒤 기준을 낮추는 것이 아니다. 기준을 올린다** (§5).

## 1. 무엇을 바꾸지 않는가

- 점수·게이트·문턱·가중치를 **바꾸지 않는다.** 측정 전용
- **시험 변수를 늘리지 않는다** — R131 과 **정확히 같은 5개**
  (`frgn_days5` · `inst_days5` · `both_days5` · `frgn_streak` · `frgn_flip`)
- 잣대를 바꾸지 않는다 — 같은 날·짝비교·부호검정, 표본 단위는 날짜
- 누출 규칙을 바꾸지 않는다 — 수급은 **D−1 까지만**
- 측정 코드를 다시 쓰지 않는다 — `scripts/flow_rank_r131.py` 의 함수를
  **그대로 import 해서** 쓴다. 다시 구현하면 두 라운드가 서로 다른 것을
  재게 된다 (이 저장소가 이미 겪은 함정)
- R55·R57·R66 전방 창을 건드리지 않는다 · blind·전방 미사용

## 2. 문턱을 **올린다** — 같은 가설을 두 번 재기 때문이다

R131 이 5개를 쟀고, 이 라운드가 **같은 5개를 다시** 잰다.
가족 단위로 보면 시험이 **10개**다. 두 번째 기회를 공짜로 쓰지 않는다.

| | 계산 | 문턱 |
|---|---|---|
| R131 | 양측 0.05 / 5 = 0.01 | z 2.5758 → **2.58** |
| **R134** | 양측 0.05 / **10** = 0.005 | z 2.8070 → **2.81** |

**올림**한다 (라운드 113 에서 반올림해 문턱을 낮춘 적이 있다).

## 3. 판정 기준 — 측정 전에 못 박는다

| | 조건 |
|---|---|
| **P1** | 부호검정 z ≥ **2.81** |
| **P2** | 방향이 양수 — 상위5의 도달률이 대조군보다 **높다** |
| **P3** | train 과 valid 에서 **방향이 같다** |
| **P4** | 짝비교 날짜 **600일 이상** |

**넷을 모두 넘어야 통과다.** 하나라도 미달이면 기각하고 현행 유지한다.

### P4 의 600 은 어디서 나왔나

감으로 고르지 않았다. R131 에서 **수급이 붙은 날짜 220일 → 짝비교
219일** 로 전환율이 사실상 1.0 이었다. 지금 붙은 날짜가 1,411일이므로
같은 전환율이면 1,400일 안팎이 나와야 한다. **600 은 그 절반 이하**로
잡은 하한이다 — 통과 여부를 가르는 문턱이 아니라, **조인이 조용히
깨졌을 때 잡아내는 안전선**이다.

## 4. 결론의 크기를 **먼저** 계산해서 적는다

라운드 129 의 식으로 **이 표본의 최소 가시 효과**를 같이 낸다.

- 그것이 R131 의 8~12%p 보다 **내려가지 않으면**, 이 라운드는 표본을
  키운 값어치가 없었다는 뜻이다. 그대로 적는다.
- 미달이어도 *"수급에 효과가 없다"* 로 쓰지 않는다.
  **"이 표본에서 X%p 짜리는 없다"** 로만 쓴다.
- 그리고 **R131 의 판정을 지운다고 쓰지 않는다.** 두 결과를 나란히
  싣는다 — 표본이 다르면 다른 물음이다.

## 5. 자기검사 — 통과해야 숫자를 쓴다 (R131 의 넷을 그대로)

| | 무엇 |
|---|---|
| ⓐ | 거짓양성률 — 그날 결과를 섞은 귀무에서 z≥1.96 이 2.5% 근처인가 |
| ⓑ | 변수가 실제로 정렬에 들어갔는가 (섞으면 z 가 바뀌는가) |
| ⓒ | 누출 검사 — D 당일을 쓰면 z 가 달라지는가 |
| ⓓ | 대조군(`score`)이 **0 이 아닌가** — 0 을 '대조'라고 찍지 않는다 |

ⓓ 는 **판정 기준이 아니다.** R131 에서 이 검사에 P4 의 상수를 잘못
빌려 써 실패로 찍힌 적이 있다 — 재는 것은 *"쟀느냐"* 이지
*"충분하냐"* 가 아니다.
