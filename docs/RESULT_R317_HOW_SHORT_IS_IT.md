# 결과 R317 — **얼마나 모자라나** · 중앙 0.31%p, 최고 후보도 +0.01% (2026-09-16 · 측정)

R316 이 *"막는 것은 사실상 하나 — 비용 차감 기대값 양수(397/398)"* 를 냈다. 다음 물음은
자연스럽다: **얼마나 모자라나.** 조금 모자란 것과 한참 모자란 것은 다른 사실이고(§3),
사용자에게도 전혀 다른 말이다.

## 1. 실측 (리포트 87개 · 후보 398개 · 값을 못 읽은 것 0개)

| | 비용 차감 기대값 |
|---|---:|
| 최소 | −1.19% |
| 25분위 | −0.58% |
| **중앙** | **−0.31%** |
| 75분위 | −0.22% |
| **최대** | **+0.01%** |
| 양수 | **1개 (0.3%)** |

**중앙 후보는 0.31%p 모자란다.** 그리고 87개 리포트를 통틀어 **가장 좋았던 후보조차
+0.01%** 다 — 사실상 0이다.

## 2. 이 수가 닫는 반론

자연스러운 반론이 하나 있다 — *"게이트가 너무 빡센 것 아닌가?"*

아니다. 그 조건의 문턱은 **0보다 크기만 하면 되는**, 만들 수 있는 **가장 약한 문턱**이다.
그런데도 398건 중 **1건**만 넘는다. 막는 것은 문턱이 아니라 **왕복 비용(0.36% · R191)보다
우위가 작다**는 사실이다.

§9 가 적어 둔 결론(*"이 엔진의 매수권 신호에는 실전에서 재현되는 비용 차감 우위가
없다"*)에 이제 **거리**가 붙는다 — **0.31%p.**

## 3. 문턱도, 화면 숫자도 만들지 않았다

- 문턱을 만들지 않았다 — *"−0.1% 까지는 봐준다"* 같은 완화는 **결과를 본 뒤의 기준
  변경**이고 §2-5 가 금지한 그것이다.
- 화면에 이 수를 **안 박았다** — 원장·리포트가 자라면 움직이는 값이라, 못 박으면 다음
  배치에 거짓이 된다(R213 이 `strict_not_worse` 에서 겪은 그 자리).
- 화면이 말하는 것은 **오늘의 조건별 수**뿐이다(R316) — 그것은 그 자리에서 세므로 안 낡는다.

## 4. 이 수로 무엇을 할 수 있나 (그리고 없나)

**할 수 있는 것**: *"재료를 더하면 얼마나 나아져야 하나"* 의 기준선이 생겼다. 새 재료가
기대값을 **0.31%p 이상** 끌어올리지 못하면 추천은 여전히 0건이다. R113 이 잰 검정력
하한(적중률 5%p)과 같은 성격의 수다 — **목표가 아니라 벽의 높이**다.

**할 수 없는 것**: 이 수는 *"비용을 줄이면 된다"* 를 뜻하지 않는다. 0.36% 는 R191 이
세 값(0.30·0.36·0.41)을 통일하며 채택한 운영 값이고, 그것을 낮추는 것은 **시장이 정하는
것**이지 우리가 고르는 값이 아니다. 낮춰 적으면 그게 §9 가 금지한 *"성과를 좋게 보이게
쓰는 것"* 이다.

⚠️ 분모는 **리포트에 오른 후보**다 — 스캔에서 이미 떨어진 종목은 여기 없다. 그러니
이것은 *"상위 후보가 얼마나 모자라나"* 이지 *"시장 전체"* 가 아니다(§3).
