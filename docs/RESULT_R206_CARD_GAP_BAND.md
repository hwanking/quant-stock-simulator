# 라운드 206 — 카드의 갭 경고 문턱 7% 를 걷어냈다. 채택 밴드가 유일 잣대다

측정: 2026-09-02 · 사전등록: `docs/PREREG_R206_CARD_GAP_BAND.md`
· 측정 코드: `_probe/r206_r1.py` · `_probe/r206_r2.py`

라운드 192 ⓓ 가 카드의 역수 계산을 고치며 남겨 둔 숙제다 — *"문턱 7% 를
채택 밴드로 바꾸는 것은 판정 문구가 바뀌는 변경이라 사전등록 감이다."*
사전등록을 쓰고(어제), 실행했다(오늘).

## R1 (닫힌 식) — 불일치가 전 정의역에 존재한다. 통과

채택 규칙: `next_action.BANDS = (5, 10, 15) × scale`,
`scale = clamp(ATR%/2.0, 0.7, 2.5)`. 매수 적격의 바깥 경계
**e1 = 10×scale ∈ [7.0, 25.0]** 이다.

즉 **고정 7% 는 스케일 전 구간에서 '눌림목 대기'(매수 적격) 안**이다:

| scale | edges | 7% 의 위치 |
|---|---|---|
| 0.7 (하한) | 3.5 / 7.0 / 10.5 | 눌림목 대기 경계 위 |
| 1.0 | 5 / 10 / 15 | 눌림목 대기 한복판 |
| 2.5 (상한) | 12.5 / 25 / 37.5 | **즉시·근접** 안 |

카드가 7% 에서 *"사실상 관망"* 을 말하는 자리에서 엔진은 **언제나 매수
적격**이라 판정한다. 역방향(밴드는 비적격인데 카드 침묵)은 scale < 0.7
이 필요해 **불가능**하다 — 이 잘못은 한 방향으로만 난다.

## R2 (25종목 실측) — 발화 1건, 그 1건이 실제 모순

기준일 2026-09-01 · 관심종목 25종목 · 실제 파이프라인:

- 7% 경고 발화: **1건** (남화토건 091590 · 위쪽 괴리 +11.7%)
- 그 1건의 `gap_band`: **눌림목 대기 — 매수 적격**

즉 예방이 아니라 **지금 화면의 자기모순**이었다: 발화한 유일한 경고가
엔진 판정과 반대로 말하고 있었다. 나머지 24종목은 괴리가 7% 미만이라
침묵 — 침묵은 옳았다.

## R3 (설계) — 전환 후 모순은 정의상 불가능. 통과

경고를 `gap_band ∈ {'장기 관찰', '괴리 과다'}` 일 때만 내면, 그 두
밴드는 `next_action` 이 스스로 비적격(`exclude_reason = '매수구간과
괴리 과다'`)으로 판정하는 구간이므로 **카드-관망 ⇔ 엔진-비적격**이
같은 잣대의 두 표현이 된다.

## 채택 · 구현

- `verdict_core.build()` 가 `gap_band` 를 **통로로** 지나가게 했다
  (§4 — 카드가 자기만의 밴드를 다시 계산하지 않는다. 출처는 여전히
  `next_action` 하나다). 없으면 `None` — 지어내지 않는다(§3).
- 카드 경고가 `_gap_pct >= 7` 대신 밴드로 판정한다. 경고 문구에
  **밴드 이름을 그대로** 적는다 — *"매수구간과 괴리가 큽니다
  [장기 관찰]"*. 숫자 줄("기준가가 권장보다 +X% 위")은 그대로다.
- BANDS·스케일·게이트는 **하나도 안 바꿨다** — 채택된 규칙의 재사용이다
  (§2-6).

남화토건류(위쪽 괴리 7~e1%)는 이제 숫자 줄만 받고 경고 꼬리가 없다 —
엔진이 눌림목 대기라 판정하는 자리이기 때문이다. 경고는 엔진이 실제로
비적격이라 보는 괴리(e1 초과)에서만 나온다.

## 검사 (§223 확장)

- 카드에 `_gap_pct >= 7` 리터럴이 없다 (§2 — 손 문턱 부재)
- 밴드 튜플과 `core.get('gap_band')` 로 판정한다
- 사전등록 링크가 있다 (주석에 있으므로 이 한 건만 원문으로 본다 —
  `code_lines()` 는 산문을 걷어낸다)
- **값으로** — `gap_band='장기 관찰'` 을 넣은 `vc.build()` 가 그 값을
  그대로 내보내고, 빈 입력이면 `None` 이다
