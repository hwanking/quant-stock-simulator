# 사전등록 R251 — 근거 없는 고정 보정 0.98 을 지울 것인가 (2026-09-09 · 측정 전 작성)

**이 문서는 측정 전에 쓴다.** 결과를 보고 기준을 고치지 않는다(§2-5).

## 0. 왜 지금 쓰나

사용자: *"어라 산식 9월 8일 근처에서 개선한다고 한거 아냐?"*

맞다. **라운드 238(2026-09-08)** 이 화면의 두 수만 보고 짚힌 결함을 정리하며
큐 7건을 남겼고, 그 마지막 줄이 이것이다:

> **고정 −2% 제거** — 사전등록 + 전 종목 영향 측정 · 별도 라운드

큐 7건 중 다섯은 R239·R242·R243 이 끝냈다. **이것과 신뢰도 구성요소 표시 둘이
남았고, 이것만 날짜가 없었다.** 그래서 오늘 쓴다.

## 1. 무엇이 있나 — 이미 확인된 사실

`quant_indicators.py:392`

```python
#: 모델 가중중앙값에 곱하는 고정 보정. 최초 커밋부터 있었고 근거가 코드에도
#  문서에도 기록되어 있지 않다.
FAIR_FIXED_HAIRCUT = 0.98
```

사슬은 이렇다(라운드 238 이 화면에 그대로 드러냈다):

| 자리 | 무엇 |
|---|---|
| `:2634` | `raw_target_val = weighted_median × 0.98` |
| `:2635` | `raw_upside_pct = raw_target_val / 현재가 − 1` |
| `:2709` | **윈저화** — 괴리율을 수축 (하한 −40 등) |
| `:2713` | `target_fundamental = 현재가 × (1 + 수축된 괴리율)` |
| `:2718` | **확장구간(10~90분위) 클립** |
| `:2722` | `base_fair_value = target_fundamental ÷ 0.98` ← 되나눔 |
| `:2767` | `displayed_fair_value = target_fundamental` (신뢰도 55↑일 때) |

**중요**: 사이에 비선형 단계가 둘(윈저화·클립) 있으므로 **지우는 효과는 단순한
×1.0204 가 아니다.** 되나눠서 답을 낼 수 없다 — **두 번 돌려서 재야 한다.**

## 2. 물음 — 하나로 좁힌다

> **H1**: 고정 보정을 지우면(0.98 → 1.00) 적정가 구역(`entry_zone`)이 실제
> 20봉 결과를 **더 잘** 가른다.

**대칭으로 본다** — 지우는 쪽이 나쁘면 그것도 결과다(유지의 근거가 된다).

기각하면 **H0**. 다만 H0 의 뜻을 미리 적어 둔다(§3 절 참조) — *"차이를 못
가렸다"* 와 *"유지가 옳다"* 는 다른 말이다.

## 3. 판정 기준 — **비용 순으로** 정렬한다 (§2-7 · 라운드 170)

| 순서 | 기준 | 비용 | 미달이면 |
|---|---|---|---|
| **R0** | 근거가 어디엔가 있는가 — 코드·문서·커밋 이력 전수 검색 | **수 분** | **있으면 유지하고 끝낸다** |
| **R1** | **영향의 상한** — 지금 유니버스에서 지우면 몇 종목의 구역·게이트·권장매수가가 바뀌나 | **10~20분** | 바뀌는 것이 없으면 표시 문제일 뿐 — 그대로 적고 끝 |
| **R2** | 표본 백필 — 켠 값·끈 값을 **둘 다** 산출해 구역이 20봉 결과를 가르는 정도를 세 구간에서 견준다 | **3~4시간** | 접는다 |
| **R3** | 방향이 train·valid·blind 에서 **같은가** | — | 접는다 |

**앞에서 미달이면 뒤는 재지 않는다.**

### 비용은 실측했다 (재기 전에 셈한다)

케이스당 `run_full_pipeline` 재실행 **평균 1.70초**(차가운 캐시 6건 · 전부 성공 ·
`_probe/r251_backfill_cost.py` · 2026-09-09). 두 번 돌리므로 케이스당 3.4초.

| 표본 | 한 번 | 두 번 |
|---:|---:|---:|
| 1,000 | 0.5시간 | 0.9시간 |
| 3,000 | 1.4시간 | 2.8시간 |
| 10,000 | 4.7시간 | 9.4시간 |
| 251,528 (전량) | **118시간** | 236시간 |

**라운드 215 가 백필을 접은 근거는 전량(118시간)이었다** — *"기존 행 백필 =
축적 전체라 안 했다"*. **표본 백필은 그때 검토되지 않았다.** 이 문서가 그것을
연다.

### 표본은 어떻게 고르나 — 새 숫자를 만들지 않는다

- **겹치지 않는 부분집합에서만** 뽑는다 — 같은 종목 35일(25봉×7/5) 안 재신호는
  한 사건이다. 규칙은 `ledger_view` 한 곳(R217·R54b 가 이미 쓰는 값).
- **층화**: 구간(train/valid/blind) × 적정가 구역(`entry_zone` 6칸).
  둘 다 이미 채택된 칸이다 — 새로 만들지 않는다.
- **크기는 통계 문턱이 아니라 예산으로 정한다.** 3시간 예산 → 약 3,000건.
  검정력을 미리 고르면 그것이 새 숫자다. 대신 **잰 뒤 검정력을 보고**하고,
  못 볼 크기의 효과는 *"이 잣대로 못 본다"* 고 적는다(라운드 113 의 두 문장).
- **날짜 군집 부트스트랩**으로 CI 를 낸다. 시드 251.

### 다중검정

구역이 6칸이므로 칸별로 보면 6회다. Bonferroni(6) 양측 z **2.64**
(0.05/6 → 2.6383 → **올림** · 라운드 113 의 규칙). **판정은 사전등록한
CI95 로 하고 보정은 같이 적는다** — 라운드 249 와 같은 방식.

## 4. 판정 규칙을 **미리** 적는다

결과를 본 뒤 정하면 그것이 §2 위반이다. 세 갈래를 미리 적는다.

**(가) 지우는 쪽이 세 구간에서 낫다** → 지우기로 **결정**한다. 다만 **배포는
2026-11-16 이후**다 — R78 이 국면 라우팅 전방 검증 중이라 다른 규칙을 같이
넣으면 어느 쪽 효과인지 못 가른다. 그때까지 화면은 지금처럼 사슬을 드러낸다.

**(나) 유지하는 쪽이 세 구간에서 낫다** → **유지**한다. 그리고 *"근거는 없지만
실측으로 유지한다"* 를 문서와 화면에 적는다 — 그때는 더 이상 근거 없는 상수가
아니다.

**(다) 못 가린다(CI 가 0 을 포함하거나 방향이 어긋난다)** → **현행 유지.**
이유를 정확히 적는다: *"지울 근거도 유지할 근거도 못 세웠다."*

- 여기서 *"근거가 없으니 지운다"* 로 가지 **않는다.** 지우면 **모든 종목의
  적정가가 오르고**(현재가 대비 더 싸 보인다) 구역·게이트·권장매수가가 느슨해진다.
  근거 없이 느슨하게 만드는 것은 §9 가 금지하는 방향이다.
- 라운드 44 가 `market_adjustment_pct: -2.0` 을 걷어낸 선례가 있으나 **그것은
  게이트에 안 닿는 표시 보정**이었다. 이것은 게이트에 닿는다. **선례를 그대로
  옮기지 않는다.**
- (다)이면 다음 재측정은 **표본이 커진 뒤**다(축적 재개 ~2026-10-08 · R217).

## 5. 하지 않는 것

- **0.98 을 다른 수로 바꾸지 않는다.** 이 문서는 **0.98 대 1.00** 만 본다.
  최적값을 찾으면 그것은 손으로 고른 새 숫자다(§2 · 라운드 29·33 이 기각된 자리).
- 윈저화·클립·안전마진·신뢰도 문턱을 건드리지 않는다.
- 결과가 어떻든 **11-16 전에는 배포하지 않는다**(R78).
- 미달이면 기준을 내리지 않는다. 미측정이라 적고 언제 다시 보는지 적는다.
