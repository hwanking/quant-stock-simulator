# 결과 R237 — 20일선 아래인데 '안착 성공' · 점수 이름이 계산보다 넓었다 (2026-09-08)

사용자 지적. 하나는 **실제 논리 결함**(고쳤다), 하나는 **이름이 계산보다 넓은 것**(이름을
고쳤다), 하나는 **결측이 판정으로 위장되던 것**(갈랐다)이다. 문턱과 산식은 그대로다.

## 1. 가격이 20일선 아래여도 '안착 성공'이 나왔다

```python
c1 = 최근 2봉 종가가 각각 그날의 20일선 위
c2 = 20일선 기울기 ≥ 0 · c3 = 거래량 ≥ 20일 평균 1.2배 · c4 = RSI ≥ 45
return passed_cnt >= 3, ...        # ← c1 이 실패해도 나머지 셋이면 '안착 성공'
```

'안착'은 **가격이 그 선 위에서 유지된다**는 뜻이다. c1 을 다른 셋과 같은 무게로 세면 이름이
가리키는 상태가 아닌 것을 안착이라 부르게 된다. 사용자가 합성 입력(종가 90 · 20일선 100 ·
기울기 양수 · 거래량 1.3배 · RSI 55)으로 재현했고, **회귀 §254 가 그 입력을 그대로 심는다.**

**고침:** c1 을 **필수 전제**로 둔다. 문턱(2봉 · 기울기 0 · 1.2배 · RSI 45)과 '3개' 규칙은
한 글자도 안 바꿨다 — c1 이 충족일 때의 판정은 종전과 완전히 같다. c1 이 미충족이면
`안착 아님 — 가격이 20일선 위에서 유지되지 않았습니다 (필수 전제). 나머지 조건은 4개 중
N개 충족` 이라 적어 **몇 개가 맞았는지도 지우지 않는다.**

**운영 영향 없음:** `check_20sma_settlement` 의 호출부는 `web_app.py` **한 곳**뿐이고, 거기서
쓰는 것은 메시지뿐이다(반환된 불리언은 아무도 안 읽고 있었다). 추천·차단·진입·청산 어디에도
연결되어 있지 않다 — 이 라운드가 바꾼 것은 **화면 문장**이다.

## 2. 결측이 '안착 대기'로 위장되고 있었다

전처리가 결측을 대체값으로 채운다: 기울기 `fillna(0.0)` · RSI `fillna(50.0)` · 거래량비
`fillna(1.0)`. 그래서 자료가 없는 종목도 **기울기 0 이상(항상 참)** 과 **RSI 50 ≥ 45** 로
두 조건이 '충족'으로 세어져 `2/4 안착 대기` 가 나왔다. 대기가 아니라 **확인 불가**다.

이제 지표마다 **이미 쓰는 창**을 못 채우면 '확인 불가'로 적고 세지 않는다 — 새 문턱이 아니라
`sma_20 = rolling(20)` · 기울기 = 그 위 `diff(3)` → 23 · 거래량비 = 20일 평균 · RSI = 14 에서
그대로 나온 수다. 20일선 자체가 결측이면 전체가 확인 불가다.

## 3. '4개 중 2개'가 아니라 **어느** 두 개인지

한 줄 요약만으로는 무엇을 기다려야 하는지 알 수 없었다. 이제 조건마다 **실제 값과 상태**를
낸다(예: `종가 25,800 vs 20일선 24,302 · 충족` / `1.02배 · 미충족`). 상태는 충족 · 미충족 ·
확인 불가 셋이다.

## 4. '수급·기술 33점'에는 수급이 없다

이 관점 점수의 계산은 둘뿐이다:

```python
parts = [clip(100 - 볼린저_위치, 0, 100), clip(100 - RSI × 1.2, 0, 100)]
점수 = mean(parts)
```

볼린저 73% · RSI 51 → (27 + 38.8) / 2 = **32.9 → 33점**. 사용자 계산과 같고 §254 가 실제로
돌려 재현한다. **수급(외국인·기관)·거래량·20일선 안착 결과는 이 점수에 들어가지 않는다.**

산식은 한 글자도 안 바꾸고 **이름**을 고쳤다: `수급·기술` → **`가격 위치 (볼린저·RSI)`**.
그리고 근거 줄에 무엇이 안 들어가는지, 값이 클수록 '눌린 자리'라는 뜻이고 상승확률이 아님을
적는다. 어느 쪽이 점수를 더 낮췄는지도 한 줄로 낸다.

**사용자 지시 중 둘은 따르지 않았다.** ① *"외국인/기관 수급 총알을 즉시 추가하라"* — 이
점수에 수급이 없다는 사실을 화면에 적는 것이 먼저다. 수급 열(`institution_net`·`foreign_net`)은
DeMARK 점수에서만 쓰이고 이 관점에는 없다. 없는 것을 있는 것처럼 붙이지 않는다(§3).
② *"'점수 하락 원인: 외국인 연속 순매도'처럼 브리핑하라"* — 그 점수에 수급이 없으므로 그것을
원인이라 적으면 **지어낸 설명**이다. 실제 두 재료 중 어느 쪽이 낮췄는지만 적는다.

## 5. 화면 실측에서 내가 넣은 결함 하나를 잡았다 (2026-09-08 · 삼성전자)

조건별 표를 띄우자 첫 줄이 **`종가 270,000 vs 20일선 259,075 · 미충족`** 이었다. 270,000 이
259,075 보다 큰데 미충족이라 **스스로 모순돼 보였다.** 판정은 맞았다 — 이 조건은 **두 봉**을
보는데(09-04 종가 255,500 < 그날 20일선 257,125) 상세에 최근 한 봉만 적은 것이 문제였다.
두 봉을 다 적는다: `오늘 270,000 vs 259,075 · 직전 255,500 vs 257,125`.

R235 에서 뜻이 뒤집힌 문구를 화면에서 잡은 것과 같은 자리다 — **회귀는 통과하고 화면만
모순되는 결함은 서버를 띄워야 나온다.** 검사를 하나 더 심었다(상세가 두 봉을 다 적는가).

## 6. 바꾸지 않은 것 · 남긴 것

- 문턱(2봉 · 0 · 1.2배 · 45)·'3개' 규칙·볼린저/RSI 산식·가중치 — 불변.
- 시장 국면 문구('완만한 상승장'인데 지수가 60일선 아래)는 **이번에 안 건드렸다.**
  국면 분류는 여러 화면과 게이트가 읽는 값이라 문구만 바꾸면 다른 화면과 어긋난다 —
  다음 라운드에서 관측 사실(지수의 20·60일선 대비 위치)을 같이 내는 쪽으로 본다.
- 볼린저·RSI 점수가 "많이 눌린 종목에 높은 점수"를 주는 구조인지의 연구는 별도 사전등록이다.
