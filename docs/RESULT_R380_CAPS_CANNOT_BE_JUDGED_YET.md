# 라운드 380 — 상한 64 두 개를 끄고 켜는 재측정은 오늘 못 연다 (2026-09-29 · 문서 전용)

코드 0 · 검사 0 · 버전 0 · **사전등록 안 씀** · 결과(적중·수익)는 **안 봤다**.

## 1. 물음

라운드 369 가 두 상한(월봉 10선 아래 → 64 · 52주 저점권 → 64)의 근거가 큰 원장에서 재현되지 않는다고 적고
*"제대로 재려면 끄고·켜고 두 판(라운드 251·267 의 길) · 비용을 먼저 센다"* 를 레이더에 남겼다. 비용 순으로 싼
것부터 쟀다(§2-7) — 둘 다 원장 칸만 읽는다(네트워크 0 · 수 초).

## 2. R0 — 이득 상한: 작지 않다

상한이 누르는 행은 **조건이 참이고 점수가 정확히 64 인 행**뿐이다(조건이 참인 행의 최고 점수가 64 · 65점 이상
0행 — 라운드 369 확인 그대로). 끄면 그 행의 점수만 위로 간다.

| | 조건 참 행 | 64점 | 63점 | 62점 |
|---|---:|---:|---:|---:|
| 월봉 10선 아래 (`m10_above` 거짓) | 133,245 | **2,724** | 71 | 166 |
| 52주 저점권 (`range_pos` < 30 · 원장 칸 근사) | 98,148 | **1,746** | 51 | 85 |
| 둘 중 하나 · 64점 | | **2,782** | | |

64 에 봉우리가 선다 — 대부분이 위에서 눌려 내려온 것으로 **보인다**(추론 · 원장에는 누르기 전 점수가 없다).
견줄 수: 원장 전체에서 점수 **68 이상은 53행**뿐이다(제목 '제한적 진입' 49 · '분할매수 검토' 4).

⚠️ 2,782 는 **상한**이다 — 같은 64 로 누르는 상한이 넷 더 있다(적정가 신뢰도 미달 · 유효표본 10건 미만 · 신뢰도
수축 괴리 · 상대 모멘텀 열위 · `quant_indicators` 의 `min(...)` 한 곳). 가장 낮은 상한이 점수를 정하므로 이 둘을
꺼도 다른 64 가 같은 행을 누르고 있으면 안 움직인다. 어느 쪽이 눌렀는지는 원장에 없다 — 다시 돌려야 안다.

**점수가 판정에 닿는 길은 하나다** — 중앙 판정의 추천 조건은 점수를 직접 안 읽고, 점수가 속한 **점수대의 과거
적중률**(`calibration_band`)이 비용 차감 기대값에 들어간다(`verdict_core` · 기대값 = 적중률 × 위 − (1 − 적중률) ×
아래 − 비용). 점수가 64 에서 68+ 로 가면 기대값에 쓰는 적중률이 바뀐다 — 추천 수가 바뀔 수 있는 자리다. 그래서
상한이 작다는 이유로 접지 않는다.

## 3. R1 — 날짜 하한: 미달

바뀌는 행이 선 **고유 기준일**(결과는 안 봤다 · 하한 30 · 라운드 84·45 에서 채택 · 라운드 251·267 이 같은 성격의
종목 단위 물음에 같은 하한을 썼다):

| 구간 | 행 | 고유 기준일 | 종목 | 겹침 없는 행 |
|---|---:|---:|---:|---:|
| train | 2,489 | 555 | 688 | 2,306 |
| valid | 117 | **23** | 80 | 107 |
| blind | 176 | **26** | 133 | 161 |

(월봉 10선 아래만: valid 23 · blind 26 · 52주 저점권만: valid 19 · blind 22)

→ **valid·blind 둘 다 하한 미달이다.** 끄고 켜는 두 판을 돌리면(2,782행 × 2판 · 라운드 251 의 케이스당 0.76~1.70초로
약 1~2시간) train 하나의 답만 선다 — 라운드 251 이 블라인드 날짜 22 에서 본 모양이고 라운드 267 이 날짜를 채우자
그 신호가 사라졌다. **하한을 안 내린다**(§2-5). 사전등록도 **안 썼다** — 표본 없이 등록부터 쓰면 재지 않은
사전등록이 된다(라운드 192 · 354 · 291 과 같은 순서).

## 4. 무엇이 날짜를 더하나

바뀌는 행은 **종목이 200일선 아래이거나 52주 범위 하위 30%** 인 날에만 생긴다 — 하락장에 몰린다. 원장 격자는
옛 역사를 한 봉 옆에서 다시 뽑을 뿐이라(라운드 217) 새 날짜는 전방 구간이 더한다. 2026-11-16 전방 재평가 때
같은 셈(이 두 표)을 다시 하고, 하한을 넘으면 그때 사전등록 → 두 판.

## 5. 서 있는 것

- 두 상한은 **그대로**다(게이트 · 동결 · 근거 없이 지우지도 유지 근거를 세우지도 않았다).
- 화면의 사유 문장은 라운드 369 가 이미 *"그 뒤 커진 원장에서는 재현되지 않아 다시 잴 예정"* 이라 적는다 —
  오늘도 참이다(다시 잴 예정이고 언제 열리는지가 이 문서다). 고치지 않았다(라운드 250 · 참인 문장).
- 레이더 줄은 상태를 *미측정 · 날짜 미달* 로 옮겼다.
