# 운영 루틴 — 케이스 스터디는 절대 중단하지 않는다 (2026-08-01 제정)

> 사용자 지시(운영 체계 v3): "한 번 수정하고 종료하지 말고, 실제 시장 데이터를
> 지속적으로 축적하고 검증하면서 성능을 개선하는 운영 체계로 완성하라."
> 100점 = 적중률 100%가 아니라 **데이터 정확성·블라인드 검증·사용성·자동
> 케이스 축적·지속 연구 반영**을 모두 갖춘 시스템이다.

## 0. 현재 수치의 정직한 해석 (화면 표기 기준)
- 검증(표본외) 66.8% (n=377): **가능성 있음** — 국면별 분해 필요, 블라인드 갭 조사 필요
- 블라인드 51.4% (n=247): **실전 신뢰도 부족 — 최우선 개선 대상**
- 고신뢰(60+) 블라인드 88.9% (n=9): **참고만 가능** — 표본 부족 경고를 적중률보다
  크게. 30건 전에는 대표 성과처럼 표시하지 않는다
- 신호율 3.1%: 선별 엄격은 장점이나 표본 축적 속도 부족 — 우연 적중 위험 점검

## 1. 케이스 축적 목표 (중단 금지)
- 1단계 3,000건 → 2단계 5,000건 → 3단계 10,000건 → 이후 매 거래일 자동 추가
- 중복 통제: 25봉 간격 기준일(지평 20봉과 비중복), 동일 종목·유사 진입일 반복 금지,
  ETF와 기초지수 사실상 중복 유의, 미래 결과 기간 겹침 금지
- 실행: `python scripts/calibration_lab.py --limit N` (체크포인트 재개 — 기존 건 자동 스킵)
- 완료 후: `.portfolio/calibration.json`·`virtual_graded.jsonl` → `data/` 복사,
  `python scripts/gen_update_history.py`, 회귀 통과 확인, 커밋·푸시

## 2. 매 거래일 루틴
**장 종료 후**: 확정 OHLCV 수집 → 전일 개장 전 추천 실제 결과 갱신
(`premarket.grade_history`) → 미결 케이스 도달 여부 확인 → 라벨링(성공/실패/미도달)
→ 수익률·MDD 계산 → 데이터 오류 검사 → 원장 저장 → 성과 재계산 → 대시보드 갱신
**개장 전**: 전일 확정 데이터만으로 추천 확정·동결(`premarket.build_report` —
생성 시각·기준일·종목·점수·행동·가격 3종·보유기간·모델 버전 박제).
장중 사후 수정 금지(코드로 강제됨 — 당일 파일 고정).

## 3. 매주 루틴
**무료 언어모델 관찰 (자동)**: `llm_watch.get_llm_watch()` 가 앱 구동 시 캐시가
7일을 넘으면 HuggingFace 공개 API에서 스스로 재조회한다(조회 전용 — 우리 데이터
전송 없음). 화면 '무료 언어모델 주간 관찰'에 목록·갱신일 표시. **관찰 전용** —
파이프라인 채택은 §5 검증 조건을 통과해야 하며, 포트폴리오 정보는 어떤 외부
모델에도 보내지 않는다.

새 확정 케이스 수 / 최근 20·50·100건 적중률 / 표본외·블라인드 적중률 /
점수대별 실측 / 신호율 / 평균 수익·손익비·PF·MDD / 연속 실패 / 실패 원인 상위 /
자산 유형·국면별 성과를 재계산해 기록. **매주 모델을 바꾸지 않는다** —
악화가 보이면 원인만 기록하고 충분한 신규 표본까지 운영 모델 유지.

## 5. 연구 채택 조건 (전부 충족 시에만)
블라인드 개선 + 비용 차감 기대값 개선 + MDD 비악화 + 종목군 비편중 +
충분한 독립 표본 재현 + 통계적 유의 + 데이터 누출 없음 + 재현 가능한 코드·산식.
후보별 기록 항목: 출처/연도/핵심 아이디어/필요 데이터/구현 가능성/대상 실패 원인/
누출 위험/계산 비용/국내·ETF 적용성/학습·검증·표본외·블라인드 성능/개선폭/
복잡도/채택 여부. → docs/MODEL_VERSIONS.md 에 축적.

## 6. 운영·후보·블라인드 3계층 분리
- **운영 모델**: 사용자에게 실제 결과 제공하는 고정 버전 (자동 교체 금지)
- **후보 모델**: 새 지표·가중치 시험 버전
- **블라인드 평가**: 최종 미사용 데이터 — 보고 전용, 선택 근거 사용 금지(§58)
- 승격 조건: 테스트 전체 통과 + 표본외·블라인드·기대수익 개선 + MDD 비악화 +
  충분한 신규 표본 + 비교 보고서 + 승인 기록

## 7. 블라인드 51.4% 최우선 개선
실측 분해는 **docs/BLIND_GAP_REPORT.md** (스크립트 `scripts/blind_gap_analysis.py`
로 재생성). 핵심 관찰: 검증 구간은 BULL 59%였고 블라인드는 SIDEWAYS 50% —
갭의 상당 부분이 장세 변화 후보. 같은 국면끼리 비교해도 남는 갭(BEAR·SIDEWAYS)이
진짜 조사 대상. 개선 가설(국면 조건부 임계값, 유사패턴 국면 가중, BEAR 게이트
강화)은 전부 학습·검증에서 먼저 검증 후 사전등록.

## 8. 고신뢰 표본 확대 기준
30건(최소 확인) → 100건(제한적 신뢰) → 200건+(통계 평가) →
국면별 각 50건 · 자산 유형별 각 50건. 30건 미만이면 높은 적중률 강조 금지,
표본 증가 시마다 Wilson 95% 신뢰구간 병기(이미 화면 적용).
