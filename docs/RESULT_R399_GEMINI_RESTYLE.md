## 3. 고치다 나온 것

1. **아이콘이 글자가 됐다** — 첫 판의 글꼴 규칙이 Material Symbols 를 덮어 사이드바에 `search`·`tune` 같은 글자가 나왔다. 라벨 속 `:material/…:` 아이콘은 testid 없이 `role="img" translate="no"` 인라인 글꼴로 그려진다 — 그것까지 뺐다.
2. **제목 안 span** — 크기를 적지 않은 span 은 제목 크기를 따르게 했다.
3. **주요 버튼 hover 글자** — 보조 버튼 hover 규칙(0,3,1)이 주요 버튼 글자(0,2,1)를 이겨 다크에서 밝은 파랑 위 밝은 글자가 됐다. 같은 무게로 한 번 더 적었다.
4. **사이드바 버튼** — web_app 의 사이드바 블록이 (0,2,3)으로 이겨 옛 남색이 남았다. 한 단계 더 구체적으로 적었다.
5. **머리줄이 상단 바를 덮었다** — Streamlit 머리줄(60px)이 불투명이라 본문 맨 위 엔진 정보가 빈 줄로 보였다(사용자 화면). 머리줄을 투명하게, 누름은 그 안 버튼만.
6. **타일 값이 스케일 밖** — 잘림을 고치려던 `clamp(20px, 13cqw, 28px)` 가 연속값이라 **22.62px** 을 냈다(타일 5개). §77 의 소스 정규식은 `font-size:clamp(` 를 숫자로 안 읽어 못 봤다. 스케일의 세 단(20·22·28)으로 계단을 두고, 문턱은 같은 비율(글자 = 타일 내용 폭의 13%)이 22·28 에 닿는 폭(170·216px)이다 — 새로 고른 수가 아니다.
7. **대화 얼굴 1.88:1** — Streamlit 기본 주황(`#FF8700` · 팔레트 밖) 위에 옛 층이 아이콘을 밝은 글자색으로 칠했다. 다크 화면의 **유일한** 미달이었다. 브랜드 면 + `on_brand`.
8. **상단 바 여백 120px** — Streamlit 메뉴 자리라며 비웠는데 이 앱의 머리줄엔 오른쪽 버튼이 **없다**(자식 0개 · 실측). 칩 덩어리(926~1,030px)가 줄 가운데서 꺾여 네 줄이 됐다. 16px 로 줄이고 칩을 둘째 줄로.
9. **배포 머리줄** — Streamlit Cloud 는 머리줄 오른쪽 도구 줄에 아이콘을 그릴 수 있다. 그때만 오른쪽을 비운다. ⚠️ 첫 판은 '머리줄 안의 버튼'으로 걸었는데 사이드바를 접으면 **펼침 버튼이 도구 줄 안**에 들어와 조건이 켜졌다. 그 버튼만 빼고 센다 — 가짜 버튼을 심어 켜지는지, 빼면 꺼지는지 양쪽을 봤다. 펼침 버튼(x 18~46)이 첫 줄 글자 머리(x 44)를 덮는 것도 그때만 왼쪽을 비워 고쳤다.
10. **'보는 중' 12px** — 옛 층이 **클래스**로 12px 을 적어 인라인만 보는 13px 바닥 규칙을 빠져나갔다. 13px. (칩 글자는 인라인 12px 이라 바닥 규칙이 이미 13px 로 올린다 — 이 칸의 첫 판은 칩이 12px 으로 남는다고 잘못 적었다.)
11. **"맨 뒤" 는 거짓이었다** — 주석이 이 층을 *"모든 CSS 뒤"* 라 적었는데 아래에 좁은 자리 블록이 **8개** 더 온다(4 의 사이드바 블록이 그래서 이겼다). *"전역 층 넷 뒤"* 로 고쳐 적고 회귀가 그 자리를 잠근다.
