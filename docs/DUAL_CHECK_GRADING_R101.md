# 라운드 101 — 채점을 독립 경로로 다시 매겼다 (dual-check)

## 왜 이것부터인가

이 저장소의 모든 숫자 — 적중률·EV·리프트·유효표본·국면별 성적 — 가 원장의
`outcome` 하나 위에 서 있다. 그게 틀리면 나머지가 전부 틀린다.

그런데 라운드 100까지 **그 값을 다른 경로로 다시 매겨 본 적이 없었다.**

## 무엇이 독립이고 무엇은 아닌가

| | 만든 것 | 언제 |
|---|---|---|
| 원장 `outcome` | `calibration_lab` 이 채점할 때 받은 OHLC | 채점 시점 |
| `bar_paths_s*.jsonl` | `path_recorder` 가 **따로 받아** 신호일 대비 %로 기록 | 경로 기록 시점 |

코드도 실행 시점도 다르다. 다만 **출처(네이버)는 같다** — 그래서 "원천
데이터가 틀렸나"는 못 잡는다. 잡는 것은 봉 정렬·지평 오프바이원·목표/손절
뒤바뀜이고, 이 저장소에서 실제로 다 났던 종류다.

## 사전등록 (재기 전에 정한 것 — §2)

1. 판정 규칙은 원장이 쓰는 것을 **그대로** 쓴다. 새로 고르지 않는다 —
   지평 안에서 고가가 목표에 먼저 닿으면 `TARGET`, 저가가 손절에 먼저
   닿으면 `STOP`, **같은 봉에서 둘 다 닿으면 성공으로 안 센다**.
2. 대조 대상은 원장 결론이 `TARGET`/`STOP` 인 건만 (`OPEN` 은 지평 미완).
3. **합격 기준: 불일치율 ≤ 1.0%.** 넘으면 합격시키지 않는다.
4. **대조 건수 < 1,000 이면 '못 쟀다'로 적고 판정하지 않는다.**
5. 불일치가 나오면 성격을 밝힌다 — 쏠리는지 흩어지는지 **분포로**.

## 첫 측정에서 내가 틀렸던 것

허용오차 없이 재니 불일치 **244건(0.138%)** 이 나왔다. 그런데 그 절반이
**내 대조의 부작용**이었다.

`path_recorder` 는 봉 %를 `round(pct, 3)` 으로 저장하는데, 나는
`저가 ≤ 손절` 을 엄격히 따졌다.

```
000080.KS 2018-05-14 · 손절 20,700/21,400 = -3.27103%
경로 5봉 저가 -3.271 (반올림)  →  -3.271 > -3.27103 이라 '미도달'
원장의 mae 는 정확히 -3.27 이고 그 봉에서 STOP 이라 했다.
```

두 원장은 **같은 봉을 같게 보고 있었고** 갈린 것은 내 비교였다.
허용오차를 **저장 정밀도에서 유도**하니(`EPS = 0.0005`) 110건으로 줄었다.
감으로 고른 숫자가 아니다 — 소수 3자리 반올림의 최대 오차다.

## 결과

```
대조 176,646건 · 건너뜀 7,713건
일치 176,536 · 불일치 110 → 0.062%  (기준 1.0%)
도달 봉까지 같은 비율 99.9%
```

| 불일치 방향 | 건수 |
|---|---:|
| 원장 STOP → 재판정 TARGET | 94 |
| 원장 STOP → 재판정 OPEN | 15 |
| 원장 TARGET → 재판정 STOP | 1 |

**110건 중 109건이 "원장이 더 나쁘게 매긴" 방향이다.** 성과를 부풀리는
쪽이 아니다.

## 남은 110건의 정체 — 채점 결함이 아니다

- **18개 종목에 몰려 있다.** 하나(`052710.KQ`)가 66건, 상위 5개가 91건.
- 원장이 본 저가가 경로보다 **중앙값 -8.8%p 낮다.** 경계에 걸친 것은 0%.

즉 두 원장이 **다른 가격 시계열**을 보고 있다 — 채점 시점과 경로 기록
시점 사이에 과거 시세가 재작성된 것(분할·병합·재상장)이다. 같은 출처를
쓰는 한 원리적으로 못 없앤다. 0.062% 는 그 대가다.

## 이 결과가 뜻하지 않는 것

- 원천 데이터가 옳다는 뜻이 **아니다** (두 경로가 같은 출처를 쓴다).
- 목표·손절 값이 옳다는 뜻이 **아니다** (그건 엔진이 정한 값을 그대로 썼다).
- 이 엔진에 우위가 있다는 뜻이 **아니다** — 라운드 49 의 결론은 그대로다.

확인한 것은 하나다: **원장이 적은 승패는 독립 경로로 다시 매겨도 같다.**

찍지 않기 위해** 건수가 하한 미만이면 실패시킨다.
