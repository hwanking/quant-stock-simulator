# 결과 R246 — 카드가 중앙 판정을 안 읽었다 · 못 받은 값이 숫자로 나갔다 (2026-09-09)

병렬 감사 6축(에이전트 54개 · 적대적 검증)에서 **42건이 실재로 확인**됐다. 이 라운드는
그중 **화면이 사용자에게 거짓을 말하는** 넷을 고친다. 값·문턱·산식은 하나도 안 바꿨다.

## 1. 추천 카드가 하위 모듈의 결론을 그대로 읽었다 — R193 의 재발

라운드 193 이 고친 결함은 이랬다: *"next_action 은 가격 거리만 보고 게이트를 모른다.
그래서 같은 화면이 '분할매수할 수 있습니다'와 '쫓아가지 마세요'를 함께 말했다."*
그때 **상세 화면**을 중앙 판정으로 옮겼다(`CORE.get('next_headline')`).

**카드는 안 옮겨졌다.**

| 어디 | 무엇을 읽나 |
|---|---|
| 상세 화면 | `CORE.get('next_headline') or _NA.get('headline')` · `CORE.get('next_kind')` |
| **추천 카드** | `_n['headline']` · `_n['kind']` — 하위 모듈 직접 |

그래서 카드는 중앙 판정이 막은 종목도 `_n['kind'] == 'buy_now'` 를 보고 **초록(pos)으로
승격**하고 *"지금 분할매수할 수 있습니다"* 를 적었다. 조건 목록도 하위 모듈 것이라,
막힌 카드에서 *"거의 닿았습니다"* 한 줄만 남아 **무엇을 기다리는지** 말하지 못했다
(상세 화면은 라운드 197 에 같은 이유로 이미 고쳤다).

고침은 상세 화면과 **같은 순서**다 — 결론·kind·조건 목록 셋 다 중앙 판정을 먼저 읽고,
없을 때만(옛 리포트) 하위 모듈로 폴백한다. 통과한 종목에서는 중앙 판정이 하위 모듈의
말을 그대로 넘기므로 **문장이 안 바뀐다.** 막힌 종목에서만 바뀐다.

## 2. 시장 카드가 수신 실패 시 박아 둔 숫자를 냈다

`get_market_indices()` 의 기본값이 이랬다.

```python
kospi_p,  ... = "N/A", "0.00", "0.00%"
kosdaq_p, ... = "N/A", "0.00", "0.00%"
usd_p,    ... = "1,421.00", "-0.00", "-0.00%"      # ← 박아 둔 숫자
sp500_p,  ... = "7,381.87", "+65.72", "+0.90%"     # ← 박아 둔 숫자
```

네 개의 `except Exception: pass` 중 어느 것이 걸려도 **그 숫자가 그대로 화면 타일에
나갔다.** 같은 함수 안에서 KOSPI·KOSDAQ 만 `N/A` 였다 — 규칙이 갈려 있었다.

넷 다 `N/A` 로 맞추고, 삼키던 예외에 **사유를 남겨** 반환에 싣는다(`unavailable`).
화면은 미수신 타일에 `0.00 0.00%`(= 보합이라는 **숫자**) 대신 사유를 적는다.

## 3. `(v or 0) / 1e8` 이 '미산출'을 도달 불가로 만들었다

`fmt_num` 에 `na='미산출'` 을 주고도 `or 0` 이 앞에 있어 **None 이 0 으로** 바뀌었다.
거래대금을 못 받은 종목이 화면에 **'0억원'** 으로 나갔다 — 라운드 37 이 *"못 잰 것으로
거르지 않는다"* 로 배운 그 자리의 표시판이다. 억 단위 환산을 한 곳(`_tn246`)으로 빼고
None 은 None 으로 넘긴다. 호출 74개 중 이 형태는 2곳이었다.

## 4. 게이트 설명이 통과 여부와 무관하게 '기준 통과'를 적었다

`('보유기간 안 도달 가능', depth_sigma <= MAX_ENTRY_SIGMA, '…기준 통과 · 모형 확률 …')`
— 설명이 **조건과 독립**이라, 미달인 행 옆에 '기준 통과'가 찍혔다. 같은 화면의 사유는
*"60% 미만이라 추천에서 뺍니다"* 라고 말한다. 판정 불리언·문턱·산식은 그대로 두고
설명만 통과/미달로 가른다.

## 5. 바꾸지 않은 것

- 판정·문턱·산식·게이트 조건 수(11) — 전부 그대로. 회귀가 `checks[7]` 을 **자리로**
  읽으므로 순서도 안 건드렸다.
- 감사가 함께 지적한 *"11조건 중 두 조건의 판정식이 글자까지 같다"* 는 **안 고쳤다** —
  조건을 합치면 자리가 밀려 회귀·화면이 같이 흔들린다. 별도 라운드다.

## 6. 감사에 대해

54개 에이전트(조사 6 + 검증 48) 중 **검증 5건이 사용량 한도로 실패**했다. 그 다섯 건의
발견은 이 라운드에 넣지 않았다 — **검증되지 않은 것은 고치지 않는다.**
