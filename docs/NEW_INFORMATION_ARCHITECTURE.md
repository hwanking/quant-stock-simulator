## 4. 단계적 마이그레이션

Streamlit 단일 스크립트에서 일괄 전환하면 session_state·캐시
(get_shared_snapshot)·사이드바 의존이 동시에 깨지므로 3단계로 나눈다.

### A단계 — 현 단일 페이지에서 순서 재배치·숨김 (구조 변경 없음)

- 렌더 순서를 v2 위계(결론→가격→이유→검증→산식)로 재배치.
- 중복 표시처 삭제(§CURRENT_UI_AUDIT §2), 큰 글씨 축소, 토큰 CSS 1블록 주입,
  제목 이모지 제거, 기업 분석 전문가 격리(expander), 우측 요약 패널 추가.
- **감사 시점에 이미 착수·일부 반영됨**: 전역 앵커 6메뉴(294–299), v2 토큰
  주석(168), 우측 패널(2662), 퀀터멘탈 격리(3401), 제목 이모지 제거 진행.
- 리스크: 낮음(렌더 순서만). 단, expander 기본 open/close 변경이 사용자 습관과
  회귀 테스트 문자열에 걸릴 수 있음.
- 회귀 테스트 영향: **크다.** test_pipeline_fixes.py는 web_app.py **소스를 문자열로
  읽어 특정 문구·패턴 존재를 검사**한다(예: 383, 423, 1313, 1642, 2368, 2431,
  2489, 2555, 2659, 2703, 2788, 2896 등 `open(... 'web_app.py').read()` 후 assert).
  **문구를 바꾸면 같은 커밋에서 test_pipeline_fixes.py의 해당 검사 문자열을
  반드시 동기화**한다. 검사 의도(회귀 방지)는 유지하고 문구만 갱신할 것.

### B단계 — st.tabs 6개로 통합 (종목 분석 영역)

- 종목 분석 영역을 `st.tabs(["요약","차트","뉴스","시나리오","과거 검증","상세 근거"])`
  하나로 감싸고 기존 렌더 블록을 §2 표대로 이주. 계산 함수·캐시 키·session_state
  키는 불변 — 렌더 호출 위치만 이동.
- 리스크: 중간. (a) Streamlit 탭은 lazy 렌더가 아니어서 6탭 전체가 매 rerun마다
  실행됨 — 무거운 차트·시뮬레이션은 탭 진입 조건부 렌더 또는 캐시 확인 필요.
  (b) 탭 내부의 expander 중첩 제한. (c) 앵커 링크(#nav-*)가 탭 내부 요소로는
  동작하지 않음 — 앵커는 탭 자체까지만.
- 회귀 테스트 영향: 탭 라벨 문자열·기존 탭 변수명(tab_pred 등, 3482)을 검사하는
  테스트가 있으면 실패 — 라벨 변경분을 test_pipeline_fixes.py에 동기화.
- 검증: A단계와 화면별 동일 수치 스냅샷 비교.

### C단계 — st.navigation 멀티페이지 (전역 메뉴 6개 분리)

- `st.navigation + st.Page`로 메뉴당 1파일. 공유 상태(종목 선택·t_ref·rho·
  스냅샷 캐시)는 `ui_shared.py`(신규, UI 계층)로 추출 — 계산 모듈은 임포트만.
- URL 쿼리 딥링크(?ticker=005930) 지원 — 추천 카드→종목 분석 이동에 필요.
- 리스크: 높음. (a) 페이지 전환 시 session_state는 유지되나 위젯 상태는 페이지
  스코프 — 사이드바 위젯 키 충돌 정리 필요. (b) `st.set_page_config` 단일 호출
  제약. (c) 캐시 미스 시 페이지 전환마다 재계산 — get_shared_snapshot 캐시로
  흡수되는지 확인.
- 회귀 테스트 영향: **가장 크다.** 소스 문자열 검사가 web_app.py 단일 파일을
  전제하므로, 파일 분리 시 test_pipeline_fixes.py의 대상 파일 경로 자체를
  페이지 파일들로 확장해야 한다. C단계 착수 전에 테스트의 파일 경로 상수를
  목록화하는 선행 작업을 넣는다.

### 단계 공통 금지사항

- final_action_score·게이트·가격 레벨 산식 변경 금지 (계산 로직 불변).
- UI에 필요한 필드가 파이프라인에 없으면 임의 값 생성 금지 — SCREEN_SPECIFICATIONS의
  '필요 데이터 인터페이스'에 정의만 남긴다.
- 미수신·산출 불가 상태를 UI가 감추지 않는다.
- 삭제가 아니라 **단계적으로 숨기기** — 정보는 탭·전문가 격리로 내려보내되 접근
  경로를 끊지 않는다.
