# 라운드 409 — 밸류에이션 탭: 업황 연결은 3주 전에 끊겨 있었다 · 이상치는 적정가에 안 들어갔다

2026-10-01 · model **v2026.10.01.6** (`ui`) · valuation **v2026.10.01.1** (`ui`) · sector **v2026.10.01.3** (`bugfix`)
· 적정가·문턱·판정·산식 **불변**

사용자가 밸류에이션 탭 외부 분석 둘을 붙였다(지시문 없음). 주장마다 코드를 열고 **검토가 본 그 종목을 실제로 돌려**
(`_probe/r409_probe.py` · 기준일 2026-09-30) 참·거짓을 갈랐다.

## 가장 큰 것 — 업황 연결이 모든 종목에서 끊겨 있었다

검토는 *"업종 분류를 받지 못해"* 가 같은 화면의 업종명(반도체와반도체장비)과 모순이라고 짚었다. **맞는 지적이었고
원인은 문장보다 컸다.**

- 업황 연결은 종목코드 → **거래소 업종표(KSIC)** 로 프록시 그룹을 찾는다(`sector_cycle.industry_map`). 그 원천인
  FinanceDataReader `StockListing('KRX-DESC')` 가 **HTTP 404** 다(2026-10-01 실측).
- 로컬 캐시는 **2026-09-11 판 2,759항목**이 마지막이고 유효시간이 7일이라 **09-18 뒤로 매 호출이 빈 표**를 돌려줬다
  — 그날부터 **모든 종목**의 업황 칸이 *"업종 분류를 받지 못해"* 를 적었다(화면이 띄우는 업종명은 다른 출처라 모순으로 보였다).
- 게다가 실패를 기억하지 않아 **종목마다 다시 물었다**(호출당 약 0.1초 · 라운드 303 의 *캐시는 실패도 기억해야 캐시다*).

고침(`sector_cycle` · 표시 전용 축이라 적정가·판정 불변):
- 원천이 답하지 않으면 **마지막으로 받은 판**을 쓴다 — 로컬 사본(유효시간 무시) → 저장소 동봉본(`data/krx_industry_ksic.json`
  · 배포 앱은 `.portfolio/` 가 빈 채 뜬다 · 라운드 331). 업종은 종목의 성질이라 몇 주 사이에 잘 안 바뀐다(라운드 218).
- 그 판을 썼으면 화면이 **판 날짜와 출처**를 적는다(*"업종표 2026-09-11 판(로컬 사본 · 원천이 응답하지 않아 마지막으로
  받은 판)"*).
- 사유를 둘로 가른다 — *업종표를 받지 못함* · *업종표에 이 종목이 없음*(둘 다 "업황 연결에 쓰는 거래소 업종표(KSIC)"라고
  어느 표인지 적는다).
- 실패도 기억한다.

사본이 쓸 만한지 먼저 쟀다: 원장 종목 1,524개 중 **78.5%** 가 사본에 있고 그중 **88.8%** 가 프록시 그룹으로 이어진다.
네이버 업종명을 같은 KSIC 규칙에 넣는 길은 **택하지 않았다** — 61.8% 가 이어지지만 '건강관리장비와용품'이 기계·산업재로
가는 식의 오분류가 섞인다(규칙이 KSIC 업종명용이다). 동봉본은 `scripts/ship_krx_industry.py` 가 로컬 사본에서 만들고
업종명만 담는다(종목명·가격 없음). 검토가 본 종목은 고친 뒤 KSIC '통신 및 방송 장비 제조업' → 반도체 그룹으로 이어진다.

## 받지 않은 것

- **이상치 강제 무효화(ROE 30% 초과 · EPS 200% 급증 → NaN)** — 손으로 고른 문턱이고(§2), 겨냥한 값은 애초에 적정가에
  안 들어간다. 해도 적정가는 한 원도 안 바뀐다.
- **'매출·현금흐름·EBITDA 자료는 입력되지 않습니다' · 고정 보정 문장 숨기기** — 참인 고지를 빼면 이름만 남아 그 자료를
  쓴 것처럼 읽힌다(라운드 239·238 · §9).
- **'잔여이익모델(RIM) 중심'으로 통합 표기** — 이 엔진에 그런 모형이 없다. 없는 이름을 붙이면 지어낸 값이다(§3).
- **'반도체 업황 사이클 현재 중립 국면 (조정치 0.0%)'** — '중립 국면'은 잰 적이 없는 말이다. 대신 실제 원인(원천 404)을 고쳤다.
- **신뢰도 감쇠를 50 쪽으로 바꾸기** — 이 점수는 관점 간 이견(표준편차)에 들어가 매수 결론을 한 단계 낮출 수 있는 값이라
  바꾸면 판정 경로가 움직인다. 전방 평가 동결 중이고 사람의 결정이다(라운드 401 의 B 목록과 같은 자리). 식과 한계는 화면에 적었다.
- **고정 보정 −2% 제거** — 라운드 251·267 이 끄고 켠 두 판으로 쟀다(효과 0 근처 · 구역 9.8% 이동). 지울지는 정책 결정이다.
- **신뢰도를 모델군 수로 다시 설계 · 실제 FCF·EBITDA 연결** — 연구·수집 거리. 오늘은 독립성 문장만 냈다.
- **0.36% 실험을 0.41% 로 다시 집계** — 원 경로로 다시 재야 한다. 그때까지 *"잰 당시 비용입니다 — 지금 운영 비용은 0.41%"*
  를 같은 문장에 적는다(라운드 350).

  가격 기준일 행 · 분류 비중 · 독립성 문장 · 추정 열 문장 · 업종 성적 % · 업종표 판 날짜 · 탭 머리 *"적정가 부근 · 가치 위치 점수
