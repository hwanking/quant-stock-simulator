# 결과 R323~R326 — '0건'이 0이 아니었다 · 가늠 AI 챗봇 창 · 시간외 거래 시간 · 금액으로 본 보유 (2026-09-16)

## R323 — 산출 불가 사유가 거짓 '0건'을 말했다

사용자 화면: *"산출 불가 — 자기유사 예측 … 유효표본 0건 — 확률 산출 기준(10건) 미달"* · *"표본 부족으로 목표·손절
선도달 확률 미산출"* · *"미선정 (자격 요건 통과 지평 없음)"* · *"평균수익 × 승률 × 일치도 / √기간"* · *"… 그대"*.

| 무엇 | 실제 | 고침 |
|---|---|---|
| **'0건'** | 20일 유사패턴이 **1~4건**이면 엔진이 `_empty_blind_result` 로 `match_count` 를 **0 으로 박는다.** 그 0 을 화면·가늠 AI 카드·거부권 문장·R295 의 *"닮은 자리를 하나도 못 찾았다"* 가 **관측 건수로 읽었다**(§3 의 지어낸 0) | 관측 건수를 `observed_match_count` 로 **따로** 싣고 말하는 자리는 그것을 읽는다. `match_count`(유효 거래 수 계산이 읽는 0)는 **그대로** |
| 문턱 | 5건 미만(관찰값조차 안 냄)과 5~9건(관찰값만)을 한 말 *"(10건) 미달"* 로 | 규칙집 `SAMPLE_TIERS` 에서 읽어 두 경우를 가른다 |
| 대응 시나리오 | *"표본 부족"* 만 — 몇 건이고 몇 건이 필요한지 없음 | *"20일 유사패턴 N건 — 먼저 닿는 쪽의 확률은 10건부터"* |
| 산식 캡션 | *평균수익 × 승률 × 일치도 / √기간* — **엔진과 다르다**(승률 항 없음 · 비용 차감·표본 신뢰·선도달비 빠짐) | 엔진 식 그대로: *(비용 차감 평균수익 × 표본 신뢰 × 기간 간 일치도 × 목표/손절 선도달비) ÷ √기간* |
| 미선정 | 값 칸 한 줄이 좁으면 …로 잘리고 무엇이 모자라는지 안 말함 | 값은 *미선정*, 부제에 세 자격(비용 차감 수익 · 유효표본 · 목표 선도달 우세) |
| '그대' | 타일 카드가 **숨긴 가로 스크롤**이라 오른쪽이 가려졌다 | 폭이 모자라면 다음 줄로 흘린다 |
| 경로 그래프 지평 | 5~120일 전부 · 기본 40일 우선 | **판정 창(20봉)의 절반~세 배**(10·20·40·60)만 · 엔진이 낸 지평에서 거른다 · 뺀 지평은 사유와 함께 적고 표본 수는 위 표에 그대로 · 기본은 엔진이 고른 기간 → 판정 창 |

**산출 불가를 '산출되게' 하지는 않았다.** 확률 문턱(10건)과 rho 기준(0.80)을 낮추면 그것이 §2 다. 대신 *왜* ·
*몇 건* · *몇 건부터* 를 말하고, 이미 있는 대안(계층 보정 확률 · 같은 자리 원장 분포 · 사이드바 rho)을 가리킨다.
계산부 문장·표시 칸만 바꿨으므로 model **v2026.09.15.5 → v2026.09.16.1**(`kind='ui'`).

## R324 — 가늠 AI 를 챗봇 창으로

사용자: *"가늠 AI는 자연스럽게 내가 물어보면 챗으로 · 물어보기 위치를 맨 위로 · 오른쪽 아래 가늠 AI는 챗봇처럼."*

- 종전: 알약을 누르면 **입력바만** 올라오고 답은 페이지 한가운데 대화 구역에 쌓였다 — 묻는 자리와 답의 자리가 화면
  몇 장 떨어져 있었다.
- 고침: 대화·추천 질문을 한 그릇(`gn_ask_panel`)에 담고, 열리면 그 그릇이 **입력바 바로 위 창**으로 뜬다(말풍선 →
  추천 질문 → 입력) · 창 안을 누르면 안 닫힌다 · 새 말이 오면 맨 아래로 · 빈 창에는 안내 말풍선.
- **맨 위로** — 대화 구역 자체는 답의 재료(판단 근거·뉴스·계층 보정)가 계산된 **뒤**에만 설 수 있어 통째로 옮기면
  재료가 비거나 계산이 두 번 된다(§4). 대신 종목 화면 **맨 위**에 챗봇 창을 여는 길을 뒀다.
- **자연스럽게** — 인사·감사에 답하고, 못 알아들은 질문에는 거절 문구(값을 지어내지 않는다) 뒤에 **오늘의 결론**
  (중앙 판정 문장 그대로)을 잇는다. 외부 LLM 은 여전히 없다(§9 — 평단이 필요한 질문이 있어 외부 전송과 양립 불가 ·
  붙이려면 사람의 결정).

## R325 — 시간외 거래 시간 ("장도 이제 8시로 바뀐다면서")

확인한 사실(보도 두 건 원문 대조 · 2026-09-14 이투데이 · 2026-09-16 ESG경제):

| | 시간 | 상태 |
|---|---|---|
| KRX 정규장 | 09:00~15:30 | **변경 없음** · 공식 종가·지수는 정규장 마감 기준 |
| KRX 장후 종가매매 | 15:40~16:00 | 시행 |
| KRX 애프터마켓(연속매매) | **16:00~20:00** | **2026-09-14 시행** · 종전 16:00~18:00 10분 단일가 폐지 |
| KRX 프리마켓 07:00 | — | **2027년 말로 연기** |
| 넥스트레이드 프리마켓 | **08:00~08:50** | 기존 운영 — *"8시"* 는 이것이다 |

- **KRX 가 8시에 연다는 것은 확인되지 않았다**(§3 — 확인 안 된 것을 적지 않는다).
- 우리 현재가(`basic.closePrice`)는 **15:30 정규장 종가**다 — 8종목의 일봉 종가와 전부 일치(2026-09-16 20:20 조회) ·
  시간외 가격은 `overMarketPriceInfo` 로 따로 온다(한 종목은 달랐다). → **값·판정·원장 채점은 안 바뀐다.**
- 바뀐 것은 말뿐이다 — 16:00~20:00 에도 거래가 되는데 화면은 '장 종료'로만 적었다. 사이드바와 종목 머리에
  *"KRX 시간외 거래 중(16:00~20:00) — 화면 가격·판정은 15:30 정규장 종가 기준"* 을 붙인다(시각은 한 곳 · 날짜와 함께).
- 곁들여: 2026 증권거래세 인상(0.15→0.20%)은 `COST_PCT` 결정 재료로 연구 조사 문서(2026-09-16)에 올라가 있다(사람이 정한다).

## R326 — 금액으로 본 보유 (1단계)

사용자: *"포트폴리오를 보고 보유할지 말지 줄일지도 · 전체 금액을 보고도 판단해서 추천."* 1단계는 **사실만** — 종목마다
지금 할 일 · 비중 · 평가금액 · 평가손익 · 수익률 · 전체 손익 중 몫을 한 표에, *손댈 수 있는 순 → 금액 큰 순*으로.
추천(몇 %면 줄인다)은 **아직 안 한다** — 계획: `docs/PLAN_R326_PORTFOLIO_SIZING.md`.
