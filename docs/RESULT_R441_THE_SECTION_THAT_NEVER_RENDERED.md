## ② 제거 예고 API — 글자 락이 별칭 호출 둘을 못 봤다

렌더 로그마다 *"Please replace `st.components.v1.html` with `st.iframe` — will be removed"* 가 찍혔다. 회귀 §92 ⑧ 은
`'st.components.v1.html(' not in 소스` 라는 **글자 락**(R98b)이라 `import streamlit.components.v1 as _x` 뒤 `_x.html(…)`
두 자리(저장 확정 스크립트 R390 · 가늠 AI 버튼 스크립트 R324)를 못 봤다. 차트는 2026-08-03(`9f76be9`)부터 이미 `st.iframe` 이었다.
배포 requirements 는 `streamlit>=1.40` 으로 위가 열려 있어(설치 1.60 · 클라우드 1.61) 제거가 실린 판이 나오면 재빌드
때 그 두 스크립트가 죽는 자리였다.

- 둘을 `st.iframe` 으로. ⚠️ **높이 0 은 못 쓴다** — `validate_height` 가 0 이하를 예외로 던지고 그 예외를 바로 그
  `try` 가 삼켜 **스크립트가 조용히 안 붙는** 이 라운드의 그 모양이 된다. 1px 로(부모 문서에 붙이는 스크립트라 보이는
  것이 없다).
- §92 ⑧ 을 AST 로 — 별칭(`import … as`) · 직접 체인 · `from … import html` 세 모양을 유도해 호출 0 을 잠그고 심어서
  양방향으로 본다 · `st.iframe` 자리 셋 이상. `declare_component` 는 다른 API 라 세지 않는다.
- 브라우저 실측: 버튼 스크립트가 부모 문서에 붙었다(`gnBound=1`) · 1px iframe 1 · 차트 iframe 880px · 서버 로그에 그
  경고 0. ⚠️ 저장 확정 스크립트는 목록 편집기를 켜야 그려지는데 브라우저 창은 사용자와 같이 쓰므로(R320) **눌러 보지
  않았다** — 같은 API·같은 모양이라 적고, 확인은 못 했다고 적는다.
- `streamlit` 의 위 경계를 고정할지는 사람이 정한다 — 2026-08-05 의 starlette 사고(requirements 의 주석 · 열어 둔
  의존성이 재빌드 때 앱을 죽였다)와 같은 성격이고, 지금은 `>=1.40` 으로 열어 둔 채다.
