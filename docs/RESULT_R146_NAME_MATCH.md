## 1. 왜 재나

공시 목록(DART 전체공시)에는 종목코드가 없고 **회사명뿐**이다(R139).
이벤트 연구(R124 §3.2)는 공시를 종목·날짜에 붙여야 시작되므로, 이
매칭이 몇 %나 되고 어디서 틀리는지를 **먼저** 재야 한다 — 수급
연구(R131)에서 조인 커버리지 96.7%를 먼저 밝히고 시작한 것과 같은
순서다.

## 2. 잣대 (측정 전에 적은 것)

1. 매칭은 두 단계만 — **정확 일치**, **정규화 일치**(공백·㈜·주식회사
   제거, 영문 대문자화). 유사도(편집거리) 매칭은 **안 쓴다** — 동명
   오염이 조용히 늘어나는 길이다.
2. 주 잣대는 **원장 방향** — 원장 유니버스 중 이름이 붙는 비율.
   공시 전체 매칭률은 참고다: DART 에는 비상장·SPC·대부업체 공시가
   섞여 있어 100% 일 이유가 없다.
3. **연도별로 가른다** (R145 §9 — 크기를 말할 때는 표본의 끝을 먼저).
4. 충돌(한 이름 → 복수 코드)은 **해소하지 않고 적는다** — 임의 해소
   규칙은 §2(숫자를 손으로 고르지 않는다)의 이름판이다.

## 3. 결과

### 주 잣대 — 원장 방향은 사실상 완전하다

| | 값 |
|---|---:|
| 원장 유니버스 | 1,500 = **주식 1,190 + ETF 310** |
| 주식 중 현재 이름이 붙는 것 | 1,189 (**99.9%**) |
| 상폐 이름까지 | 1,190 (**100.0%**) |

처음에는 "1,500 중 79.3%"로 보였다 — 안 붙는 310개를 뜯으니 **전부
(100.0%) ETF** 였다. ETF 는 DART 공시의 발행 주체가 아니므로(운용사가
공시한다) 이벤트 연구 대상이 아예 아니다. **분모를 갈라야 참값이
보인다** — 백필 때 "남은 92.6%가 ETF"(§장부)와 같은 모양이다.

### 공시 방향 — 건수의 58.3%가 붙고, 연도 내내 안정

공시 **2,249,225건 · 고유 회사명 75,616개** (2026-08-21 기준).

| 잣대 | 정확 | 정규화 |
|---|---:|---:|
| 고유명 기준 | 4.4% | 4.4% |
| **건수 기준** | 58.2% | **58.3%** |

고유명 4.4%는 착시다 — 고유명의 대부분은 한두 번 공시하고 마는
비상장·SPC·조합이다. 건수로 보면 58.3%이고, **원장 종목의 공시만
30.0~32.6%**(연도별)다. 이벤트 표본은 연 4~5만 건 수준 — 충분하다.

연도별 정규화 매칭(온전한 해): **56.8% ~ 60.2%** (최저 2013).
**옛 구간이 무너지지 않는다** — 사명 변경 우려는 상폐 목록(4,176행)이
옛 이름을 대 줘서 작다. 원장 교집합도 30.0~32.6%로 평평하다.

### 충돌 — 42개 이름

정규화 후 한 이름이 복수 코드로 가는 이름이 **42개**다. 해소하지
않았고 산출물에 목록을 남겼다 — 이벤트 사전등록에서 이 이름들을
**제외**하면 된다(건수 영향은 미미하다).

## 4. 이벤트 연구에 주는 것

- **조인 규칙이 확정됐다**: 정규화 정확 일치만 · 충돌 42개 이름 제외 ·
  ETF 제외. 유사도 매칭 금지.
- 이름 마스터는 스냅샷으로 박제 — 재현 가능.
- 연 30% 안팎의 원장 교집합이 15년 내내 평평하므로, 조인 커버리지가
  구간 비교를 왜곡할 걱정은 작다.

## 5. 하지 않은 것

- 유사도 매칭 (동명 오염)
- 충돌의 임의 해소 (보통주 우선 같은 규칙 발명)
- 운영 코드에 매칭 탑재 — 이건 연구 재료다. 사전등록이 확정한 뒤에만
  들어간다.
