# 퀀트 시스템 전체 지도 — 모든 분석 요소와 판정 흐름

> 이 문서는 화면에 뜨는 모든 점수·게이트·가격 레벨이 **무엇을 의미하고, 어떤
> 데이터에서 나오며, 최종 매수·관망·매도 판단에 어떻게 연결되는지**를 한 곳에
> 정리한 단일 지도다. 산식의 수치는 전부 `analysis_rulebook_ko.txt` 가 단일
> 출처이며, 이 문서는 그 구조를 설명한다.
> (판정 성적 수치는 `.portfolio/calibration.json` 이 최신본이다 — 이 문서의
> 예시 수치는 2026-08-01 리플레이 327건 기준)

## 0. 한 장 요약 — 점수는 이렇게 만들어진다

```
원천 데이터 (네이버 시세·게시 재무 / 다음 교차검증 / 야후 글로벌 / DART RSS)
   │
   ├─ ① 종목 기본 매력도 (35%) ── 펀더멘털·밸류에이션·재무안전·산업·장기구조
   ├─ ② 현재 매매 적합도 (45%) ── 과거패턴·경로기대·DeMARK·기술구조·수급·시장국면·확률우위·가격위치
   └─ ③ 리스크 안전성   (20%) ── 손익비·변동성·재무위험·이벤트·유동성·뉴스위험
   │
   ▼  가중합 (원점수)
   │
   ▼  신뢰도 축소 (분석 신뢰도·표본에 비례해 50점 방향으로 수축)
   │
   ▼  게이트 상한 min(...) — 아래 §5 의 상한들 중 가장 낮은 값이 이긴다
   │
   ▼  최종 행동점수 (final_action_score, 0~100 단일 정본)
   │
   ▼  하드 정합성 검사(§18) → 위반 시 '판정 보류 (데이터 정합성)'
   ▼  소프트 이견 화해 → 매수의도인데 조건 미충족이면 '관망' 하향
   │
   ▼  행동 판정: ≥85 적극분할매수 / ≥75 분할매수 / ≥68 제한적 진입
                / ≥58 조건확인·관망 / ≥48 신규매수보류 / ≥35 비중축소 / <35 거래회피
```

## 1. 원천 데이터 — 무엇을 쓰고, 무엇을 안 쓰나

| 데이터 | 출처 | 용도 | 한계(정직 표기) |
|---|---|---|---|
| 일봉 OHLCV | 네이버 금융 시세 파싱 | 모든 기술 지표·백테스트 | 정지봉(o=h=l=0) 제거, 원시가는 `*_raw` |
| 현재가 | 네이버(기준) + 다음(교차검증) | 표시·검증 | 1% 이상 벌어지면 분석 차단(교차검증 게이트) |
| 게시 재무 (PER·PBR·EPS·BPS·ROE·부채비율) | 네이버 종목페이지 게시값 | 적정가·재무안전 | 공시 원문 대조 미연동 — 게시값 신뢰 한계 명시 |
| 배당 | 네이버 게시 DPS | 배당 카드 | 배당락일은 관례 추정으로 표기 |
| 지수(코스피·코스닥) | 네이버 fchart 일봉 | 시장 국면·상대 모멘텀 | — |
| 글로벌 (S&P500·나스닥·VIX·원/달러) | Yahoo Finance 일봉 | 글로벌 위험 점수 | — |
| 종목 뉴스 | 네이버 종목뉴스 API (제목·언론사·시각·연관묶음) | 위험 낱말 감점만 | 기사 해석 안 함 — 낱말 일치만 |
| 공시 | DART RSS 최근 50건 | 관심종목 촉매 | 회사명 매칭 한계 명시 |
| 수급 (외국인·기관) | 네이버 투자자별 | 수급 점수 | 미수신 시 NaN (0 채움 금지) |
| **안 쓰는 것** | 증권사 컨센서스·리서치·IR 원문 | — | 미연동 — 흉내 내지 않고 '미연동' 표기 |

원칙: **수집하지 못한 값은 만들지 않는다.** 미수신 항목은 가중치 0으로 두고
나머지 항목으로 재정규화하거나, '산출 불가/표본 부족'으로 표기한다.

## 2. 세 기둥 점수 (원점수 가중합)

### ① 종목 기본 매력도 (35%)
- 펀더멘털 30% (ROE·EPS 성장 계열), 밸류에이션 25% (PER·PBR 상대수준),
  재무안전 20% (부채비율), 산업경쟁력 15%, 중장기 구조 10%
- ETF(펀드)는 이 축의 밸류에이션 요소가 성립하지 않아 **비적용** 처리

### ② 현재 매매 적합도 (45%) — 내부 9개 항목
| 항목 | 비중 | 의미 · 데이터 |
|---|---|---|
| 과거 유사패턴 | 22% | 자기유사 구간의 이후 성과 (Z-정규화 + Pearson 0.7 / DTW 0.3) |
| 경로 기대값 | 16% | 유사경로의 20일 기대수익 분포 |
| DeMARK 결합 | 14% | 9-13 셋업·카운트다운 + 볼린저·RSI·W%R 확인 |
| 기술 구조 | 13% | 이동평균 배열·볼린저 위치·지지/저항 |
| 수급·거래량 | 11% | 외국인·기관 5/20일 누적 + 거래대금 |
| **시장 국면** | 8% | 상장시장 지수 국면 60% + 글로벌 위험 40% 합성 |
| 확률 우위 | 7% | 관찰 승률의 유효표본 비례 신뢰 (ESS) |
| 가격 위치 | 5% | 적정가 대비 진입 구간 |
| 이벤트 타이밍 | 4% | (보수적 중립) |
- 시장 국면·글로벌: 미수신이면 항목 제외 후 재정규화 (중립 50점 금지)
- 글로벌 감점표: S&P500 60일선 이탈 −12, 나스닥 고점대비 −10%↓ −15,
  VIX 25↑ −10 / 35↑ −25, 원/달러 20일 +3%↑ −10

### ③ 리스크 안전성 (20%)
손익비 27% · 변동성 22% · 재무위험 18% · 이벤트 13% · 유동성 8% ·
**뉴스 위험 12%** (제목 위험낱말 1건당 −25, 하한 25 — 가점 없음)

## 3. 실행 가격 레벨 — 진입가·목표가·손절가

리플레이 진단(목표/손절 비율 2.0 → 이론 선도달확률 33%)으로 재설계됨:

| 레벨 | 산식 | 의미 |
|---|---|---|
| 권장 매수가 | 적정가 × (1−안전마진 15~25%) | **신규 진입 기준** (신뢰도 미달 시 미산출) |
| 손절가 | 현재가 − max(3%, 2.0σ20) · TDST 지지 0.5~1.5R 내면 그 지지선 | 변동성 바닥 — 노이즈 손절 방지 |
| 1차 목표 | min(손절거리×0.7, 최근접 저항) · 0.8σ 하한 | **1차 분할익절** (무추세 이론 P≈59%) |
| 2차 목표 | 최근접 구조 저항 (1R~3R 제한) | 구조적 목표 — 손익비는 이 레벨 기준 |
| 비중 제안 | 목표 연변동성 20% ÷ 실현 연변동성 (10~100%) | Moreira–Muir 변동성 관리 · 레버리지/인버스는 ×0.5 |

## 4. 자산 유형별 차등 (기계적 동일 적용 금지)

| 유형 | 판별 | 다르게 적용되는 것 |
|---|---|---|
| STOCK | 기본 | 전체 게이트 |
| ETF | 이름 기반 (ETF·ETN·커버드콜 등) | 적정가 계열 게이트 **비적용** (기술·추세 기준) |
| ETF_LEV | '레버리지'·'2X' | + 상한 67점 (일일 재조정 복리손실) + 비중 ×0.5 |
| ETF_INV | '인버스' | + 상한 67점 + 상대 모멘텀 게이트 비적용(역방향이 정상) + 비중 ×0.5 |
| 신규상장/표본부족 | 봉 수·유효표본 | 확률·표본 게이트가 자동으로 '산출 불가' 처리 |

## 6. 판정 보류 vs 화해 — 이견 처리 원칙

- **하드(판정 보류)**: 산술 불변식 위반만 — 확률 노출 불일치, 상승여력 부호 오류,
  시세 교차검증 실패. "데이터 정합성 문제" 로 표기.
- **소프트(화해)**: 신호 간 이견은 확신 하향 — 매수의도인데 진입가 밖/약세 우세/
  다중기간 충돌이면 '조건 확인·관망' 으로 내리고 사유를 남긴다 (Bates–Granger,
  Timmermann 예측결합 원칙). 관점 간 표준편차 ≥20이면 BUY 도 소액분할로 하향.

## 7. 자기 검증 3중 루프

| 루프 | 무엇 | 되먹임 |
|---|---|---|
| 표본외 Walk-Forward | purge+embargo, Brier/MAE/Sharpe/MDD | 전략 품질 상한(sq_cap) |
| **가상 백테스트 리플레이** | 실제 엔진을 과거 기준일로 (오늘 데이터 차단) | 점수대 적중률 표시 + 상한 / 기하·게이트 재설계 근거 |
| 실전 판정 성적표 | 화면에 내보낸 판정의 실제 결과 | 적중률<45% 시 자기보정 상한 |

리플레이 무결성: 기준일이 5일 초과 과거면 오늘의 시세·지수·뉴스·상대모멘텀을
전부 차단하고 가격 시계열을 기준일에서 절단한다 (§54 회귀로 잠금).

케이스 원장(`.portfolio/virtual_graded.jsonl`)에는 사례별로 종목·유형·기준일·
당시 국면·점수·판정·진입/목표/손절가·이후 경로(MFE/MAE)·선도달 결과·수익률·
성공/실패·실패 분류(노이즈 손절/방향 오판/미도달)가 기록된다.

## 8. 한 종목을 열었을 때 화면이 답하는 순서

1. 데이터 정상? → 교차검증 게이트·출처 매트릭스
2. 표본 충분? → 유효표본·ESS·티어
3. 시장 국면? → 컨텍스트 패널 (국내+글로벌+뉴스)
4. 추세? → 월봉 10선·이동평균·DeMARK
5. 요소별 점수·근거 → 산식표 + 관점별 독립 판정
6. 거부 조건 → ⛔ 박스
7. 가중합→상한 과정 → "이 점수는 이렇게 나왔습니다"
8. 최종 종합점수 (단일 정본)
9. 행동 판정 (사/말어 배너)
10~12. 권장 매수가·1차/2차 목표·손절가 (+예상 보유기간 20일 지평)
13. 기대수익·손익비
14. 유사 사례 수·관찰 성과 + 이 점수대의 리플레이 적중률
15. 신뢰도·한계 (미연동·추정 표기)

## 9. 알려진 한계 (감추지 않는 것)

- 게시 재무는 이력이 없어 리플레이의 가치평가 순도에 한계 (calibration.json note 에 명시)
- 뉴스는 제목 낱말 일치만 — 내용 해석·호재 반영 없음 (의도된 설계)
- 컨센서스·공시 원문 미연동 — Zacks 류 이익수정 모멘텀은 구현하지 않음
- 리플레이 표본은 2025~2026 국면 편중 — 국면별 성과를 분리 보고하는 이유
- 적중률 70%는 보장값이 아니라 검증 목표 — 최신 실측은 calibration.json 이 정본
