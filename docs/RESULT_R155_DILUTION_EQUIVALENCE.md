# R155 — "증자 한 건 ≈ 다른 것 두 건": 점추정은 거의 정확히 0, 그러나 동등성은 증명 못 한다 (2026-08-22)

**한 줄**: 짝지어 재니 **중앙값 차이가 −0.006%p** 로 거의 정확히 0이고
차이도 안 보인다(D1 z −0.06). 그러나 **동등성 검정은 통과하지

보인다.**

## 1. 왜 보통 검정으로는 안 되나

R154 §3 은 네 집단의 위치를 보고 *"증자 한 건 ≈ 다른 것 두 건"* 을
읽었지만 **판정하지 않았다.** 그 문장은 **동등성 주장**이고,
*"차이가 유의하지 않다"* 는 **"같다"가 아니라 "다르다고 말할 근거가
없다"** 이기 때문이다. 그 둘을 섞는 것이 R113 에서 이미 고쳐 쓴
실수다.

그래서 **TOST**(두 개의 단측 검정)로 **적극적으로** 물었다 —
차이가 미리 정한 마진 안에 들어오는지.

**마진은 손으로 고르지 않았다.** R154 가 이미 발표한 **k=1·증자X
중앙값 −0.170%p** 의 절댓값을 썼다 — 뜻은 **"공시 한 건어치"**.
즉 *"두 값의 차이가 공시 한 건어치보다 작은가"* 를 물었다.
문턱도 R153·R154 의 **z 2.25** 를 그대로 재사용했다(새 숫자 없음).

## 3. 판정 — 못 가린다

짝 날짜 **1,006일** · k≥2·증자X 이벤트 **1,660건** (표본 조건 통과).
C(D) = Δ(증자 한 건) − Δ(증자 아닌 것 둘 이상).

| | 값 |
|---|---:|
| C 중앙값 | **−0.006%p** |
| C 평균 | +0.042%p |
| 승률 | 49.9% (필요 53.5%) |
| **D1** 양측 부호검정 | **z −0.06** → 차이 못 봄 |
| **E1** TOST 아래(C > −0.17) | 516/1,006 → **z 0.82** |
| **E1** TOST 위(C < +0.17) | 518/1,006 → **z 0.95** |

**판정: "못 가린다"** — 사전등록 §6 의 네 갈래 중 *D1 미달 + E1 미달*
칸이다. **차이도 동등성도 못 보였다.** blind 는 열지 않았다(둘 중
하나라도 통과해야 연다).

## 4. 그래도 말할 수 있는 것 — 점추정은 거의 정확히 0이다

중앙값 차이 **−0.006%p** 는 마진(0.170%p)의 **3.5%** 다. 두 집단은
**관측된 범위에서 사실상 같은 자리에 있다.** 다만 그것은 **점추정**
이고, 하루하루의 흔들림이 커서 **"같다"를 통계적으로 세울 수는
없다.**

이 구분을 흐리지 않는 것이 이 문서의 목적이다:

> **보이는 것**: 증자 한 건과 증자 아닌 것 둘 이상은 거의 같은
> 크기로 나쁘다(중앙 차이 0.006%p).
> **세울 수 있는 것**: 없다. 이 표본으로는 "같다"도 "다르다"도
> 증명하지 못한다.

## 5. 사후 진단 — 얼마나 더 있어야 하나 (판정에 쓰지 않는다)

"못 가린다"로 끝내면 **얼마나 못 가리는지**를 안 적는 것이다.
관측 비율이 그대로일 때 z 2.25 에 닿는 날짜 수를 역산했다.

| | 관측 | 필요 날짜 |
|---|---|---:|
| 아래 단측 | 516/1,006 (51.3%) | **7,580일** |
| 위 단측 | 518/1,006 (51.5%) | **5,693일** |
| 지금 | | 1,006일 |
| **물리 상한** | 246일/년 × 14.9년 | **3,665일** |

→ **상한 밖이다.** 이 마진(공시 한 건어치)에서는 **한국 시장의 모든
거래일을 다 모아도 동등성을 세울 수 없다.** R129 가 순위 연구에서
만났던 것과 같은 벽이다 — 표본을 늘리는 것이 답이 아닌 자리.

**마진을 넓히면 통과하겠지만 하지 않는다.** 결과를 본 뒤 마진을 바꾸는
것은 사전등록을 무의미하게 만든다. 다시 물으려면 **다른 마진을 근거와
함께 미리 정한 새 사전등록**이 필요하고, 그 근거는 이번 결과가 될 수
없다.

## 7. 이 결과가 바꾸는 것과 바꾸지 않는 것

**바꾸지 않는다**: R153·R154 의 결론은 그대로다 — 겹침은 증폭하고,
그 증폭은 희석 때문이 아니다. 이번 라운드는 **두 집단의 크기 비교**만
물었다.

**바꾼다**: R154 §3 의 *"증자 한 건 ≈ 다른 것 두 건"* 을 앞으로
**주장으로 쓰지 않는다.** 정확한 문장은 —
**"점추정은 거의 같지만, 같다고 세울 수는 없다(그리고 이 마진에서는
앞으로도 못 세운다)."**

**여전히**: 매수 우위는 R148·R149·R150·R151·R153·R154·R155 통틀어
**0개**다. 운영 반영 없음 · R55/R57/R66 동결(~2026-11-16) 미접촉 ·
현재 시총 미사용 · 원장 미조인 · mfe/mae 미사용 · 인과 주장 없음.
