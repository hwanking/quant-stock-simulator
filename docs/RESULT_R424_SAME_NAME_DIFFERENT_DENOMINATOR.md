### 1b. 재다가 나온 것 — "괴리의 상당 부분이 국면 조성" 은 넘친 말이었다

## 6. 재다가 나온 것 둘째 — 계층 실측 표가 한 번도 안 그려지고 있었다

종목 화면의 *"더 넓은 계층의 실측 — 같은 조건이었던 과거"* 와 *"이 종목 과거 신호 실체"* 펼침이
**SELF 층이 있는 종목에서는 통째로 빠졌다.** SELF 층(라운드 61)은 EV 가 None 인데 행 포맷이
`{r['ev']:+.2f}` 라 TypeError 가 났고, 블록 끝의 `except Exception: pass` 가 사유 없이 삼켰다. 전방 기록부
64종목 전부 SELF 가 있어 **64/64 실패**(SELF 를 가진 종목 577 · 2026-10-03 · `_probe/r423_layers_self.py`).
EV 가 없는 층은 EV 칸 없이 그리고, 블록이 실패하면 stderr 에 트레이스백을 남긴다. 값은 안 지어냈다.

## 7. 살펴보고 안 고친 것

- **케이스 스터디 필터**의 '성공(목표 선도달) N%' 는 전체 사례 중 비율이고 '미도달(만기)' 를 따로 거른다 —
  세 갈래 나눔이라 적중률이 아니다. 그대로 둔다.
- **화면 도달 모듈 53개**의 코드 줄에서 원장 `success` 칸을 적중으로 세는 자리는 고친 뒤 0 이다(남은 것은
  채점 여부를 거르는 `.notna()` 와 추적 집계의 칸 이름 — 다른 원장). §420 이 유도해서 잠근다.
- 실시간 산출물 생성기(취약구간 지도 · 놓침 연구 · 업종 성적 · 전날 미국장 · 계층 표)는 이미 미결을 뺀다.
- 고정 국면 표·R159 의 **셈**은 안 고쳤다(위 3 · 게이트와 판정한 날의 기록).
- 원장의 `success` 칸 자체도 안 바꿨다 — 모든 소비자의 값이 움직이고(R197 · 파생물을 다시 쓰는 일) 고정 표의
  재현이 깨진다. 읽는 쪽이 한 규칙을 부른다.

## 8. 규칙으로 남기는 것

- **원장을 직접 셀 때 적중의 분모는 판정 완료다** — `ledger_view.decided_hit` 를 부른다. `success` 칸은
  미결도 False 다.
- **같은 이름의 수가 둘이면 단위를 이름 옆에** (R233) — 이번엔 단위가 *분모*(미결 포함 여부)·*띠*(점수대
  경계)·*비용*(0.30·0.36·0.41·0.55)이었다.
- **단정은 재고 나서 쓴다** — '정체가 국면 조성' 은 재 보니 몫이 0.8%p 였다. 화면이 몫을 그 자리에서 센다.
- **`except: pass` 는 사유를 남긴다** — 표 하나가 두 달 가까이 아무 말 없이 빠져 있었다.
