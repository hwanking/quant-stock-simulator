# 사전등록 R153 — 겹침(Event Confluence): 여러 공시가 같은 날 나면 반응이 더 큰가

**등록일 2026-08-22. 이 문서는 측정 전에 커밋된다 — 커밋 해시가 증거다.**

## 0. 왜 이제 여는가 — R124 §4 가 건 조건이 채워졌다

R124 §4 는 겹침 연구를 **마지막**으로 미루며 두 조건을 걸었다.

1. *"개별 이벤트가 각각 측정된 뒤에만 의미가 있다."*
   → **채워졌다.** R148(순수 창) · R149(기준선 대비) · R150(매칭) ·
   R151(원장)에서 7유형을 각각 쟀다.
2. *"개별이 전부 귀무인데 겹침만 유의하면 다중검정의 산물일 가능성이
   높다."*
   → **개별이 귀무가 아니다.** 순수 창에서는 6/7 유형이 매칭 뒤에도
   음으로 유의했다(z −3.42 ~ −10.37). 다만 **원장에서는 귀무였다**
   (R147·R151). 그래서 **venue 를 갈라서** 다룬다(§2).

**질문**: 같은 종목·같은 거래일에 서로 다른 유형의 공시가 **둘 이상**
나면, 하나만 난 날보다 반응이 **더 큰가**.

## 1. 표본 — 이미 확인했다 (측정 전에 적는다)

종목·거래일 조합의 동시 유형 수(전 구간, 2014-05-30~):

| k (동시 유형 수) | 건수 |
|---:|---:|
| 1 | 80,937 |
| 2 | 3,650 |
| 3 | 223 |
| 4 | 18 |
| 5 | 1 |
| **k≥2 합계** | **3,892 (4.6%)** |

개발 구간(D0 ≤ 2026-01-30): **k≥2 3,601건 · 1,770일** ·
k=1 75,012건 · 2,865일. 채택 문턱(1,000건·300일)을 넘는다.

## 2. venue 와 시험 (측정 전에 고정)

**주 venue 는 순수 창이다** — 개별 효과가 실재하는 자리이기 때문이다.
원장은 개별이 귀무이므로 R124 §4 의 경고가 그대로 적용된다 →
**기술 통계로만** 낸다(§5).

창·매칭은 **R150 과 한 글자도 같다**: 진입 D+1 시가 → 청산 D+5 종가,
시장(KS11/KQ11) 초과, 비용 미차감(차분에서 상쇄), 층 = (시장,
거래대금 5분위, 변동성 5분위), 분위는 그날 횡단면 순위, 매칭 변수는
D0 포함 직전 20거래일.

날짜 D 에서
- Δ₂(D) = 층별 (k≥2 이벤트 평균 − 대조 평균) 을 이벤트 수로 가중평균
- Δ₁(D) = 층별 (k=1 이벤트 평균 − 대조 평균) 을 같은 방식으로
- 대조 = 그날 7유형 **어느 공시도 없는** 종목 (R149·R150 과 동일)

| # | 시험 | 무엇을 묻나 |
|---|---|---|
| **T1** | Δ₂(D) 의 부호검정 | 겹친 날은 보통 날과 다른가 |
| **T2** | (Δ₂ − Δ₁)(D) 의 부호검정 (둘 다 있는 날) | **겹침이 하나보다 큰가 — 이것이 본 질문** |

k 는 **7유형 전부**로 센다(선택 없음). 6유형(IR·안내 제외)으로
세는 것은 §5 민감도이며 **판정에 쓰지 않는다.**

## 3. 조합별 시험은 하지 않는다 — 그 비용을 미리 적는다

R124 §4 는 *"겹침을 열 때는 조합 수만큼 다중검정 보정을 올린다. 그
비용을 미리 적어 두고 시작한다"* 고 했다. 계산해 보면 **조합별 시험은
애초에 불가능하다.**

- 7유형의 2중 조합은 **21가지**. Bonferroni 21 · 양측 α=0.05/21 →
  z = 3.037 → **올림 3.04**
- 그런데 **가장 흔한 조합조차 975건**(증자·CB·BW + 투자·설비)으로
  표본 조건 1,000건을 **못 넘는다.** 2위 이하는 548 · 375 · 277 …

→ 그래서 **조합이 아니라 개수 k 로** 묻는다. 시험은 T1·T2 **둘뿐**
이고 보정도 둘만 한다. 조합별로 훑어 유의한 칸을 찾는 짓은 하지
않는다 — 표본이 못 받치고, 그것이 R124 가 경계한 바로 그 행위다.

## 4. 판정 기준 (측정 전에 고정 — 측정 후 내리지 않는다)

| 기준 | 값 |
|---|---|
| 시험 수 | 2 (T1, T2) |
| 문턱 | Bonferroni 2 · 양측 α=0.05/2 → z=2.2414 → **올림 2.25** |
| 방향 | 양측 |
| 표본 조건 | 시험별 k≥2 이벤트 **≥ 1,000** 그리고 유효 날짜 **≥ 300** |
| 구간 | 개발 D0 ≤ 2026-01-30 · blind 2026-02-03~07-15 (문턱 통과분만) |
| 미달 시 | 기각. 창·k 정의·유형 집합을 바꿔 재시도하려면 새 사전등록 |

**해석을 미리 적는다.**

| T2 결과 | 뜻 |
|---|---|
| 음으로 유의 | **겹침이 증폭한다** — 여럿이 겹치면 하나보다 더 못하다 |
| 미달 | 겹침에 **추가 정보가 없다** — 개별의 합 이상이 아니다 |
| 양으로 유의 | 겹침이 오히려 **완화한다** — 발견으로 적되 규칙으로 쓰지 않는다 |

**어느 쪽이든 운영에 넣지 않는다**(§6). R151 이 보였듯 순수 창의
사실은 이 엔진의 진입에 닿지 않는다.

## 5. 자기검사와 민감도

**자기검사(통과 조건)**: 이 스크립트를 **단일 유형(자사주·배당)** 으로
돌리면 R150 의 매칭 결과 **Δ 평균 +0.048%p · z −3.42** 를 재현해야
한다. 허용 오차 Δ **0.001%p** · z **0.01**. 못 하면 **측정을 중단한다.**
R149·R150 에서 이 검사가 두 번 다 실제 결함을 잡았고 R151 에서는
통과했다.

**민감도(판정에 쓰지 않는다)**: k 를 6유형(IR·안내 제외)으로 셀 때 ·
k≥3 만 볼 때 · 창을 D+1/3/10/20 으로 바꿀 때 ·
**원장 venue**(매수권 케이스에서 겹침 여부로 가른 ΔH) — 원장은
개별이 귀무이므로 R124 §4 대로 **기술 통계로만** 적는다.
