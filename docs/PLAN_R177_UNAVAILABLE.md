# 못 내는 값들 — 무엇이 얼마나, 그리고 어떻게 할 것인가

**작성** 2026-08-25 (라운드 177)
**요청** *"전체적으로 미산출 미선정 등등 뭐가 안 나오는 거는 개선할 계획을
가지고 있어야지."*

맞는 말이다. 지금까지는 *"못 냈다"* 를 정직하게 적기만 하고(§3), **언제
낼 수 있게 되는지**는 안 적었다. 여기서 계획을 세운다.

## 2. 그중 하나는 결함이었다 — 이미 고쳤다 (라운드 177)

```
적정가 대비 상승여력 -24.3% (신뢰도 73점) · 진입 위치: 판정 불가
```

**같은 줄에서** 적정가 대비 위치를 알면서 *"판정 불가"* 라고 적고 있었다.
그리고 그 '판정 불가' 때문에 **고평가 차단이 통째로 꺼져** 현대건설이
추천에 올라왔다(현재가가 적정가보다 **+32.1%** 위).

→ 고쳤다. 근거: `docs/RESULT_R177_TAGS_AND_VALUE_GATE.md`

**교훈**: *"못 냈다"* 가 **다른 판단을 조용히 멈추는 자리**가 있으면 그건
표기 문제가 아니라 **결함**이다. 계획의 1순위는 그것들이다.

## 5. 규칙으로 남기는 것

1. **못 낸 값 옆에는 반드시 사유를 적는다.** 지금 `판정 불가`·`미수신`·
   `산출 불가` 14곳이 사유 0% 다 — 이 비율을 **회귀가 센다**.
2. **못 낸 값이 다른 판단을 멈추게 두지 않는다.** 멈춘다면 그 기본값이
   '통과'인지 '차단'인지 반드시 확인한다 — R177 은 하필 '통과'였다.
3. **못 잰 것으로 거르지도 않는다** (§3). 적정가를 못 낸 종목은 이번
   가드로도 막지 않는다.
4. 계획은 **갈래를 밝힌다** — ⓐ(영영 못 함)와 ⓒ(우리 탓)를 같은 목록에
   섞어 두면 고칠 것이 안 보인다.

## 6. 다음에 잴 것

`판정 불가`·`미수신`·`산출 불가` **14곳 각각**에 대해
*"이건 ⓐ·ⓑ·ⓒ 중 무엇인가"* 를 붙인다. ⓒ 가 또 있으면 그것이 다음 라운드다.
