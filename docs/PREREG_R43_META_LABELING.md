# 사전등록 — 라운드 43: 메타 레이블링 · 임계값 재보정

**작성 시각: 측정 전.** 이 문서를 쓴 뒤에 코드를 돌린다.
측정 후 기준을 내리지 않는다. 미달이면 기각하고 현행을 유지한다.

---

## 0. 먼저 정리 — 목표를 어디에 거는가

제안받은 목표는 *"충분한 블라인드 표본에서 행동 신호 적중률 65% 이상"* 이다.
동의한다. 다만 **현재 숫자를 정확히 적어 두고 시작한다.**

| 구간 | 표본 | 적중률 |
|---|---:|---:|
| 전체 블라인드 | 977 | 47.7% |
| 매수권(58+) 블라인드 | 280 | 56.1% |
| 60점+ 블라인드 | 23 | 82.6% ← **표본 부족, 성능으로 인정 안 함** |

**82.6%(n=23)를 목표 달성으로 쓰지 않는다.** Wilson 95% 하한이 61.2% 로
넓고, 23건은 우연으로 82%가 나올 수 있는 크기다.

그리고 이미 측정된 벽이 하나 있다 (라운드 36):

> 목표 0.7R · 손절 1R · 왕복비용 0.36% → **본전 적중률 63.1%**
> 목표 배수를 0.4R~3.0R 로 훑었으나 **어떤 배수도 train·valid·blind
> 세 구간 모두에서 양수가 아니었다.**

즉 65% 는 "있으면 좋은 수치"가 아니라 **비용을 넘기 위해 필요한 최소선**이다.
이번 라운드가 그걸 넘지 못하면 그렇게 보고한다.

## 1. 이번 라운드에서 하는 것 / 하지 않는 것

### 한다 — 지금 데이터로 검증 가능

| # | 항목 | 근거 |
|---|---|---|
| A | **메타 레이블링** (2차 분류기) | 원장 19,883건에 성공/실패 라벨과 피처가 있다 |
| B | **임계값 재보정** (58~70점) | 같은 원장에서 바로 잰다 |
| C | **국면 × 자산유형 × 실패유형 분해** | `failure_class` 필드가 이미 있다 |
| D | **Purged Walk-Forward + Embargo** | 시간 분할이 이미 있고 겹침만 제거하면 된다 |

### 하지 않는다 — 지금은 검증할 수 없다

| 항목 | 왜 안 하는가 |
|---|---|
| 시계열 파운데이션 모델(Chronos·TimesFM·MOIRAI) | 외부 모델 가중치를 받아야 하고, **포트폴리오·시세를 외부로 보내지 않는다**는 규칙과 충돌 가능. 로컬 추론이 가능한지부터 확인해야 한다 |
| 뉴스 → 가격 반응 학습 | 원장에 뉴스 필드가 **없다**. 필드를 먼저 채워야 한다(라운드 42에서 남긴 한계) |
| VIX 기반 동적 임계값 | VIX 시계열을 원장 시점별로 안 갖고 있다. 대신 **이미 있는 국면 × 변동성 6칸**으로 같은 효과를 노린다 |

숫자를 지어내지 않기 위해, 못 재는 것은 이번에 넣지 않는다.

## 2. 메타 레이블링 설계 (항목 A)

### 구조

```
1차 모델 (현행 룰 기반 엔진)  →  "매수 후보"  (방향)
                                      ↓
2차 모델 (메타 분류기)        →  "실행 / 건너뜀"  (확신)
```

1차 모델은 **바꾸지 않는다.** 설명 가능성을 유지한다.

### 학습 대상

1차 모델이 매수권이라고 한 케이스만 (`score >= 58`). 그 안에서
`success` 를 라벨로 쓴다. 매수권 밖은 애초에 실행하지 않으므로 제외한다.

### 피처 — 원장에 **이미 있는 것만**

| 피처 | 원장 필드 |
|---|---|
| 종합점수 | `score` |
| 시장 국면 | `regime` |
| 종목 변동성 | `vol20` |
| RSI | `rsi` |
| 볼린저 위치 | `bb_pos` |
| 52주 위치 | `range_pos` |
| DeMARK 상태·카운트 | `demark_state` · `demark_bull` · `demark_bear` |
| 월10선 위/아래 | `m10_above` |
| 진입 구간 | `entry_zone` |
| 유효표본 | `eff_sample` |
| 관찰 승률 | `win_rate` |
| 순기대수익 | `net_expected` |
| 시장 | `market` |
| 자산유형 | `asset_type` |

**미래 정보는 넣지 않는다.** `return_pct` · `mfe_pct` · `mae_pct` ·
`outcome` · `touched_bar` · `close_return_pct` · `failure_class` 는 결과라서
피처로 쓰면 누출이다. 회귀로 잠근다.

### 모델

`sklearn` 가용 여부를 먼저 확인한다. 없으면 **의존성을 새로 깔지 않고**
순수 파이썬 결정트리/로지스틱을 직접 쓴다. 어느 쪽이든 다음을 지킨다:

- 최대 깊이 4 이하 (과적합 억제 · 규칙을 사람이 읽을 수 있어야 한다)
- 리프 최소 표본 50 이상
- 학습은 **train 구간만**. valid 로 문턱을 고르고 blind 는 **딱 한 번** 본다

### 누출 차단

- **Purge**: 라벨 기간(20봉)이 겹치는 케이스를 학습에서 제외
- **Embargo**: 분할 경계 전후 20거래일 제외
- 같은 종목의 인접 케이스는 같은 폴드에 둔다

## 3. 사전등록 판정 기준 (측정 전 고정)

### 메타 레이블링 채택 조건 — **전부** 충족

| # | 조건 | 기준 |
|---|---|---|
| ① | 블라인드 적중률 | **≥ 65.0%** |
| ② | 블라인드 표본 | **≥ 100건** |
| ③ | Wilson 95% 하한 | **≥ 58.0%** |
| ④ | 비용 차감 기대값 | **> 0** |
| ⑤ | 손익비 | 현행(0.72) 대비 **비악화** |
| ⑥ | 최대 역행(MAE 평균) | 현행 대비 **비악화** |
| ⑦ | 신호율 | 현행 매수권의 **≥ 30%** 유지 |
| ⑧ | 국면 편중 | 상승·옆걸음·하락 중 한 칸이 통과 신호의 **≤ 60%** |

하나라도 미달이면 **기각**한다. 기준을 내리지 않는다.

### 임계값 재보정 채택 조건 (항목 B)

58/60/62/65/68/70 각 문턱에 대해 위 8개를 같이 재고, **①②③④를 모두
넘는 문턱이 있으면** 그중 신호율이 가장 높은 것을 고른다. 없으면 현행 58 유지.

## 4. 예상 — 미리 적어 둔다

정직하게, **채택 가능성은 낮다고 본다.**

- 라운드 21·36에서 이미 "매수권 신호에 비용 차감 우위가 없다"가 반복 확인됐다
- 라운드 32에서 진입 엔진 10종 전부 블라인드 신호EV 음수였다
- 블라인드 매수권이 280건인데, 메타 모델이 걸러내면 표본이 더 줄어
  ②(≥100건)와 ⑦(신호율 30%)이 동시에 걸릴 수 있다

그래도 재는 이유: **어느 조건이 먼저 무너지는지 알면 다음 라운드의 과제가
정해진다.** 그리고 실패를 실패로 적는 것이 이 프로젝트의 방식이다.

어느 조건에서 막혔는지, 다음 과제를 그대로 적는다.
