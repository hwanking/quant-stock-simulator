## 1. 무엇을 바꾸지 않는가 (동결 준수)

- 점수·게이트·문턱·가중치를 **바꾸지 않는다.** 이 라운드는 **측정 전용**
- 결과가 좋아도 이번에 반영하지 않는다. 반영은 2026-11-16 이후 **새
  사전등록**으로만 한다
- R55·R57·R66 전방 창에 조건을 **얹지 않는다.** 이 팩터가 채택되면
  자기 전방 창을 따로 연다
- 블라인드·전방 표본을 **모델 선택에 재사용하지 않는다**

## 2. 무엇을 재는가

**질문**: 외국인·기관 순매매의 **연속성**이 같은 날 종목을 가르는가.

잣대는 라운드 49·110·111·112 와 **같다.** 새로 만들지 않는다 —
만들면 그 결과를 종전 라운드와 비교할 수 없다.

- 같은 날 안에서 변수로 정렬 → 상위 5종목 vs 6위 이하 **매수권(58+)**
- 두 집단의 목표선 도달률 차이 → 날짜별 승패 → **부호검정**
- 표본 단위는 **날짜**다 (케이스가 아니다 — 라운드 80·113)

## 3. 누출 차단 — 전일까지만 쓴다

외국인·기관 순매매는 **당일 장 마감 후**에 공표된다. 그러므로 날짜 D 의
신호를 매길 때 **D 당일 수급을 쓰면 누출**이다.

→ **D−1 까지의 수급만 쓴다.** 예외 없다.
→ 이 규칙이 지켜졌는지 측정 스크립트가 **자기검사로 확인**한다
  (D 당일 값을 섞으면 결과가 달라지는지 대조 — 안 달라지면 애초에
  변수가 안 들어간 것이다).

## 4. 시험할 변수 — **정확히 5개.** 늘리지 않는다

원시 순매매 **금액·주식수는 쓰지 않는다.** 종목 크기에 지배되고,
크기를 나눌 분모(거래량·상장주식수)가 원장에 없다. 없는 분모를
지어내지 않는다 (§3). 그래서 **크기에 무관한 형태**만 시험한다.

| # | 변수 | 정의 (전부 D−1 까지) |
|---|---|---|
| V1 | `frgn_days5` | 최근 5거래일 중 외국인 **순매수 일수** (0~5) |
| V2 | `inst_days5` | 최근 5거래일 중 기관 순매수 일수 (0~5) |
| V3 | `both_days5` | 외국인·기관 **동시** 순매수 일수 (0~5) |
| V4 | `frgn_streak` | D−1 기준 **연속** 외국인 순매수 일수 (0~20) |
| V5 | `frgn_flip` | 직전 5일 순매도 → 최근 순매수 **전환** (0/1) |

V1·V4 가 영상 요약의 주장("3일 이상 연속")에 해당한다.
**"3일"이라는 문턱은 쓰지 않는다** — 일수를 그대로 정렬 키로 쓴다.
문턱을 미리 고르면 그것이 발견인지 고른 것인지 못 가른다.

### 같이 재는 대조군 (판정 대상 아님 · 해석용)

- `score` — 종합점수로 같은 잣대를 돌린 값. **같은 표본에서** 기준선이
  얼마인지 알아야 V1~V5 를 읽을 수 있다. 라운드 112 의 교훈 —
  표본을 줄이는 것만으로 z 가 ±2 움직였다.

## 5. 판정 기준 — **측정 전에 못 박는다**

| | 조건 |
|---|---|
| **P1** | 부호검정 z ≥ **2.58** (양측 0.05 / 5시험 = 0.01 → z 2.5758, **올림**) |
| **P2** | 방향이 양수 — 상위5의 도달률이 대조군보다 **높다** |
| **P3** | train 과 valid 에서 **방향이 같다** |
| **P4** | 짝비교 날짜 **200일 이상** (수급이 붙은 구간 안에서) |

**넷을 모두 넘어야 통과다.** 하나라도 미달이면 기각하고 현행 유지한다.
**측정 후에 기준을 내리지 않는다.**

보정 문턱을 **올림**하는 것은 라운드 113 의 교훈이다 — 그때 반올림해서
문턱을 조금 낮춘 적이 있다.

## 6. 검정력을 결과와 함께 낸다

라운드 129 가 계산한 대로, 이 잣대는 표본이 810일일 때 보정 문턱에서
**5%p 미만을 못 본다.** 이 라운드의 표본은 그보다 **적다**(수급 구간
안이므로). 따라서 최소 가시 효과는 5%p 보다 **크다.**

→ 결과가 미달이어도 *"효과가 없다"* 라고 쓰지 않는다.
   *"이 표본에서 X%p 짜리는 없다"* 라고 쓴다. X 는 R129 의 식으로
   **같이 계산해서** 적는다.

## 7. 자기검사 — 통과해야 숫자를 쓴다

이 저장소는 "검사가 무엇을 재는지 이름만 보고 믿었다"로 여러 번 당했다.
아래 셋을 통과하지 못하면 결과를 쓰지 않는다(종료 코드로도 알린다).

| | 무엇 |
|---|---|
| ⓐ | **거짓양성률** — 그날 결과를 섞은 귀무에서 z≥1.96 이 2.5% 근처인가 |
| ⓑ | **변수가 실제로 들어갔는가** — 변수를 무작위로 섞으면 z 가 바뀌는가. 안 바뀌면 정렬에 안 쓰인 것이다 |
| ⓒ | **누출 검사** — D 당일 수급을 쓰면 z 가 달라지는가. 안 달라지면 §3 이 안 지켜진 게 아니라 변수가 비어 있는 것이다 |

특히 ⓑ 는 **0건이 '없다'인지 '못 봤다'인지** 가르기 위한 것이다.
수급이 붙은 케이스가 19% 뿐이므로, 조인이 조용히 실패하면 변수가 전부
결측이 되고 그때도 "미달"이 나온다. 그 둘은 다른 사실이다.

## 8. 표본 구성

- 개발 구간(train + valid)만. **blind·전방 미사용**
- 수급이 붙은 (종목, 날짜)만. 안 붙은 케이스는 **버리지 않고 제외**로
  세어 보고한다 (몇 %를 못 쓰는지 적는다)
- 매수권 58+ 필터는 대조군 쪽에만 적용 — 라운드 49 와 같다
