## 2. 잠금

회귀 §244 가 두 파일의 화면 문자열을 AST 로 훑어 내부 참조 **0건**을 요구한다(훑은 수를
`scanned=` 로 찍는다 · CSS 주석은 제외 · 심기로 잡힘/오탐 양방향 확인). 물타기 이유 넷은
반말 어미('않았다' · '않는다' · '같다' · '막혔다')가 없어야 한다. 옛 낱말을 잠갔던 §240 ·
§241 · §243 은 새 문장으로 옮겼다(번호 대신 문장을 잠근다).
