# 결과 R327 — 옛 스냅샷의 '표본 대기' · '아직 안 잼'을 누르면 잰다 · 적정가 산출 불가를 쉬운 말로 (2026-09-16)

사용자 화면 셋(종목 이름은 적지 않는다):

## ① "표본 대기 · 표본외 검증은 마쳤고, 그 성적이 기준에 못 미쳤습니다. 사…"

- **원인**: 라운드 292(2026-09-14)가 이 사유를 **'표본외 성적 미달'** 로 갈랐다(기다려서 풀리지 않으므로 '대기'가
  아닌 이름). 그런데 관심종목 행의 스냅샷은 **09-10** 에 찍혀 옛 이름 '신뢰도·표본 확보 대기'를 안고 있었다 —
  표는 *"표본 대기"*(기다리면 된다) 옆에 *"사례가 쌓인다고 풀리는 조건이 아닙니다"* 를 적었다. 한 줄이 스스로 어긋났다.
- **고침**: 새로 재지 않고 **중앙 판정과 같은 가름**을 옛 스냅샷에 적용한다 — 옛 이름이고 사유가 그 갈래의 문장(머리
  '표본외 검증은 마쳤고')이면 '성적 미달'로 읽는다. 판별 낱말이 `verdict_core` 의 문장 머리와 같은지 §333 이 잠근다
  (둘이 어긋나면 옛 가름이 조용히 죽는다). 다른 사유면 옛 이름 그대로(양방향 심기).
- **'사…'**: 표의 사유 한 줄이 34자에서 낱말 가운데를 잘랐다 — 같은 폭 안에서 **첫 문장이 끝나면 거기서** 자른다.

## ② "아직 안 잼 · 아래 '지금 계산해서 채우기' · 또는 이름을 눌러 열기"

- R322 는 길을 **가리키기만** 했다 — 그 버튼은 화면 아래에 있고 5개씩 차례로 채운다.
- **고침**: 칸 자체를 **"지금 재기 (1~3분)"** 링크로(`?measure=코드`). 누르면 그 **한 종목만** 채우기 버튼과 **같은
  코드**로 바로 잰다(§4 — 채우는 길을 둘로 만들지 않는다). 자동으로 돌리지는 않는다(한 종목 1~3분 · R166) — 누른
  사람이 시작한다. 목록에 없는 코드·못 읽는 값이면 아무것도 안 한다(§3).

## ③ "시장조정 펀더멘털 적정가 미산출 · 산출 불가 — 멀티플 모델 적용 범위 밖 … -84% 괴리"

- 게이트는 옳다(모델 적정가가 시장가보다 70% 넘게 아래면 이익·장부가로 가격을 설명할 수 없다 · R54). 그런데 괄호 속
  *왜* 가 **PER>100 · PBR>10** 일 때만 붙어, 그 밖(예: **적자**)에서는 *"-84% 괴리"* 만 남았다.
- **고침**(표시 문장만 · 게이트·문턱 70%·값 불변 · model v2026.09.16.2 `kind='ui'`):
  - 수신한 주당순이익이 0 이하면 *"최근 이익이 적자(주당순이익 0 이하)"* 를 이유로 적는다(새 문턱 없음 · 사실).
  - 쉬운 말 한 줄: *"지금 주가가 회사가 버는 이익·가진 자산으로 계산한 값보다 훨씬 높아, 시장이 앞으로의 성장이나 실적
    회복을 먼저 값에 넣은 상태입니다."*
  - **대신 볼 것**: 매매 판정 · 차트의 원장 분포(같은 자리 과거 결과).

## 바꾸지 않은 것

bucket 가름 규칙 · 적정가 게이트·문턱 · 채우기 계산 · 판정 · 원장. 검사 §333(5건).
