### 마무리에서 나온 결함 넷 (재고 나서 고쳤다)

1. **메뉴 줄이 여전히 x 27** — 바깥 여백을 걷었는데도 10px 이 남았다. Streamlit 이 사이드바 스크롤 칸에
   `scrollbar-gutter: stable both-edges` 를 걸어 **왼쪽에도** 스크롤바 자리를 비워 두었다(clientWidth 263 / offsetWidth 283).
   오른쪽에만 두어 17px.
2. **휴대폰 본문 좌우가 40px** — 킷 전역의 휴대폰 규칙(16px)이 같은 층의 **뒤에 오는** 무조건 규칙(2.5rem)에 져서 죽어 있었다
   (375px 실측 · 일치하는 규칙 셋 중 마지막이 이김). ⚠️ R471 첫 판의 회귀 주석이 *"휴대폰 구간은 킷 전역의 16px 그대로"* 라
   적었다 — 거짓이었다. 마지막에 오는 톤 층에 휴대폰 규칙을 두었다(16px). 고친 뒤 375px: 가로 넘침 0 · 타일 15개 중 잘림 0.
3. **라이트 모드 대비 두 자리** — 맨 위 화면 전환의 고르지 않은 칸(Streamlit 이 config.toml 의 다크로 칠함 · 1.01:1)과
   대화 얼굴 아이콘(라이트 글자 규칙이 특정도에서 on_brand 를 이김 · 2.85:1). 톤 층에 전환 칸 규칙 · 라이트 글자 규칙의 예외에
   대화 얼굴 자손.
4. **config.toml 이 옛 제미나이 색** — R471 이 팔레트를 바꾸고 이 파일을 안 옮겨, 화면 전환의 고른 칸이 옛 파랑이었다. §81 이
   값으로 대 보는 네 값을 지금 팔레트로.

## R472 — '자격 0' 줄: 언제 막았나 · 0 까지의 거리

자동매매의 '실주문 자격 0' 줄은 *"가장 많이 막은 조건은 '비용 차감 기대값 양수' 미충족 (5/5개)"* 까지만 적었다.

- **언제** — 머리를 '오늘'이 아니라 **판정일**로 · 판정 시각(그 판정을 낸 개장 전 리포트의 생성 시각)과 자동매매 장부에 계획으로
  적힌 시각을 같이. 계획에 리포트 시각을 싣고(plan_id 에는 안 든다), 옛 계획은 그 판정일 리포트 파일에서 읽는다
  (`premarket.generated_at` · 엔진 버전이 같은 파일 먼저 · 못 찾으면 None).
- **'개선'** — 그 조건의 문턱은 0 이고 식은 `EV = p·up + (1 − p)·dn − 비용` 이다(중앙 판정). 문턱을 내리거나 비용을 낮춰
  적는 것은 §2·§9 다. 고칠 수 있는 것은 **설명**이고, 같은 식으로 0 이 되는 확률과 지금 확률을 적는다(새 문턱 없음).

실측(판정일 2026-10-08 · 후보 5개 · 장부 읽기 전용):

| | 값 |
|---|---|
| 판정 시각 | 2026-10-08 15:32 (개장 전 리포트 생성) |
| 장부에 계획으로 적힌 시각 | 2026-10-09 17:01 |
| 가장 가까운 후보의 비용(0.41%) 뺀 기대값 | −0.24% |
| 0 이 되려면 필요한 목표 선도달 확률 | 61.4% |
| 그 점수대의 원장 실측(기대값에서 되짚음) | 59.9% |
| 모자란 폭 | 1.5%p (5개 범위 1.5~4.3%p) |

되짚은 확률 다섯 개가 59.85~59.88 · 한 개 58.82 로 나와, 점수대 적중률(59.85%)과 맞는다 — 식을 거꾸로 푼 것이 맞다는 확인이다.
이 줄은 R317 의 *"벽의 높이"* 를 종목 단위로 적은 것이다(그때 후보 중앙 0.31%p · 운영 비용 0.36 시절).

## R472 — 작업 중 카드

OrbitMusic 의 작업 카드를 옮겼다. 이 PC 에서 저녁 작업이나 스윙 워커가 **도는 동안만** 상단 바 아래 오른쪽에 뜬다.

- 읽는 것은 둘 · 둘 다 가볍다(셸·네트워크 없음 · 15초 조각 · 앱 전체를 다시 안 돌린다): 저녁 작업 실행 기록의 마지막 시작 줄 뒤
  끝난 단계 수 · 워커 잠금 파일의 주인 프로세스.
- **막대는 끝난 단계 수 / 전체 단계일 때만** — 워커처럼 장이 끝날 때까지 도는 작업에는 막대가 없다(지어낸 퍼센트).
- 기록이 지금 단계의 시간 상한(그 스크립트의 것)보다 오래 안 바뀌었으면 **도는 중이라 하지 않는다** — 상한을 넘기면 작업이 스스로
  '멈췄다'를 적으므로, 그 줄도 없으면 끊긴 것이다.
- 확인: 심은 기록(5단계 중 2단계 끝)을 읽는 쓰기 금지 앱에서 카드 440×75px · '3/5단계' · 막대 2/5 · 스윙 탭에서도 뜬다.
