# 라운드 465 — 자동 갱신은 화면 전체로 (입력 칸이 있는 갈래는 빼고)

2026-10-09 · 판정·점수·문턱·주문 규칙 **불변** · 버전 없음 · 스윙 탭 그리기 구조 하나.

## 무엇이 비어 있었나

사용자: *"15초마다 자동 갱신 해줘."* 이 PC 장부에는 이미 자동 갱신이 켜져 있었다(15초 · 라운드 457 · 2026-10-09 12:06 설정 사건). 그런데
15초마다 다시 그려지는 것은 **계좌 칸 조각 하나**였다 — 지휘 띠(워커 · 신규 매수 · 보호 매도 · 오늘 계획) · 시스템 상태 띠 · 오늘 엔진
깔때기 · 주문 사건 · 포지션 카드는 화면을 다시 열어야 바뀌었다. 장중에 워커가 주문을 내고 체결을 맞추는 동안 관제실이 그것을 안 보였다.

## 무엇을 바꿨나

- 스윙 탭 **본문 전체**를 조각 하나로 감쌌다. 자동 갱신이 켜져 있으면 그 간격으로 본문이 다시 그려진다(앱 전체는 안 돈다 — 사이드바·분석
  화면은 그대로). 조각은 **제 장부 연결**을 연다(라운드 454 — 조각만 다시 돌 때 바깥 연결은 이미 닫혀 있다).
- **'시스템' 갈래는 뺀다.** 설정·연결 정보 입력 칸(앱 키 · 위험 한도)이 있어 쓰는 도중에 다시 그리면 안 된다. 입력 위젯이 있는 갈래가 그
  하나뿐인지는 손 목록이 아니라 뷰 함수의 AST 로 세어 회귀가 대 본다.
- 갈래를 바꿔 갱신 여부가 달라지면(관제실 → 시스템, 그 반대) 앱을 한 번 다시 돈다 — 조각을 다시 정의해야 `run_every` 가 바뀐다.
- 계좌 칸은 바깥이 다시 그리는 중이면 **제 타이머를 안 건다** — 같은 바퀴에 한 번만 잔고를 읽는다(두 타이머가 겹쳐 15초에 두 번 읽지 않게).
- 토글 이름을 동작에 맞췄다 — '자동 갱신(잔고 읽기)' → **'자동 갱신(화면 · 잔고)'**, 도움말이 무엇을 다시 그리고 무엇을 빼는지 적는다.
- 주문은 여전히 워커만 낸다. 화면이 15초마다 다시 그려져도 증권사에 주문을 보내지 않는다(잔고 조회만).

## 비용

본문 한 바퀴는 장부 조회 · 작업 스케줄러 상태(60초 캐시 — PowerShell 은 1분에 많아야 한 번) · 실행 기록 파일 읽기 · 잔고 조회 한 번이다.
잔고는 가격만 바뀌면 장부에 600초마다 남긴다(라운드 457 의 저장 규칙 그대로).

## 검사

회귀 §448(6건) — 갱신 판정 · 입력 위젯 갈래와 갱신 목록의 일치(AST 유도) · 본문 조각의 run_every 와 제 연결 · 갈래 바뀜에 다시 돌기 · 계좌
칸 타이머 하나 · 자식 렌더(켠 채 관제실 → 시스템 · 예외 0). §440 ⑪ 의 *"run_every 조각은 계좌 칸 하나"* 는 이 라운드가 바꾼 사실이라 새
사실(계좌 칸 + 본문)로 옮겼다. 15초 타이머가 실제 브라우저에서 도는지는 사이트를 다시 띄워 확인한다(앱 테스트는 조각 타이머를 돌리지 않는다).
