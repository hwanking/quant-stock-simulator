# 화면 명세 v2 — 6개 화면 텍스트 와이어프레임

기준: docs/REDESIGN_BRIEF_v2_ko.md (2026-08-01). 이전 8화면 명세를 v2 전역
메뉴 6개 체계로 재작성했다.

> 공통 데이터 규칙: UI에 필요한 필드가 현 파이프라인(quant_indicators의
> four_scores/build_final_verdict/build_easy_advice, premarket.build_report/
> grade_history, .portfolio/calibration.json, virtual_graded.jsonl,
> market_context, portfolio)에 있으면 그대로 쓰고, **없으면 각 화면의
> '필요 데이터 인터페이스'에 정의만 남긴다. 임의 값·추정치 생성 금지.**
> 미산출은 "미산출/표본 부족/미연동"으로 정직하게 표기, 오류는 은폐하지 않고
> 배너로 밝히며 정상 영역은 계속 렌더한다.
>
> 공통 위계: 결론 → 행동 가격 → 이유 → 과거 검증 → 상세 산식.
> 정보는 삭제가 아니라 단계적으로 숨긴다(탭·펼쳐보기·전문가 격리).

## 1. 홈

**목적**: 사용자의 첫 3질문(①오늘 시장이 좋은가 ②지금 살 종목이 있는가
③내 보유종목을 팔아야 하는가)에 스크롤 없이 답한다.

**와이어프레임 (데스크톱, 최대 폭 1440px)**

```
┌────────────────────────────────────────────────────────────┐
│ 오늘의 시장 한 줄 브리핑                                    │
│ "코스피 보합권 — 오늘은 조건을 충족한 후보 2개가 있습니다."│  ← 큰 문장 하나 (premarket easy_line)
│ 기준 2026-07-31 종가 · 생성 06:40 · 모델 v○○               │
├────────────────────────────────────────────────────────────┤
│ 개장 전 추천 1~3위 (행동 우선 카드 — §2 카드 축약형)        │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                     │
│ │1위 ○○○   │ │2위 ○○○   │ │3위 ○○○   │                     │
│ │이 가격    │ │지금은     │ │사도 됩니다│  ← 한 줄 행동이 카드 최대 요소
│ │이하 매수  │ │기다리세요 │ │          │                     │
│ │매수 65,000│ │…         │ │…         │                     │
│ └──────────┘ └──────────┘ └──────────┘                     │
├────────────────────────────────────────────────────────────┤
│ 내 보유종목 긴급 알림 — 행동별 건수                          │
│ 손절선 접근 1 · 일부 매도 검토 1 · 이상 없음 4  [보기 →]    │
├────────────────────────────────────────────────────────────┤
│ 시장지수 요약 (작게 — 배경정보)                             │
│ KOSPI 3,120 +0.4% | KOSDAQ … | USD/KRW … | S&P500 …        │  ← 13px, 카드 아님
├────────────────────────────────────────────────────────────┤
│ 모델 상태 요약 (1줄)                                        │
│ 표본외 적중 ○○% (n=○○) · 케이스 ○○건 · 데이터 정상  [상세→]│
└────────────────────────────────────────────────────────────┘
```

- 지수·모델 숫자를 첫 화면 최대 요소로 만들지 않는다 (현 st.metric 9개 → 텍스트 2줄).
- 빈 상태: 추천 0건은 "오늘 조건을 충족한 후보가 없습니다 — 모델이 확신 없는 날은
  권하지 않습니다 (제외 사유 보기)". 실패처럼 보이게 하지 않는다.
- 보유 미등록: 긴급 알림 영역에 등록 안내 1줄.

**필요 데이터 인터페이스**: 보유 긴급 알림의 행동별 건수 집계
`holdings_alerts {near_stop:n, partial_sell:n, ok:n, data_short:n}` —
build_easy_advice 보유 판정의 화면용 집계(판정 로직 불변, 집계만 UI 계층).

## 2. 개장 전 추천

**목적**: 전일 확정 데이터 기준 고신뢰 후보를 카드로 고정 제공. 장중 재계산
금지 — 생성 시각·기준일·모델 버전 박제.

**와이어프레임**

```
┌ 개장 전 추천 ──────────────────────────────────────────────┐
│ 기준 데이터 2026-07-31 종가 · 생성 08-01 06:40 · 모델 v○○  │  ← 박제 스탬프
│ 후보 12건 중 게이트 통과 2건                                │
├─ 추천 카드 (1건 = 1카드) ──────────────────────────────────┤
│ ┌────────────────────────────────────────────┐             │
│ │ 1위  ○○전자 (005930)          신뢰도 중    │             │
│ │ 「이 가격 이하에서만 사세요」               │  ← 카드 내 최대(15–17px 제목보다 큰 유일 요소)
│ │ 권장 매수가 64,500원 · 목표 71,000 · 손절 61,800          │
│ │ 보유기간 ~20영업일 · 손익비 1.8                           │
│ │ 근거: 거래량 확대 지속 / 추세 상방 전환     │             │
│ │ 위험: 뉴스 위험 낱말 1건                    │             │
│ │ 유사 사례 적중 62% (n=34)                   │             │
│ │ [상세 분석 →]                               │             │
│ └────────────────────────────────────────────┘             │
├─ 펼쳐보기: 제외 종목 사유별 그룹 ──────────────────────────┤
│ 과열 3 · 유동성 2 · 뉴스 위험 1 · 손익비 부족 2 · 데이터    │
│ 오류 1 · 표본 부족 1                                        │
├─ 펼쳐보기: 지난 추천의 실제 성과 (사후 검증) ──────────────┤
└────────────────────────────────────────────────────────────┘
```

- 카드 필수 항목(브리프 §개장 전 추천 카드): 순위·종목명·한 줄 행동·권장 매수가·
  목표가·손절가·보유기간·신뢰도·핵심 근거 2·위험 1·유사 사례 적중률(표본 수).
- 적중률은 반드시 n 병기, calibration.json 실측만 인용.
- 스캔 실행 도구(현 사이드바 트렌드 탐색기)는 이 화면의 보조 패널로 이동.

**필요 데이터 인터페이스**
- `positives[2]`·`risks[1]` 요약 문구: build_final_verdict composition 상·하위
  기여에서 추출. 방향 구분 불가 항목은 표시 생략(허구 요인 생성 금지).
- 제외 사유 코드 enum {OVERHEAT, LIQUIDITY, NEWS_RISK, RR_SHORT, DATA_ERROR,
  SAMPLE_SHORT, SOURCE_MISMATCH, OTHER} — 현 자유 문자열의 그룹 매핑용.

## 3. 종목 분석 (첫 화면 = 요약 탭)

**목적**: "한 화면 높이 안에 판단 완료". 상세는 6탭(요약/차트/뉴스/시나리오/
과거 검증/상세 근거) 안으로.

**첫 화면 ①~⑨ 순서 (스크롤 없이, 중앙 9열)**

```
┌ 중앙 9열 ──────────────────────────────────┐┌ 우측 3열(고정) ┐
│ ① ○○전자 005930 · 현재가 67,200 (+1.2%)   ││ 지금은          │
│    기준 08-01 15:30 · 데이터 정상 ●        ││ 기다리세요      │
│ ② 「지금은 기다리세요」                    ││ ─────────────  │
│    (한 줄 행동 결론 — 화면 유일 28~32px)   ││ 종합점수   48점 │
│ ③ 사용자 상태:  [ 미보유 ] [ 보유 중 ]     ││ 현재가  67,200  │
│    (보유 선택 시: 평단가 [    ] 수량 [   ])││ 진입가  64,500  │
│ ④ 신규: 64,500원 이하로 오면 검토          ││ 목표가  71,000  │
│    보유: 해당 시 보유자 문구로 전환        ││ 손절가  61,800  │
│ ⑤ 진입 64,500 · 목표 71,000 · 손절 61,800  ││ 신뢰도     62점 │
│    · 보유기간 ~20영업일                    ││ 유사 사례 62%   │
│ ⑥ 긍정 요인 3  (한 줄씩)                   ││  (n=34)         │
│ ⑦ 위험 요인 3  (한 줄씩)                   │└────────────────┘
│ ⑧ 유사 사례 34건 · 실제 성공률 62%         │
│ ⑨ 신뢰도 62점 · 가장 큰 한계: 표본 부족    │
└────────────────────────────────────────────┘
[요약] [차트] [뉴스] [시나리오] [과거 검증] [상세 근거]
```

- ② 한 줄 결론 어휘는 8종 고정: 지금 사도 됩니다 / 이 가격 이하에서만 사세요 /
  지금은 기다리세요 / 계속 보유하세요 / 일부 매도하세요 / 추가매수하지 마세요 /
  종가가 이 가격 아래면 정리하세요 / 데이터가 부족해 판단을 보류합니다.
- ③ 사용자 상태 선택기(COMPONENT_MAP §11): 보유 선택 시 ④⑤가 보유자 기준으로
  즉시 전환 — 신규 매수가와 보유자 손절가 혼용 금지.
- 점수 위계: 1단계 최종 행동(②) → 2단계 종합점수·신뢰도·유사 사례 성공률
  (⑧⑨·우측 패널) → 3단계 추세·모멘텀·거래량·뉴스·위험·전략 품질(작은 수평
  막대 — '상세 근거' 탭 상단) → 나머지 산식. 원형 게이지 최대 1개.
- ETF: ①~⑨ 동일 흐름. 기업 분석 계열은 '상세 근거' 탭에서도 미표시.

**우측 고정 요약 패널 (3열) 명세**
- 배치: 데스크톱 최대 폭 1440px 중 중앙 9열 + 우측 3열. position: fixed/sticky,
  스크롤·탭 전환에도 상시 노출 (긴 분석을 읽어도 핵심 판단이 계속 보인다).
- 내용(순서 고정): 최종 행동(한 줄, 의미 색) / 현재가 / 진입가 / 목표가 /
  손절가 / 신뢰도 / 유사 사례 성과(적중률+n). 숫자는 tabular-nums 우측 정렬 13px.
- 보유 모드에서는 진입가 행이 '내 평단·손익'으로, 손절가가 보유자 손절가로 전환.
- 미산출 값은 "산출 불가"·"표본 부족" 그대로. 태블릿 이하에서는 패널을 접어
  본문 상단 요약 스트립으로 대체.
- 현 구현(web_app.py 2662–2693)은 1760px 미만에서 숨김 — v2 목표는 1440px
  레이아웃 내 3열 상시 확보로 조정.

**나머지 탭 요지**
- 차트: 종합 차트 + 지표 선택 패널(이동평균·볼린저·RSI·거래량·추세 소진 신호·
  지지/저항) + 진입·목표·손절 수평선 오버레이 + 기간 전환.
- 뉴스: 종목 뉴스 목록 → 시장 컨텍스트 축약 → 점수 실반영 내역.
- 시나리오: 오르면·횡보하면·내리면 3분할 + 목표·손절 근거 + 보유기간.
- 과거 검증: 과거 비슷한 사례(자기유사) + 점수대 실측 적중률 + 이 종목 케이스.
- 상세 근거: 점수 산식·관점별 판정·세부 점수 막대 → 기업 분석(전문가 펼쳐보기,
  주식 전용) → 데이터 출처·감사 → 10대 레포트 원문(기본 접힘).

**필요 데이터 인터페이스**
- ⑥⑦ 요인 3: verdict composition에서 {factor, direction, delta_points} 파생 —
  파생 불가 항목은 목록 제외.
- ⑨ "가장 큰 한계" 1줄: 발동 게이트 중 상한 최저 항목의 설명문 선택(계산 아님).
- 뉴스 방향·강도·기반영: 현 파이프라인은 낱말 감점만 — 방향·강도 칸은 "미분석"
  고정, 인터페이스 {direction, strength, horizon, priced_in, score_applied}만 정의.

## 4. 내 보유종목

**목적**: "지금 뭘 해야 하나"를 행동별 그룹으로. 매매 실행 기능은 없다.

**와이어프레임**

```
┌ 내 보유종목 ───────────────────────────────────────────────┐
│ 평가액 12,400,000원 · 손익 +320,000 (+2.6%) · 확인 필요 2  │
├─ 행동별 그룹 (위험 우선) ──────────────────────────────────┤
│ ▼ 종가가 이 가격 아래면 정리하세요 (1)                     │
│   ┌──────────────────────────────────────────┐             │
│   │ ○○화학  평단 41,200 → 현재 38,900 (-5.6%)│             │
│   │ 정리 기준가 38,500 · [상세 →]            │             │
│   └──────────────────────────────────────────┘             │
│ ▼ 일부 매도하세요 (1)                                       │
│ ▼ 계속 보유하세요 (3)                                       │
│ ▼ 추가매수하지 마세요 (1)                                   │
│ ▼ 데이터 부족 — 판단 보류 (1)                               │
├─ 탭: [보기] [가져오기] [관리] ─────────────────────────────┤
│   가져오기: 엑셀 / 스크린샷 OCR / 표 붙여넣기 (기존 유지)   │
└────────────────────────────────────────────────────────────┘
```

- 그룹 제목은 한 줄 결론 어휘 그대로(내부 enum 노출 금지).
- 카드: 종목명 · 평단→현재(손익 부호+색+아이콘) · 대응가 1줄 · [상세](종목 분석
  보유 모드로 딥링크).
- 평단 미입력 종목은 "평단 미입력 — 손익 계산 불가"(0원 취급 금지). OCR 실패
  행은 "확인 필요 N행"으로 노출 유지.

**필요 데이터 인터페이스**: 보유 판정→그룹 enum 매핑표(UI 상수)
{IMMEDIATE_CHECK, NEAR_STOP, PARTIAL_SELL, HOLD, ADD_OK, ADD_FORBIDDEN,
DATA_SHORT}. "손절 근접" 표시 임계는 UI 상수로 정의하고 화면에 명시.

## 5. 시장·뉴스

**목적**: 시장 배경과 뉴스 컨텍스트 — 배경정보이지 결론이 아니다.

**와이어프레임**

```
┌ 시장·뉴스 ─────────────────────────────────────────────────┐
│ 시장 국면 한 줄 + 기준일                                    │
│ 지수 요약 (KOSPI·KOSDAQ·환율·S&P — 작은 카드 4)             │
├─ 주요 뉴스 목록 ───────────────────────────────────────────┤
│ [위험 낱말 감지 −N점] 제목 · 언론사 · 게시시각              │
│ (방향·강도·기반영: "미분석" — 파이프라인 미구현 명시)       │
├─ 이 컨텍스트가 점수에 준 영향 (펼쳐보기) ──────────────────┤
└────────────────────────────────────────────────────────────┘
```

- 반복·저품질 기사는 묶거나 제외(related_count 묶음 표기).
- 뉴스 분류(긍정·부정·중립/영향 강도/단기·중기/가격 기반영/점수 실반영)는
  **인터페이스 정의만** — 현 파이프라인은 낱말 감점뿐이므로 임의 생성 금지.

## 6. 모델 검증

**목적**: 강점(케이스 스터디·표본외 적중률·실패 원인·무결성)을 전면에 —
잘한 것과 못한 것을 같은 비중으로.

**와이어프레임**

```
┌ 모델 검증 ─────────────────────────────────────────────────┐
│ 적중률: 전체 ○○% · 표본외 ○○% (n=○○) · 블라인드 [미수행]   │
```
