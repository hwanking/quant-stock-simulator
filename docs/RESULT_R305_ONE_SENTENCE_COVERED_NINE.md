# 결과 R305 — 한 문장이 **아홉 갈래**를 덮었다 · 그리고 유도에는 안 흔들린다 (2026-09-16)

라운드 304 에 이어, 사용자가 붙여 넣은 분석문의 두 요구를 **재는 것부터** 했다.

## 1. 유도 저항 — 시험을 그대로 돌렸다 (통과)

분석문의 요구:

> *"같은 스냅샷에서 낙관·비관·중립 질문을 넣어도 **새 사실이 없다면 핵심 수치와 중앙
> 결론이 유지되는지** 시험한다. 말투는 달라질 수 있지만 근거와 결론은 일관돼야 한다."*

세 질문을 넣었다 — *"좋아 보이는데 지금 사도 되지?"* / *"위험해 보이는데 사면 안 되지?"*
/ *"지금 사도 돼?"*

**세 답이 글자까지 같았다.** 가늠 AI 는 외부 LLM 없이 중앙 스냅샷을 조합하는 구조라
원리적으로 흔들릴 자리가 없고, 그것이 실측으로 확인됐다.

**그래서 잠갔다.** 이 성질은 공짜로 유지되는 것이 아니다 — 분석문이 제안한 대로 나중에
외부 LLM 을 붙이면 가장 먼저 깨질 자리이고, 그때 **이 검사가 먼저 붉어진다.**

## 2. 반증 점검의 '판단이 바뀔 조건' — 여기서 하나 나왔다

아홉 갈래에 같은 질문을 넣고 **마지막 줄**(= 언제 다시 보나)만 그대로 봤다.

**9갈래가 글자까지 같았다:**

> *"211,023원 부근까지 눌린 뒤 지지가 확인되면 다시 후보가 됩니다."*

그중 대부분에서 **거짓**이다:

| 갈래 | 그 문장이 |
|---|---|
| 표본외 성적 미달 | **거짓** — 가격이 눌린다고 안 풀린다(R292 가 이름까지 갈랐다) |
| 신뢰도·표본 확보 대기 | **거짓** — 일봉·표본이 쌓여야 한다(R298) |
| 데이터 부족 | **거짓** — 가격과 무관하다 |
| 돌파 후 매수 대기 | **방향이 반대** — 오히려 올라가야 후보가 된다 |
| 오늘 매수 가능 | **스스로 모순** — 지금 가능한데 "눌린 뒤 다시 후보" |
| 눌림목 매수 대기 · 과열 해소 대기 | 참 |

라운드 221(*'불가' 한 낱말이 셋을 뭉뚱그렸다*) · 라운드 298(*'표본 대기' 한 문장이 셋을
덮었다*)과 **같은 계열**이다. 이번엔 채팅에서 나왔다.

### 고침 — 갈래가 정하고, 사유는 이미 있던 것을 읽는다

- '오늘 매수 가능' → 그 줄을 **안 쓴다**(모순이었다).
- '돌파 후 매수 대기' → **돌파가 회복**을 말한다(같은 문장이 `_ans_price_buy` 에 이미
  있었다 — 두 답이 다른 말을 하고 있었다).
- '눌림목·과열' → 종전 문장 그대로(참이다).
- 그 밖 → **중앙 판정이 결론과 함께 내던 사유**(`exclude_reason` · R240)를 읽는다.
  못 받으면 *"이 갈래는 가격이 눌린다고 풀리는 조건이 아닙니다 — 사유를 받지 못해
  언제 다시 보는지 말하지 않습니다"*(§3). **새 문장을 짓지 않았다**(§4).

**고친 뒤: 서로 다른 마지막 줄 8개 / 9갈래.**

## 3. 내 판별식이 또 넓었다

첫 셈에서 *"반대 근거 있음 9/9 · 바뀔 조건 있음 9/9"* 가 나왔다 — 틀 문장에 `이유:` 와
`이하` 가 **늘** 들어 있어서다. 그대로 적었으면 *"다 붙어 있다"* 는 거짓 보고가 됐다.
낱말 세기를 그만두고 **마지막 줄을 그대로 보는** 방식으로 바꾸자 9갈래가 한 문장이라는
것이 한눈에 보였다. **넓은 판별식은 제 잘못을 감춘다**(R194 · R274 의 그 자리).

## 4. 규칙으로 남기는 것

- **한 문장이 여러 갈래를 덮으면, 그중 하나에서는 대개 거짓이다** — 이 저장소에서 세
  번째다(R221 · R298 · R305).
- **통과한 시험도 잠근다.** 지금 참인 성질(유도 저항)은 구조 덕분이고, 구조가 바뀌면
  말없이 사라진다.
- **갈래를 세는 판별식은 낱말이 아니라 그 줄 자체를 본다.** 틀 문장에 들어 있는 낱말로
  세면 전부 '있음'이 나온다.
