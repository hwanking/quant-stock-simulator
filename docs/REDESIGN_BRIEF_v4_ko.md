# 재설계 브리프 v4 — 제품형 운영 UX (2026-08-01)

> 핵심: "분석형 제품을 대기업 SaaS/금융 플랫폼처럼 — 업데이트와 주요 이슈까지
> 제품답게 운영되는 구조". UI 미화가 아니라 제품 구조 + 정보 설계 + 업데이트
> UX + 이슈 UX를 함께 잡는다.

## 지적 3가지
1. 정보 우선순위 약함 — 뭐가 제일 중요한지 한눈에 안 들어옴
2. 디자인 일관성 약함 — 카드·색·테두리·강조 방식 과다
3. **운영 제품 느낌 부족 — "업데이트 내역", "주요 이슈", "전체 보기" 같은 제품형 UX 부재**

## 톤앤매너
대기업 금융 서비스 / 프리미엄 SaaS 대시보드 / 화려함보다 정돈감 /
중요한 것만 크게, 나머지는 조용하게 / 같은 수준 정보는 같은 스타일 /
이모지 대신 통일 아이콘 / 결론 먼저, 세부는 펼쳐보기.

## 정보 순서
결론 → 행동 → 핵심 근거 → **이슈** → 검증 → 상세

## 업데이트 내역 (제품형 Release Notes) — 필수
- 상단 요약: 최근 업데이트 N건 · 최신 버전 · 최근 핵심 변경 2~3개
- 리스트: 날짜 / 버전 / **카테고리** / 제목 / 자세히 보기·접기
- 카테고리: 데이터 / 모델 / UI·UX / 뉴스 분석 / 추천 로직 / 케이스 스터디 /
  버그 수정 / 성능 개선
- 최신 3~5건 메인 노출 + **"전체 업데이트 보기"** (필터: 전체/모델/데이터/UI·UX/뉴스/버그)
- 원천은 커밋 로그(손으로 쓰지 않음 — 기존 원칙 유지), 카테고리는 규칙 분류

## 주요 이슈 (Key Issues) — 필수
- 제목 "주요 이슈" · 부제 "오늘 꼭 봐야 할 핵심 변화" · 우측 "전체 보기"
- 카드: 유형 / 중요도 / 제목 / 한 줄 설명 / 관련 종목·시장 / 생성 시각
- 유형: 시장 / 뉴스 / 추천 / 데이터 / 모델 / 리스크 / 시스템 공지
- 중요도: 높음 / 중간 / 낮음
- 메인에 최근 3건 요약 + 전체 보기(중요도·유형 필터, 최신순, 해결 여부)
- **이슈는 실데이터·실경고에서만 생성** (예: 고신뢰 표본 부족, 검증-블라인드 괴리,
  지수 미수신, 뉴스 위험 낱말, 게이트 차단 사유, 과열 보류) — 날조 금지
- 역할 구분: 이슈 = 지금 중요한 것 / 업데이트 = 그동안 바뀐 것. 서로 연결
  (모델 변경 → 둘 다, 데이터 지연 → 이슈 먼저·해결 후 업데이트 기록)

## 종목 상세에도 이슈
종목 관련 요약 2~3개(뉴스 변화·점수 변동 이유·추천 제외 이유·데이터 경고·과열)
+ 전체 이슈/뉴스/판정 근거 보기 버튼.

## "전체 보기" UX 통일 (공통 컴포넌트)
최근 3건만 보기 + 전체 보기(펼치기/모달) + 섹션 헤더 우측 CTA — 주요 이슈·
업데이트·뉴스·케이스 스터디·과거 검증 전부 같은 패턴.

## 홈 화면 순서 (v4 확정)
①상단 헤더 ②오늘의 한 줄 브리핑 ③오늘의 추천 1~3위 ④내 보유종목 요약 알림
⑤**주요 이슈 (요약 3 + 전체 보기)** ⑥**최근 업데이트 (요약 3~5 + 전체 보기)**
⑦시장 지표 요약 ⑧모델 상태 요약 ⑨상세 분석 링크.
지수·적중률 숫자가 첫인상을 지배하지 않게.

## 디자인 세부 (꼭)
네온 제거 / 외곽선 남발 제거 / 동일 여백 시스템 / 카드 높이·정렬 통일 /
섹션 헤더 통일 / 상태 라벨(정상·경고·오류) 통일 / 문구 정제 / 반복 삭제.
피할 것: 카드별 색 테두리, 이모지 과다, 큰 숫자 남발, 긴 보고서 펼침, 제목 장식.
