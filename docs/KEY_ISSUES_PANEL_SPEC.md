# 주요 이슈 패널 명세 (v4 — 구현됨: product_ops.build_global/stock_issues)

## 원칙 (날조 금지)
이슈는 **이미 계산된 실측·실경고의 재표현만** — 새 판단·예측 문장을 생성하지
않는다. 예측성 이슈(예: "미국 기술주 약세로 변동성 확대 가능")는 그 판단을
산출하는 검증된 파이프라인이 생기기 전까지 만들지 않는다.

## 유형 7종 / 중요도 3단계
시장·뉴스·추천·데이터·모델·리스크·시스템 공지 / 높음·중간·낮음(정렬 기준).

## 생성 규칙 표 (전역 — build_global_issues)
| 조건 (데이터 원천) | 유형 | 중요도 |
|---|---|---|
| 고신뢰(60+) 블라인드 n<30 (calibration.json) | 모델 | 높음 |
| 검증-블라인드 적중률 괴리 ≥10%p (calibration.json) | 모델 | 높음 |
| 지수 미수신 (m_indices N/A) | 데이터 | 높음 |
| 매수권 신호율 <5% (signal_frequency) | 추천 | 중간 |
| 시장 국면 약세 라벨 (market_ctx) | 시장 | 중간 |

## 생성 규칙 표 (종목 — build_stock_issues)

|---|---|---|

## 노출 규칙
홈·종목 상세 모두: 중요도순 요약 **3건** 카드(뱃지: 중요도+유형, 제목, 한 줄
설명, 생성 시각) → 3건 초과 시 expander "전체 이슈 보기 (n건)" 표
(중요도·유형·범위·생성 열 — 필터는 표 정렬로 대체, 확장 시 selectbox 추가).
카드 테두리는 '높음'만 neg 색, 나머지 중립(DESIGN_SYSTEM_V2 규칙).

## 확장 백로그
해결 여부 상태 저장(이슈 지속 기록 파일), 관련 버전 연결, 유형 필터 selectbox.
