# 결과 R319 — 죽은 칸 16개를 전부 봤다 · 살아 있는 × 1.03 은 **도달 불가**였다 (2026-09-16)

R313 은 *"아무도 안 읽는 칸 16개는 **후보**이고, 둘만 눈으로 확인했다"* 고 적었다.
**확인 안 한 것을 확인했다고 적지 않는다**(§3) — 그러니 나머지 열넷을 열어야 끝난다.

## 1. 열넷의 정체

| 갈래 | 칸 | 뜻 |
|---|---|---|
| 이름표·설명 글 | `value_floor_basis` · `entry_levels_note` · `target_trajectory_20d_note` · `sq_grade` | 해가 없다 |
| 진짜 값인데 안 읽힘 | `entry_premium_pct` · `timing_weight_sum` · `context_` 다섯 · `relative_momentum_12_1` · `m10_val` | 같은 재료의 **다른 칸은 읽힌다**(`context_cap` · `rel_mom_detail` · `m10_status` …) |
| **손으로 고른 수** | `buy_entry_range_str` | `권장 매수가 × 0.97 ~ 권장 매수가` 를 '매수 구간'이라 만든다 — **3% 띠 · 근거 없음** |

R313 의 `target_trajectory_20d`(× 1.03)에 이어 **두 번째 손으로 고른 수**다. 둘 다 아무도
안 읽는 것이 다행이다.

## 2. 같은 모양을 저장소 전체에서 찾았다 — 살아 있는 자리가 있었다

`× 1.03` 을 전체에서 찾자 1차 목표 계산이 나왔다:

```python
if risk_abs > 0:
    ... 손절 거리 기반 목표 ...
else:
    target_tech_1st = float(curr_price * 1.03)     # 손으로 고른 3%
    ...  target_struct = float(curr_price * 1.05)  # 손으로 고른 5%
```

`risk_abs = 현재가 − 손절가` 가 0 이하면 탄다. 계산부(§1)라 **고치기 전에 셌다**(§2-7):

```
원장 251,528행 중 목표 = 현재가 × 1.03 (원 단위 일치)    715행
원장 251,528행 중 손절가 ≥ 현재가 (그 갈래의 조건)       0행
```

**715행은 우연한 일치다.** 예시 다섯이 전부 손절이 현재가 아래(정상 갈래)였고, 정상
갈래가 전형적인 변동성에서 +3% 근처에 떨어지는 것은 이상하지 않다. **값으로 재면 715건의
'지어낸 목표'를 발표할 뻔했고, 조건으로 재니 0이다.** 이 프로브는 그 경고를 **미리**
적어 두었다(*"원 단위 일치는 우연히 같은 값도 잡는다 — 손절 조건과 같이 본다"*).

## 3. 0 인 이유는 표본이 아니라 **구조**다

```
base_risk = 현재가 × max(손절 바닥, 변동성 × 배수)
손절 바닥  = 규칙집 stop_floor_pct(3.0%) × 국면 stop_mult(최소 0.7) = 2.1%
```

바닥이 2.1% 라 손절 거리는 **늘 0보다 크다**(TDST 지지로 바꿔도 0.5R~1.5R 안이라 여전히
양수). 즉 그 갈래는 **지금 규칙에서 도달 불가**다 — 원장이 못 담는 짧은 이력 종목에서도
마찬가지다(원장이 안 잰 자리를 추론으로 메우는 것이 아니라, 식이 그렇다).

## 4. 고친 것 — 코드가 아니라 **그 갈래를 막고 있는 두 사실**

코드는 **안 고쳤다.** 도달 불가 갈래를 지워도 관측되는 것이 없고, 계산부다(§1).

대신 §328 이 **그 갈래를 막고 있는 것**을 잠근다:

- 규칙집 `stop_floor_pct` 를 **읽어서** > 0
- 국면 `stop_mult` 를 **표에서 유도해**(손 목록 아님) 최소 > 0
- 심기 양방향 — 변동성 0 · 최저 배수에서도 거리가 양수 / 바닥 0 · 변동성 0 이면 거리 0
- 엔진의 손절 식이 심기와 같은 식인지 소스로 확인

누가 둘 중 하나를 0 으로 만들면 **이 절이 먼저 붉어지고**, 그때 +3%·+5% 가 살아난다.

## 5. 남기는 것

> **값이 같다는 것은 그 식으로 만들어졌다는 증거가 아니다.** 어느 갈래에서 나왔는지는
> **조건**으로 가른다. 그리고 조건이 0 이면 **왜 0 인지**(표본인가 · 구조인가)를 따로 본다 —
> 표본이 0 이면 "아직 안 나왔다"이고, 구조가 0 이면 "나올 수 없다"다.
