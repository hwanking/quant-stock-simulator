# 결과 R235 — 이동평균선 이름에 이동평균이 아닌 값이 들어 있었다 (2026-09-08)

사용자 지적: *"같은 60일선이 한 행에서는 267,537원, 다른 행에서는 263,843원이다. 횡보 목표가가
지지선보다 낮다. 하락 시나리오인데 손절이 진입가다."* 파 보니 셋 다 같은 뿌리였다 — **표가
현재가에 변동성 배수를 곱한 값에 이동평균선 이름을 붙이고 있었다.**

## 1. 무엇이 있었나 (실측 · 삼성전자 · 현재가 270,000원 · vol_20 ≈ 4.56%)

| 화면에 적힌 이름 | 실제로 쓰인 식 | 실제 이동평균인가 |
|---|---|---|
| 20일선 복귀 276,157원 | `현재가 × (1 + 변동성 × 0.5)` | 아니다 |
| 60일선 지지 267,537원 | `현재가 × (1 − 변동성 × 0.2)` | 아니다 |
| 60일선 종가 이탈 263,843원 | `현재가 × (1 − 변동성 × 0.5)` | 아니다 |

`tech_df` 에는 **`sma_20`·`sma_60` 이 이미 있는데** 표는 그것을 한 번도 읽지 않았다. 같은
'60일선'이 두 값이 된 이유가 이것이다 — 두 행이 다른 배수를 쓴 서로 다른 변동성 기준선이었다.
사용자가 그 숫자를 이동평균선으로 알고 행동할 수 있다. R164(코드에서 숫자만 뽑아 남의 종목을
만든 것)·R220(첫 매치를 업종으로 기록한 것)과 같은 모양이다 — **못 읽은 것을 다른 값으로
만들지 않는다(§3).**

곁들여 넷:

- **`atr_val` 은 ATR 이 아니다.** `vol_20 = adj_close.pct_change().rolling(20).std()` — 20일
  일간수익률 표준편차다. 고가·저가·전일 종가 갭을 쓰는 ATR 과 정의가 다르다.
- **변동성을 못 받으면 `0.02` 로 가격을 만들었다.** 미수신인데 시나리오 가격이 나왔다.
- **횡보 '1차 목표'가 지지선보다 낮았다** — `현재가 × (1 − 변동성 × 0.5)` 를 목표가로 적었다.
- **하락 행의 손절이 중앙 판정 값이 아니었다** — `현재가 × (1 − 변동성 × 1.0)` 을 "종가 이탈
  즉시 손절"이라 적어, 중앙 판정의 손절선과 다른 숫자가 매도 지시처럼 보였다(§4).

## 2. 고친 것 (표시 전용 · 배수·값·판정 불변)

- 이동평균선 이름에는 **실제 `sma_20`·`sma_60`** 을 넣고, 현재가가 그 위인지 아래인지 적는다.
  없으면 **"확인 불가 (이동평균 미수신)"** — 대체값을 쓰지 않는다. 60일선은 변수 하나를 두 행이
  같이 읽는다.
- 변동성 기준선은 그렇게 부른다. 캡션이 **"20일 일간수익률 표준편차 4.56%"** 라 적고 *"평균 실제
  범위(ATR)가 아니고, 20일 뒤 가격의 예측 구간도 아닙니다"* 를 같이 적는다. 칸 이름도
  '예상 가격 범위' → **'변동성 배수 참고 가격대'**, 제목의 '20일'도 뺐다.
- **변동성 미수신이면 표를 만들지 않는다** (0.02 경로 제거).
- **정합성 게이트**: 상승 1차 참고 목표선이 상승 확인선보다 낮으면 숫자를 억지로 맞추지 않고
  "미산출 — 정합성 미충족"으로 적는다(종전 식은 2차 목표 × 0.95 라 저변동성에서 역전됐다).
- **횡보 행은 목표선을 내지 않는다** — 검증된 횡보 진입계획이 없다.
- **청산 기준은 중앙 판정에서** (`new_stop`·`hold_stop`). 이 표는 손절선을 새로 만들지 않는다.
- 판정하지 않는 수급 조건(외국인 순매수 전환 · 기관 동반 매도)은 **판정하지 않는다고 적는다**.
  RSI 는 실제 값을 적되 *'리셋'의 기준은 정해져 있지 않습니다* 를 붙인다(수급 열은 엔진에
  아예 없다 — `foreign`·`inst` 컬럼 없음).

배수(0.5 · 0.2 · 2.0 …)는 **한 개도 바꾸지 않았다.** 새 문턱을 만들지 않았다(§2).

## 3. 남긴 것 — 다음 라운드의 밸류에이션 큐 (같은 날 앞선 지적 · 코드로 확인 끝)

| 무엇 | 확인한 것 | 자리 |
|---|---|---|
| **근거 없는 −2% 상수** | `raw_target_val = weighted_median * 0.98` — 최초 커밋부터 있고 근거가 없다. R44 가 걷어낸 것은 **다른** 상수(`market_adjustment_pct: -2.0`)였고 이것은 **생존자**다 | `quant_indicators.py:2599` |
| **'기초 펀더멘털 가치'가 되돌린 값** | `base_fair_value = target_fundamental / 0.98` — 윈저화·클립을 거친 최종값을 0.98 로 나눠 만든 값이라 실제 가중중앙값이 아니다 | `:2687` |
| **모델 이름과 입력 불일치** | FCFF(DCF) = `정상화EPS×0.85` 에 고정 WACC 0.085·g 0.02·계수 0.65 · EV/EBITDA 의 EBITDA = `EPS×1.45+BPS×0.04`(추정) · SOTP = BPS 배수 · EV/Sales&GP = `BPS×1.8+추정EBITDA×10` | `:2452~2501` |
| **'유효 독립모델'** | 여섯이 EPS·BPS·ROE 한 뿌리에서 나온다 — 독립성 검사는 없다 | `:2751` |
| **신뢰도의 뜻이 둘** | `price_axes.TIERS` 는 60~79 = '제한적', 엔진은 ≥70 = '정상 표시' — 같은 77점에 두 이름 | `price_axes.py:41` · `:2728` |
| **'OOS 보정성능'** | 적정가 오차가 아니라 `compute_strategy_quality`(전략 품질)를 10% 가중으로 쓴다 | `:2711` |
| **체결률 79.3% · 3.4일** | 이번 종목 값이 아니라 라운드 25 결과를 적어 둔 고정 문자열 | `price_axes.py:287` |
| **`missing_inputs`** | 여섯 지표(부채비율·PBR·PER·ROE·BPS·EPS)만 본다 — "미수신 입력 없음"이 DCF 자료까지 있다는 뜻이 아니다 | `:2318` |

사용자 지적 중 **하나는 사실과 달랐다**: *"신뢰도가 편차를 안 본다"* — `모델 합의도`(가중
0.15)가 이미 모델 간 산포를 감점한다(`c_agree = 100 − 평균편차×180 − 중앙·평균 괴리×100`).
화면이 구성요소를 안 보여 줘서 알 수 없었을 뿐이다. **문턱을 새로 만들지 않는다** — 다음
라운드는 구성요소를 화면에 내는 것부터 한다. `0.98` 제거는 **값이 바뀌는 변경**이라 사전등록과
영향 측정이 먼저다(§2).

## 4. 화면 실측 (2026-09-08 · 서버 재기동 뒤 · 다른 종목 · 현재가 25,800원)

| 자리 | 전 | 후 |
|---|---|---|
| 60일선 | 한 행 267,537 · 다른 행 263,843 (둘 다 변동성 기준선) | **두 행 모두 24,302원** (실제 `sma_60`) |
| 20일선 | 현재가×(1+변동성×0.5) | 25,132원 (실제 `sma_20`) · 현재가 위 |
| 상승 참고 목표선 | 2차×0.95 를 그대로 표기 | **"미산출 — 정합성 미충족"** (이 종목 변동성 2.25%에서 실제로 역전됐다) |
| 횡보 목표선 | 지지선보다 낮은 값을 '1차 목표' | 미산출 (검증된 진입계획 없음) |
| 하락 행 청산 | 변동성 기준선을 "즉시 손절" | 중앙 판정 — 신규 24,082원 · 보유자 24,637원 (아래 표 5행과 같은 값) |

**정합성 게이트가 실제로 걸렸다.** 사용자가 "저변동성에서 역전된다"고 예로 든 그 경우가 이
종목에서 그대로 나왔다 — 종전이면 상승 확인선(25,132원)보다 낮은 목표선이 숫자로 나갔다.

그리고 화면을 보다가 **내가 넣은 문구 하나가 뜻이 뒤집혀 있었다**: 하락 행의 확인선을
'무효화선'이라 적었는데, 그 선을 하회하면 하락 시나리오는 **성립**한다. 고쳤다(§252 심기).
회귀만 봤으면 못 잡았다 — 문자열은 통과했고 뜻만 틀렸다.

## 5. 남기지 않은 것 · 남긴 것

- 상승 무효화선과 하락 확인선이 **같은 값**(현재가×(1−변동성×1.0))이다. 배수가 원래 같아서다.
  값을 바꾸면 새 문턱이므로 그대로 두고 이름만 갈랐다.
- 수급(외국인·기관)은 엔진에 컬럼 자체가 없다 — 연동은 새 라운드.
