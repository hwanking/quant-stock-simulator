# 사전등록 R149 — 기준선 대비로 다시 묻는다: 공시가 보통 날과 다른가

**등록일 2026-08-22. 이 문서는 측정 전에 커밋된다 — 커밋 해시가 증거다.**

## 0. 왜 다시 묻나 — R148 이 잣대의 결함을 드러냈다

R148 은 사전등록대로 *"초과수익이 0 보다 큰가"* 를 물어 **양의 알파
0/7 · 기각**을 냈다. 판정은 선다. 그러나 7유형이 전부 "유의(−)"로
나왔고, 사후 진단에서 **비이벤트 기준선도 −0.232%** 였다 — 시가 진입
→ 종가 청산 창에 상수 비용을 얹으면 어느 날이든 음이다.

즉 **"0 대비"는 이 창에서 잣대가 아니었다.** R148 §5 가 적은 그대로,
다음 사전등록의 주 잣대는 **기준선 대비**여야 한다. 이 문서가 그것이다.

**질문**: 같은 날 안에서, 공시가 난 종목의 창 수익이 공시가 없는
종목의 창 수익과 다른가.

## 2. 잣대 (측정 전에 고정)

창은 R148 과 **한 글자도 바꾸지 않는다** — 진입 D+1 시가 → 청산
D+5 종가, 시장(KS11/KQ11) 초과.

날짜 D · 유형 T 에 대해

    Δ(T, D) = mean(그날 T 공시 종목의 창 초과수익)
            − mean(그날 **7유형 어느 공시도 없는** 종목의 창 초과수익)

- 대조군은 **"그날 아무 공시도 없는 종목"** 이다 (7유형 기준).
  T 만 뺀 대조군은 다른 이벤트에 오염되므로 쓰지 않는다 —
  민감도로만 본다(§5).
- **비용은 차감하지 않는다.** 상수라 차분에서 **정확히 상쇄**된다
  (event−control 은 비용 전/후가 같은 값이다). R148 이 비용을 이벤트
  효과로 오독할 뻔한 자리라 여기서는 아예 빼 둔다.
- 판정 통계: Δ(T, D) 의 **부호검정** (0 제외 · 양측) — R110·R147·R148
  과 같은 계열. 표본 단위는 **날짜**다.

## 3. 판정 기준 (측정 전에 고정 — 측정 후 내리지 않는다)

| 기준 | 값 |
|---|---|
| 시험 수 | 7 (유형별 하나) |
| 문턱 | Bonferroni 7 · 양측 α=0.05/7 → z=2.690 → **올림 2.70** |
| 방향 | 양측 — 증자·CB·BW 는 음이 나올 수 있다 |
| 표본 조건 | 유형별 이벤트 **≥ 1,000** 그리고 유효 날짜(이벤트·대조 공존) **≥ 300** |
| 구간 | 개발 = D0 ≤ 2026-01-30, blind = 2026-02-03 ~ 2026-07-15. 개발에서 판정, blind 는 **문턱을 넘은 유형만** 한 번 |
| 미달 시 | 기각, 현행 유지. 창·대조군·잣대를 바꿔 재시도하려면 새 사전등록 |

**방향 해석도 미리 적는다** — 양(+)이면 "그 공시는 보통 날보다 낫다",
음(−)이면 "보통 날보다 못하다". R148 과 달리 이번에는 **음도 실제
발견**이다(기준선이 이미 제거됐으므로). 다만 어느 쪽이든 **운영에
넣지 않는다**(§6).

## 4. 재구현 자기검사 (측정 전에 정한 통과 조건)

이 스크립트는 R148 의 창 계산을 **다시 구현한다.** 베낀 논리가 스스로를
증명하지 못하는 것은 이 저장소가 이미 겪었다. 그래서 재구현이
**R148 의 발표 값을 재현하는지**를 먼저 확인하고, 어긋나면 **측정을
중단한다**:

- 유형별 개발 구간 평균 초과수익 7개가 `data/event_window_r148.json`
  의 값과 **0.001%p 이내**
- 비이벤트 기준선 평균이 **−0.232%** 와 0.001%p 이내

재현이 깨지면 결과를 내지 않는다 — 문턱을 낮추는 것이 아니라 멈춘다.

## 5. 민감도 (판정에 쓰지 않는다 — 기술 통계)

- 대조군을 "T 공시만 없는 종목"으로 바꿨을 때
- 시장(KOSPI/KOSDAQ)별로 나눠 각각 차분한 뒤 평균
- 창을 D+1 / D+3 / D+10 / D+20 으로 바꿨을 때

이 셋 중 무엇이 유의해 보여도 **판정에 쓰지 않는다.** R112 의 교훈 —
표본을 바꾸는 것만으로 ±2 가 움직인다.
