# 결과 R238 — 화면에 없던 고정 −2% 를 계산 사슬로 드러낸다 (2026-09-08)

R235 가 큐로 남겨 둔 밸류에이션 여덟 건 중 **P0 셋**을 처리했다. 값·산식·게이트 낱말은
하나도 바꾸지 않았다 — 이번 라운드는 **숨어 있던 것을 화면에 내는 일**이다.

## 1. 275,844 → 270,327 의 −2.0% 는 어디서 오는가

사용자가 화면의 두 수만 보고 정확히 짚었다. 코드에 있다:

```python
raw_target_val = weighted_median * 0.98
```

**최초 커밋부터 있었고 근거가 코드에도 문서에도 없다.** 라운드 44 가 걷어낸 것은 이것이
아니라 별도의 `market_adjustment_pct: -2.0` 이었다 — 이것은 그 정리에서 **살아남은 자리**다
(R167 의 '지어낸 재무지표 생존자'와 같은 모양).

그리고 화면의 '기초 펀더멘털 가치'는 **최종값을 0.98 로 되나눈 값**이었다
(`base_fair_value = target_fundamental / 0.98`). 윈저화·클립이 걸리지 않은 종목에서는 우연히
가중중앙값과 같지만, 걸리면 달라진다 — 즉 **원인을 결과에서 역산한 라벨**이었다.

**실행으로 확인**(2026-09-08 · 삼성전자 · 실제 파이프라인):

| 단계 | 값 |
|---|---:|
| 모델 가중중앙값 | 275,844원 |
| 고정 보정 −2.0% | **270,327원** |
| 극단값 수축 | 해당 없음 (윈저화·클립 모두 False) |
| 업황조정 0.0% | 270,327원 |

`가중중앙값 × 0.98 == 원시 적정가` 항등식이 성립한다. 사용자가 계산한 −5,517원과 같다.

**고침(이번 라운드):** 상수에 이름을 주고(`FAIR_FIXED_HAIRCUT`) 두 계산 자리가 그것을 부른다.
엔진이 사슬을 그대로 내보내고(가중중앙값 · 보정률 · 원시값 · 윈저화/클립 여부) 화면이 한 줄로
적는다 — *"적정가가 나온 순서 — 모델 가중중앙값 275,844원 → 고정 보정 −2.0% → 270,327원 →
업황조정 +0.0% → 최종 270,327원. 고정 보정은 이 저장소가 처음부터 갖고 있던 값이고 근거가
기록되어 있지 않습니다."* 카드의 '기초 펀더멘털 가치' 라벨은 **실제 가중중앙값**으로 바꿨다.

**지우지 않은 이유:** 지우면 **모든 종목의 적정가가 2% 움직인다.** `entry_zone`·밸류 게이트·
권장 매수가가 그 값을 읽으므로 추천이 바뀐다. §2 가 요구하는 순서는 사전등록 → 영향 측정 →
결정이다. 그때까지 **숨기지 않고 그대로 보여 준다**(§9). 제거는 별도 라운드의 사전등록이다.

## 2. 배너와 상세가 한 화면에서 다른 말을 했다

배너 `진입 위치: 적정가 이하 (안전마진 미확보)` · 상세 `현재가 대비 +0.1% (적정가 부근)`.
둘 다 맞다 — 배너는 `현재가 ≤ 적정가` 를 묻고, 상세는 채택된 ±7% 띠를 쓴다.

**구역 낱말은 못 바꾼다** — `entry_zone` 문자열을 밸류 게이트가 읽는다(R183·R185 블라인드
실측이 '적정가 이하'로 서 있다). 그래서 낱말은 그대로 두고 **배너 문장에 얼마나 아래인지와
엔진이 이미 쓰는 띠 낱말을 같이** 넣었다: *"현재가는 적정가 아래이지만 차이는 +0.1%뿐입니다
(적정가 부근)."* 사용자가 제안한 ±3% 하드코딩은 **새 문턱**이라 쓰지 않았다(§2 · 이미 채택된
띠를 재사용).

## 3. 업황 사유가 세 번 찍혔다

같은 문장이 `업황조정 가치` 절에서 두 번(미연동 분기 + 무조건 분기), 아래 적정가 카드에서 또
한 번. **한 자리에서만** 낸다. 아래 카드는 값만 적고 사유는 위를 가리킨다.

## 4. 사용자 지적 중 하나는 사실과 달랐다 (다시 확인)

*"신뢰도가 모델 간 편차를 안 본다"* — 이미 본다. `모델 합의도`(가중 0.15)가
`100 − 평균편차×180 − 중앙·평균 괴리×100` 으로 산포를 감점한다. 화면이 구성요소를 보여 주지
않아 알 수 없었을 뿐이다. **그래서 "편차 2배 이상이면 신뢰도를 40~50점대로 깎는" 로직은 넣지
않았다** — 그 2배·40~50점은 실측되지 않은 새 문턱이다(§2). 신뢰도 구성요소를 화면에 내는 것이
먼저이고, 그것이 다음 라운드다.
