## ① 89,520건 "안 본 사례" — **가장 중요한 지적** (P0)

> *"Blind 전체가 10,910건인데 특정 점수구간 Blind가 89,520건일 수는
> 없습니다."*

**맞다.** lineage 를 추적했다:

| | |
|---|---:|
| 그 숫자의 출처 | `.portfolio/calibration.json` bands |
| bands 의 n 합계 | **177,042건** |
| = | **학습(153,620) + 검증(12,512) + 블라인드(10,910) 전체** |

즉 89,520은 55~59점 구간의 **전체 리플레이** 표본이지 표본외가 아니다.
"안 본 사례"·"표본외 성적"이라 부른 곳 **다섯 자리**를 전부 정정했다:

- 가늠 AI 문장 → *"리플레이 성적 … (학습·검증 포함 전체 N건 기준)"*
- 판정 근거 표 → *"이 점수대의 리플레이 성적 (학습·검증 포함)"*
- 확률 패널 행 → 동일
- 추천 카드 2곳 → *"과거 동점수대 **리플레이** 적중"*

회귀 §214 가 **값으로** 잠근다 — bands 합계가 블라인드의 3배를 넘는다는
사실 자체를 검사한다(전체 리플레이라는 증거).
진짜 표본외(블라인드 51.3%)는 홈 화면에 따로 있고 그대로다.

## ② 확률 합 128% (P0)

목표 칸만 계층 보정값(약 58% · R59 채택)을 쓰고 손절(50%)·미결(20%)은
유사사례 실측 비율이었다 — **서로 다른 추정치를 한 분할처럼** 그렸다.

**값은 하나도 안 바꿨다.** 세 타일을 같은 표본(유사사례)의 분할로 통일해
**합이 100%** 가 되게 하고, 계층 보정값은 캡션에 **별도 추정치**로 갈라
적는다: *"위 세 칸과 다른 추정치라 그 분할과 합산되지 않습니다."*

(정규화 방안은 쓰지 않았다 — 두 추정치를 섞어 **측정하지 않은 새 숫자**를
만드는 것이라 §3 에 걸린다.)

## ③ KOSPI 하드코딩 (P0)

```python
basis = f"(KOSPI {kp:,.0f} vs …)"      # ← 이름이 박혀 있었다
```

값 838은 그날 **코스닥 지수가 맞다**(라운드 173 이후 시장별로 옳게 받는다).
이름만 하드코딩이었다. ctx 가 이미 들고 있는 `index` 를 라벨이 쓰게 했다.

실측: `index_name='KOSDAQ'` → `(KOSDAQ 838 vs 20일선 809·60일선 857 기준)`.
이름이 없으면 종전 KOSPI 폴백 유지(옛 경로 보호).

## ④ "미산출인데 이하" (P0 — 조건문 버그)

```
현재가가 가치 기준선(적정가−안전마진) 이하
  → 현재 41,350원 / 가치 기준선 미산출
```

비교 대상이 없는데 비교문이 찍혔다. **게이트 판정(미충족)은 그대로 두고**
— 보수성 불변 — 라벨만 갈랐다:

> 가치 기준선 대비 위치 — **기준선 미산출이라 판정 불가**
> 현재 41,350원 · 기준선을 계산하지 못해 위·아래를 판정하지 않습니다

## ⑤ 음수 PER = "저PER 관찰" (P0)

`per < 8` 이 **음수 PER(적자)** 까지 삼켰다. `per <= 0` 분기를 넣었다:

> PER 음수 (적자) — PER 기반 저평가 해석 불가

**점수 쪽은 값 불변이다** — 매력도 산식은 원래 `0 < per` 가드가 있어
(2287·2290·2297) 적자 종목에 저PER 보너스가 들어간 적이 없다.
틀린 것은 표시 문구뿐이었다.

## ⑥ EV≤0 인데 "사세요" (P0 — 가장 심각하다는 지적)

서진시스템 비용 후 기대값 −0.09% 인데 *"38,681원 이하로 내려올 때만
사세요"* 라고 지시했다. 화면 스스로 *"이 엔진의 매수 신호에는 비용 차감
후 재현되는 우위가 확인되지 않았다"* 고 적으면서(§9).

**가격 계산은 안 바꿨다. 문장을 기대값에 따라 가른다:**

| EV | 문장 |
|---|---|
| **> 0** | (종전) …이하로 내려올 때만 사세요 |
| **≤ 0 · 미산출** | **"…는 매수 권고가 아니라 관찰 기준 가격입니다.** 비용 차감 후 기대값이 −0.09%로 양수가 아니라 신규 매수를 권하지 않습니다. 변동성으로 계산한 관찰 기준일 뿐 '싸다'는 뜻이 아닙니다." |

## ⑦ "기업·업황이 나빠서가 아니라" (사실 아님)

> 48점 · 적정가 미산출)도 **함께** 신규 매수를 제한합니다.

## ⑧ 관심종목 자동 이동 (사용자 요청)

평단·수량을 넣으면 보유중 묶음·포트폴리오 견해가 **다음 rerun 에야**
움직였다(묶음이 render 첫머리에서 계산되므로). 저장 직후 `st.rerun()` 으로
**즉시** 이동·반영. 무한 rerun 없음 — rerun 뒤에는 입력값과 저장값이 같아
dirty 가 다시 서지 않는다.
