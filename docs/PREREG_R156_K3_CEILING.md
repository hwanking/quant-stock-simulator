# 사전등록 R156 — k≥3 겹침은 언젠가 판정할 수 있나 (표본 상한)

**등록일 2026-08-22. 이 문서는 측정 전에 커밋된다 — 커밋 해시가 증거다.**

## 0. 왜 이 질문인가

R153 은 겹침 깊이를 늘린 칸(k≥3)을 이렇게 적고 **판정하지 않았다**:

> k≥3 만: 이벤트 **219** · 날짜 **190** · 평균 −0.979%p · z −2.47 —
> **표본 조건 미달**이라 판정하지 않는다. 더 겹칠수록 더 음인 것처럼
> 보이지만 **그 말은 이 표본으로 못 한다.**

그러면 **언제쯤 할 수 있나.** R129 가 순위 연구에서, R155 가 동등성
에서 물었던 것과 같은 질문이다 — **"못 봤다"를 "얼마나 못 봤다"로
바꾼다.**

**질문**: k≥3 겹침을 사전등록 문턱(z 2.25 · 이벤트 1,000 · 날짜 300)
으로 판정하려면 표본이 얼마나 필요하고, 그것이 **물리적으로 가능한가.**

## 1. 이것은 가설 검정이 아니다

새 효과를 주장하지 않는다. **실현 가능성**을 계산한다. 그래서
통과/기각 문턱 대신 **무엇을 어떻게 계산할지**를 미리 못 박는다.
계산식·상수·자기검사를 아래에 고정한다.

## 2. 재료 — R153·R154·R155 와 똑같다

창·매칭 동일(D+1 시가 → D+5 종가 · 시장 초과 · 층 = 시장 × 거래대금
5분위 × 변동성 5분위 · 대조 = 그날 7유형 어느 공시도 없는 종목) ·
개발 구간 D0 ≤ 2026-01-30 · 일봉 1,190종목 · 2014-05-30~.

## 3. 계산할 것 (측정 전에 고정)

| # | 무엇 | 어떻게 |
|---|---|---|
| C1 | 지금 k≥3 표본 | 이벤트·날짜·승률·z (R153 재현) |
| C2 | **z 2.25 에 닿는 날짜** | 관측 승률 p 에서 `n ≥ (2.25 / (2(p−0.5)))²` |
| C3 | **이벤트 1,000 에 닿는 날짜** | 관측 적립률(이벤트/거래일)로 나눠 |
| C4 | 필요 날짜 | max(C2, C3, 300) |
| C5 | **물리 상한** | **3,665일** = 246일/년 × 14.9년 (R129 유도값 재사용) |
| C6 | 종목 축 여력 | 상장 종목수 ÷ 유니버스 종목수 (마스터 스냅샷) |

**C5 는 새 숫자가 아니다** — R129 가 유도해 R155 가 이미 쓴 값을
그대로 쓴다.

## 4. 종목을 늘리면 되는가 — 미리 갈라 적는다

**날짜와 종목은 같은 축이 아니다.** 부호검정의 표본 단위는 **날짜**다.
종목을 늘리면 **하루당 이벤트**가 늘어 그날 추정이 정밀해지지만
**날짜 수는 안 늘어난다.** 그러므로

- 종목 확장은 C3(이벤트 적립)에는 **직접** 도움이 된다
- C2(승률→z)에는 **간접**으로만 — 하루 추정이 정밀해지면 승률이
  0.5 에서 멀어질 수 있다. 그 크기는 **가정 없이는 못 낸다.**

그래서 **가정을 만들지 않고 실측한다**(§5 E1).

## 5. 자기검사와 검증 (측정 전에 정한 통과 조건)

**S1 — 재현**: k≥3 의 이벤트·날짜·평균·z 가 R153 발표값
(**219 · 190 · −0.979 · −2.47**)과 일치해야 한다. 허용 오차
**0.001 / 0.01**. 못 하면 **측정을 중단한다.**

**S2 — 닫힌 식 검증(R129 의 교훈)**: R129 는 닫힌 식과 시뮬레이션이
**19.9%p** 어긋난 적이 있다(둘이 다른 것을 재고 있었다). 그래서 C2 를
**부트스트랩으로 대조**한다 — 날짜를 복원추출로 N일 뽑아 z 를 재는 일을
반복해 `P(z ≥ 2.25) ≈ 80%` 가 되는 N 을 찾는다. **난수 씨앗 20260822
고정**, 반복 **2,000회**.
닫힌 식과 부트스트랩의 **상대 괴리가 20% 를 넘으면** 둘을 나란히 적고
**부트스트랩을 채택**한다(물음이 "이런 날을 N일 모으면"이므로 —
R129 와 같은 판단). 기준을 내려서 맞추지 않는다.

**E1 — 종목 축 실측(판정 아님)**: k≥2 표본에서 **하루당 이벤트 수**로
날짜를 나눠 구간별 승률을 낸다. 하루당 이벤트가 늘 때 승률이 실제로
0.5 에서 멀어지는지 **가정 없이** 본다.

## 6. 결론 형식 (측정 전에 고정)

세 갈래 중 하나로 적는다.

| 결과 | 뜻 |
|---|---|
| C4 ≤ C5 | **언젠가 가능하다** — 필요 날짜가 물리 상한 안 |
| C4 > C5, 종목 확장으로 C3 해결 가능 | **부분적으로 가능** — 이벤트는 채워도 **날짜(C2)가 벽**이면 여전히 불가 |
| C4 > C5 | **불가능하다** — 모든 거래일을 다 모아도 판정 못 한다 |

어느 쪽이든 **효과를 주장하지 않는다.** 이 문서는 *"k≥3 이 더
나쁘다"* 를 말하지 않는다 — R153 이 판정하지 않은 것을 판정하지
않은 채로 둔다.
