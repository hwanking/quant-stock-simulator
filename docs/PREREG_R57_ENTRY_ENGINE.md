# 사전등록 — 라운드 57: Entry Engine (측정 전 고정)

작성: 2026-08-09. 이 문서 저장·커밋 후에 측정한다.

## 0. 배경 — 이미 잰 것

케이스 스터디 2호(2026-08-09): 고정 % 깊이 지정가는 **역선택**이다 —
깊을수록 체결분 성과가 나빴고(−1% +1.171 → −7% +0.414), 최고의 신호는
눌림을 주지 않았다(미체결분 +15.8). 따라서 이 라운드는 고정 %가 아니라
**시장 구조 기준선(ATR·이동평균·피벗·볼린저)** 을 후보로 잰다. 구조
기준선이 %와 다른 것은, 기준선 위에서 체결되는 것은 "지지가 살아 있는
눌림"이고 뚫고 내려간 종목은 체결 자체가 안 되기 때문이다 — 같은
역선택이 나오는지가 이 라운드의 핵심 질문이다.

## 1. 진입 후보 (고정 — 표준 정의만, 튜닝 숫자 없음)

신호일 종가(기준가) 이전 봉으로만 계산 (누출 금지):

| 후보 | 정의 |
|---|---|
| 즉시 | 기준가 (다음 봉 시가 근사) |
| 현행 눌림가 | 기준가 × (1 − vol20) — **기준선** (라운드 25 채택) |
| ATR 0.5·1.0 눌림 | 기준가 − 0.5/1.0 × ATR14 |
| MA5 / MA20 | 신호일 5·20일 이동평균 |
| BB 중앙 / 하단 | 20일 볼린저 중앙선 / −2σ |
| 피벗 지지 | 직전 10봉 최저 low |
| 전고 돌파 재지지 | 직전 20봉 최고 high (돌파 후 그 선까지 되눌림) |

기준가보다 **위**인 후보(예: 상승 중 MA5)는 그 신호에서 제외 — 눌림
대기의 뜻이 없다. 돌파 재지지만 예외(위에서 걸고 기다리는 후보가 아니라
돌파 확인 후 되눌림 체결).

## 2. 측정 (고정)

- 데이터: 개발 매수권(58+) · 판정완료 · 블라인드 제외 · 경로 21봉
- 체결 = 신호 다음 봉부터 low ≤ 후보가 (돌파 재지지는 high ≥ 전고 확인
  후 low ≤ 전고). 같은 봉 동시 조건은 보수적으로 미체결 처리
- 후보별: 3/5/10/20봉 체결률 · 체결 후 20봉 종가 순EV(비용 0.36%p) ·
  양수 마감률 · PF · 체결 중앙 봉 · **미체결분 기준가 매수 시 순EV**
  (기회비용 — 2호에서 이것이 결론을 뒤집었다)
- 정책 평가는 "그 후보에 걸고, 미체결이면 매수 안 함"의 **신호 전체
  EV**(체결 EV × 체결률)로도 본다 — 체결분만 보면 역선택을 놓친다
- σ 단위 보고 병행: 후보가의 깊이를 vol20 로 나눠 σ 로도 기록

## 3. 선택·게이트 (고정)

- train 에서 후보 비교표 작성 → **valid 1회**로 기준선(현행 눌림가)과 대조
- 채택 게이트 (전부 충족): valid 에서
  1. 신호 전체 EV > 기준선 신호 전체 EV
  2. 체결률(20봉) ≥ 50% — 못 사는 진입가는 진입가가 아니다 (라운드 25)
  3. PF > 기준선 PF
  4. 체결분 순EV > 0
- 국면(코스피 4상태)별 분할표는 **보고만** 한다 — 국면별 라우팅 채택은
  표본 확인 후 별도 증분 가설 (R55 전례)
- 미달이면 기각·현행 유지. blind 미사용. 확인은 전방 축적분

## 4. 채택 시 (미리 고정)

- 화면의 다층 매수구간(공격/선호/가치)은 **게이트 통과 후보로만** 구성
- 각 층에 체결률·체결 후 EV·근거(어느 기준선인가)를 병기
- versioning.release(axis='model', kind='algorithm') + 2주 전방 병행
