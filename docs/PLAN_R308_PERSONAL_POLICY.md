# 계획 R308 — '개인 투자정책' 은 계산이 아니라 **빈 칸**이 없는 것이다 (2026-09-16 · 측정)

사용자가 붙여 넣은 분석문의 남은 제안 중 하나다:

> *"가늠에 **개인 투자정책**을 넣는 것은 좋습니다. 다만 개인 성향을 주가 예측에 섞으면
> 안 됩니다. … 저장 항목은 **보유 목적·투자기간·허용 손실·종목 및 업종 비중 제한·
> 추가매수 가능 자금·레버리지 사용 여부** 정도입니다. **모르는 값은 임의로 정하지 않고
> 비워두거나 필요한 때 확인합니다.**"*

**만들기 전에 셌다**(R288 의 규칙 — 간밤 시황에서 재료가 이미 다 있었던 그 자리).

## 1. 엔진 쪽은 여덟 중 일곱이 **이미 있다**

유도 모듈 39개를 훑었다(2026-09-16):

| 분석문의 항목 | 저장소에 | 어디 |
|---|---|---|
| 투자기간(지평) | **있다** | `horizon_days` · `HORIZON_BARS` (20봉) |
| 허용 손실 | **있다** | `hold_stop` · `new_stop` · MDD |
| 종목 비중 제한 | **있다** | `suggested_position_pct`(변동성 관리 비중) |
| 업종 비중 제한 | **있다** | HHI · 업종 비중(포트폴리오) |
| 현금 비중 | **있다** | 위험예산의 현금비중 |
| 추가매수 자금 | **있다** | 물타기 6조건(`personalize_for_position`) |
| 레버리지 사용 | **있다** | `ETF_LEV`/`ETF_INV` 상한 |
| **보유 목적** | **없다** | — |

## 2. 그런데 **사용자가 넣는 값**은 넷뿐이고 전부 '보유 사실'이다

화면의 입력 위젯을 전수로 세니:

- 숫자 입력 **4** — 매입가 · 수량 · 평균 매수가 · 보유 수량
- 고르기 6 — 전부 **화면 필터**(후보 발굴 방식 · 점수대 · 국면 …)
- 라디오 1 — *"이 종목을 갖고 계신가요?"*
- 토글 2 — 편집 · **손절 폭 좁게(0.6배)**(R293)

**투자 성향·제약을 넣는 자리는 하나도 없다.** 즉 이 일은 *계산을 새로 만드는 것*이
아니라 **사용자의 제약을 받는 칸을 만들고, 이미 있는 엔진 값과 견주는 것**이다.

## 3. 그래서 오늘은 **안 만들었다** — 그 값은 사용자만 안다

허용 손실 · 투자기간 · 비중 한도 · 레버리지 허용은 **사람의 값**이다. 내가 기본값을
고르면 그 순간 **손으로 고른 숫자**(§2)이자 **지어낸 값**(§3)이고, 분석문도 같은 말을
한다(*"모르는 값은 임의로 정하지 않는다"*). 그래서 **빈 칸으로 두고 화면이 묻는** 구조가
유일하게 정직한 형태다 — 그 화면의 모양은 쓰는 사람이 정하는 것이 맞다.

## 4. 만들 때의 설계 (측정에서 나온 것만)

1. **저장 자리 하나** — 관심종목·보유가 쓰는 파일 규약을 그대로 쓴다(화이트리스트에 키를
   넣지 않으면 재시작에 사라진다 · R223 이 겪은 자리).
2. **모르는 값은 `None`**, 화면은 *"미입력 — 넣으면 적합성을 같이 봅니다"*(§3).
3. **두 줄로 가른다**(분석문 그대로):
   · **종목·전략 평가** — 이 조건에서 검증된 우위가 있는가 (지금 화면이 하는 일)
   · **내 투자정책 적합성** — 기간·위험·비중이 내 원칙에 맞는가 (새로 붙는 줄)
4. **예측에 안 섞는다** — §9 가 평단에 대해 이미 정한 규칙을 그대로 넓힌다. 검사로
   잠근다: *정책 값을 바꿔도 점수·적정가·확률·bucket 이 한 자리도 안 바뀐다*(R23 의
   평단 불변 검사와 같은 모양 — 이미 회귀 §23 에 그 틀이 있다).
5. **투자기간이 다르면 같은 확률을 쓰지 않는다** — 엔진의 창은 20봉이고(R300 이 그
   경계를 화면에 그었다) 다른 기간의 확률은 **그 기간으로 검증된 것만** 쓴다. 없으면
   *"그 기간은 검증하지 않았다"* 고 적는다.

## 5. 남은 제안들의 상태 (같은 분석문)

| 제안 | 상태 |
|---|---|
| 중앙 판정과 채팅의 일치 | **했다** — R304(53%→0%) |
| 유도 저항 시험 | **했다** — R305(통과 · 잠금) |
| '판단이 바뀔 조건' | **했다** — R305(9갈래 한 문장 → 8개) |
| 반증 점검의 나머지(확인된 사실·유리한 근거) | 안 함 — 재료는 `gate_checks` 에 있다 |
| **개인 투자정책** | **이 문서** — 빈 칸은 사용자의 값 |
| 근거 묶음(evidence_id) | 안 함 — 스냅샷·계보는 있고 답변에 잇는 일이 남았다 |
| 판단 변화 보고 | 안 함 — 전방 기록부가 재료다 |
| 메신저 알림 · MCP · 외부 LLM | **안 한다** — §9 와 충돌 · 사람의 결정이 먼저 |
