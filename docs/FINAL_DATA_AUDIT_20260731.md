## 발견한 문제 (심각도 순)

### 1. [높음] 뉴스·촉매 모듈이 수집하지 않은 사건·출처를 날조
- 종목코드 해시로 '신사업 진출', '공급망 재편 수주 확대' 등 4개 문구 중 하나를 자동 부착
- 출처를 "KRX & 실시간 종합 시황", "DART 공시 & 증권사 리서치 컨센서스",
  "기업 IR 공식 보고서"로 표기 — **그 어떤 것도 조회하지 않음**
- 수급 데이터 없이 "강한 매수세 유입", "차익매물 출회" 원인 단정
- 수정: `bitemporal_engine.get_timeframe_news_analysis` 전면 재작성 —
  가격·거래량 **관찰**과 게시 지표의 **정량 해석**만 서술, 미연동 사실 명시.
  쓰이지 않던 날조 `TIMEFRAME_NEWS_DB` 블록도 제거.

### 2. [높음] 코스닥 종목의 기준가가 낡은 시드 값으로 위장
- `fetch_and_update_naver_realtime` 이 티커를 무조건 `.KS`로 등록 →
  `086520.KQ` 조회 시 신선한 시세(79,100원)는 `.KS` 키에, 파이프라인은 `.KQ` 키의
  **시드 리터럴 358,500원**을 "네이버증권 기준가(정상)"로 사용 (오차 78%)
- 수정: 입력 접미사 보존. 수정 후 기준가=교차=일봉 모두 79,100원 일치.
- 이 결함은 §40에서 추가한 **스캐너 교차검증 게이트가 실전에서 잡아낸 것**이다.

### 3. [중간] 원천 일봉의 결함 봉이 무검증 통과
- 거래정지 기간 봉이 o=h=l=0 으로 수신됨 (삼성전자 2018-04-30~05-03 액면분할 정지)
  → 0원 저가가 ATR·DeMARK·저점 계산 오염 가능
- 종가가 고가보다 1원 높은 피드 반올림 불일치 3봉 (2015~2016)
- 수정: 적재 시 거래정지 봉은 **제외**(가격을 만들지 않음), 반올림 불일치는
  같은 봉의 자기 값으로 고저 정의 복원.

### 4. [중간] 확률 표기 모순
- 표본 23건(확률 허용)인데 패턴 탭만 "산출 불가 — 기준 미달" 표시.
  원인: 존재하지 않는 `sim['win_rate']` 키 참조 → 항상 None
- 목표 8.7% + 손절 43.5% = 52.2%만 표시 — 나머지 47.8%가 무엇인지 미표시
- 수정: 탭 판정은 엔진의 `probabilities_shown`·`bayes_prob` 사용.
  `no_touch_prob`(미도달) 범주 신설 — 세 범주 같은 분모, 합 100%.

### 5. [중간] 실행 가격의 기준 혼용
