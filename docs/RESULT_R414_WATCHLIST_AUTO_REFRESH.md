## 고친 것

**① 재는 길 하나 — `watch_refresh.py`.** 채우기 버튼 본문(스냅샷 → 중앙 판정 → 값 묶음 → 물타기 6조건 → 보유 계획 갱신 →
병합)을 모듈로 옮겼다. 화면의 채우기 버튼 · 표의 '지금 재기' 링크 · 밤 스크립트가 **같은 함수**를 부른다(§4 — 라운드 169 가
경로를 베끼다 한 단계를 빠뜨린 자리를 두 번 만들지 않는다). 화면에 남은 `_wl_avg_down_snap`·`_fair_reach_snap`·
`_wl_needs_fill` 은 모듈을 부르는 껍데기다. 종목 상세의 스탬프 자리(라운드 141)는 그대로다.

**② 무엇을 다시 재나 — 문턱 없음.** 채우기 버튼이 모자라다고 보던 갈래(라운드 166~387 그대로) + 엔진 값 기준일이 **그날의
확정 분석 기준일보다 앞선 행**. 기준일은 앱과 같은 한 곳(`bitemporal_engine.resolve_analysis_date` · 장 마감 뒤면 오늘 ·
장중·휴장이면 직전 거래일)이고 **못 구하면 안 잰다**(§3). 매 거래일 한 번이면 옛 규칙 스탬프·옛 이름 칸(R327·R387·R396 이
읽는 쪽에서 가르던 것)은 다음 거래일 밤에 새 규칙으로 바뀐다 — 개장 전 리포트·전방 기록기와 같은 하루 주기다.

**③ 보유 계획은 밤 갱신이 스스로 안 바꾼다.** `portfolio.hold_plan_update` 가 정한 대로만 — 잰 날에 고정 · 1차 매도가에 닿거나
창이 끝나면 다시 잼 · **손절선을 넘긴 계획은 그대로**(사용자 결정 2026-09-28 · 라운드 373). 밤 작업은 `remeasure=False` 이고
사람이 누르는 '기준 다시 재기'만 True 다(§402 가 세 갈래를 심어서 잰다).

**④ 저장은 행마다 그 자리에서.** 파일을 **다시 읽어** 그 종목의 스냅샷 칸만 바꾸고 바로 쓴다 — 15~20분 사이에 사용자가 저장한
매입가·수량을 옛 복사본으로 덮지 않는다. 못 낸 값(None·'')으로 옛 값을 지우지 않는다(라운드 141 의 규칙 · `merge_into` 한 곳).
`portfolio.save_watchlist` 는 임시 파일에 다 쓰고 통째로 바꿔 끼운다(반쯤 쓰인 파일을 상대가 읽지 않게).

**⑤ 세션이 파일을 따라간다.** 앱은 관심종목을 세션에 한 번 읽고 제 복사본만 봤다 — 그대로면 밤의 갱신 뒤 사용자의 다음
저장(`_wl_write`)이 옛 스냅샷으로 파일을 덮는다. 파일 수정시각이 세션이 읽은 때와 다르면 다시 읽는다(앱 자신의 저장은
수정시각을 같이 적어 두어 안 되읽는다).

**⑥ 산출물로 센다.** 실행마다 `.portfolio/watch_refresh_log.jsonl` 한 줄(때 · 기준일 · 다시 잴 행 · 잰 행 · 실패 목록 · 초).
관심종목 절이 그것을 읽어 *"자동 갱신 — 마지막 실행 … · 다시 잴 행 N 중 M 갱신 · 실패 k"* 를 적고, 기록이 없으면 **없다고**
적는다(라운드 412 — '켜져 있다'가 아니라 '산출물이 생겼다'로 센다). 백업 DENY 에 `watch_refresh*`(어느 종목을 쟀는지는 이
PC 에만 · §9).

**⑦ 누가 돌리나 — Windows 작업 스케줄러.** `gaeum-watch-refresh` · 평일 **17:00**(정규장 마감 15:30 뒤 · 시간외 16~20시의
가격은 엔진이 안 쓴다 · R325) · 로그온 중일 때 · 놓친 시작은 PC 가 켜지면 바로(StartWhenAvailable) · 겹치면 새 것을 버림 ·
3시간 상한. **Claude 의 예약 작업이 아니다** — 그것은 라운드 412 가 보인 대로 무인으로 한 번도 일을 못 했다(권한 확인으로
추정). 평범한 파이썬 하나가 묻는 것 없이 돈다. 등록: `scripts/register_watch_refresh_task.ps1`(2026-10-02 등록 · 다음 실행
2026-10-05 17:00).

## 안 바꾼 것

- 값·판정·등급·6조건·선·문턱·산식 — 하나도. 재는 **때**와 **누가**만 바뀌었다.
- 표의 '지금 재기' · '옛 판정 — 지금 다시 재기' · '기준 다시 재기' 링크 — 그대로(지금 당장 재는 길 · 같은 함수).
- 종목 상세를 열 때 찍는 스탬프(라운드 141) · 개장 전 리포트에서 옮겨 적는 스탬프(라운드 142) — 그대로.
- 계산부 파일은 열지 않았다(§1).

## 한계 — 적어 둔다

- PC 가 꺼져 있으면 그날은 안 돈다 — 켜지면 바로 한 번 돈다(그때의 기준일로 · 다음 거래일 장중이면 직전 거래일 값).
- 밤 작업은 엔진 기본 rho(0.80)로 잰다. 사이드바에서 다른 rho 를 골라 둔 세션의 '지금 재기'는 그 값으로 잰다 — 두 판이
  다를 수 있다(종전에도 채우기 버튼은 세션 rho 였다).
- 시세를 못 받은 행은 **실패로 기록**하고 옛 값을 둔다 — 실패 수가 화면 한 줄에 나온다.
- 여기까지가 **이 PC** 의 일이다. 배포 앱의 관심종목은 그 방문자의 것이라(§9) 이 작업이 닿지 않는다.
