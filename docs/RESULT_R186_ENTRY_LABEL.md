# R186 — 진입가의 이름은 중앙 판정이 정한다

**날짜**: 2026-08-30 · **트리거**: 사용자 R184 전수 분석 P1 —
*"'권장 매수가' 명칭은 EV>0 + 게이트 통과 시에만. 아니면 검토 기준가/관찰
진입선."* (서진시스템 스크린샷: 카드가 "매수 후보가 아닙니다"라고 말하며
같은 칸에 '권장 매수가 38,681원'을 내밀었다)

## 무엇이 문제였나

`entry_pullback_price`(변동성 기반 눌림 진입가) 하나가 화면 어디서나
**'권장 매수가'** 로 불렸다 — 추천을 통과했든 아니든. R185 가 판정을
하나로 모았지만 **이름**은 여전히 판정과 따로 놀았다:

- 추천 제외 카드의 가격 줄: `권장 매수가 38,681원`
- easy_advice 가 "매수 권고가 아니라 관찰 기준 가격"이라 말한 분기에서도
  가격표 첫 줄은 `권장 매수가(1차 분할)`
- 배너 머리말이 "오늘은 실행 자리가 아닙니다"인데 그 아래 줄은
  `매수구간 · 이 값 이하에서만`
- 관심종목 열 이름 `1차 목표(권장가)` — 추천 아닌 종목이 절반인 목록
- **다른 값이 같은 이름**: 안전마진 상자가 `buy_entry_max`(적정가−안전
  마진)를 '권장 매수가'라 불렀다 — 배너의 권장 매수가(실행 진입가)와
  다른 값이다 (quant_indicators:3860 주석이 지목해 둔 그 결함)

## 고침 — 이름을 한 곳에서 (새 숫자 0개 · 가격·판정 불변)

1. **`verdict_core.entry_label`** 신설: `recommended`(11조건 전부 통과)일
   때만 `'권장 매수가'`, 아니면 `'검토 기준가'`. 화면이 각자 정하면 §4
   위반이라 중앙 판정이 정한다.
2. **카드**(`ui_kit.reco_card`): 줄 이름을 `rec_label` 데이터로 받고
   **기본값은 '검토 기준가'** — 호출부가 라벨을 빠뜨렸을 때 과장(추천
   아닌데 권장)이 축소보다 나쁘다(라운드 120e 의 기본값 기준). 산문
   ("현재가는 …보다 N% 높습니다")도 같은 라벨을 쓴다.
3. **배너**(`trade_plan` → `ui_kit.trade_plan_card`): recommended 가
   아니면 `매수구간 · 이 값 이하에서만` 대신 `검토 기준가 · 매수 지시
   아님 — 조건 충족 시 검토`.
4. **easy_advice 가격표**: 매수를 실제로 권하는 분기(지금 사도 됩니다 ·
   EV>0 눌림)만 `권장 매수가(1차 분할)`, 나머지는 `검토 기준가(1차 분할)`.
5. **안전마진 상자**: `buy_entry_max` 를 R184 게이트 라벨이 이미 쓰는
   **'가치 기준선(적정가−안전마진)'** 으로 통일 (§2 재사용 — 새 이름
   아님). 전문가 밸류 표의 '권장 매수가 조건' → '가치 기준선 조건'.
6. **기준 표기 통일**: 카드 하위 표기 `권장가 기준` → `진입가 기준`
   (verdict_core.price_basis 의 낱말), 관심종목 열 `1차 목표(권장가)` →
   `(진입가)`, DeMARK·판정근거 안내문의 '권장 매수가' → '진입 기준가'.

## 검사

- **§216** (신규): entry_label 규칙(통과→권장 · 미통과→검토, 실제
  build 로) · 카드 기본값이 검토 기준가 · trade_plan 전달 · 배너 두 분기
  렌더 문자열 · '권장가 기준' 코드 소멸 · 안전마진 상자 명칭.
- §97 갱신: 카드 라벨이 픽스처별 기대값(권장/검토)과 일치 + **반대
  이름이 같은 카드에 없다**. 픽스처 기본값 경로가 검토 기준가로
  떨어지는지 잠근다.
- §59 갱신: 관찰/EV음수 분기 가격표에 '권장' 금지, 매수/EV>0 분기는
  '권장' — 세 분기 모두 실행으로 확인.
- §184 ⓐ 갱신: 열 이름 (진입가) + '권장가' 열 이름 소멸.

## 하지 않은 것

- `verdict_core.checks[0]` 의 조건 이름('권장 매수가 산출')은 그대로 —
  "추천하려면 진입가가 있어야 한다"는 조건 이름으로는 참이고,
  `_bucket` 의 문자열 매칭·기존 검사와 얽혀 있어 이름만 바꾸는 이득이
  없다.
- '목표 매수가'(관심종목 엔진 값 열)는 '권장'을 주장하지 않아 유지.
- 가격·판정·게이트는 한 글자도 안 바뀌었다 — 이름만 바뀌었다.
