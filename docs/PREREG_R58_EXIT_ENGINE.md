# 사전등록 — 라운드 58b: Exit Engine (측정 전 고정)

작성: 2026-08-09. 이 문서 저장·커밋 후 측정한다.

## 0. 배경 — 이미 잰 것 (케이스 스터디 1·3·5호)

- 피크 대비 종가 반납 중앙 9.06%p · +5% 밟고 빈손 32.9%
- 어깨 반납은 국면 무관(빈손 32~35% 평평) → **단일 규칙 후보부터** 잰다
- 어깨는 시끄럽다(피크 봉 거래량 중앙 1.58배) · EV 는 20봉까지 단조 증가
  → 이른 전량 청산은 드리프트를 버린다 — 부분 익절 계열이 유망
- 승자의 24%가 목표 전 −3%를 견뎠다 → 타이트한 트레일링은 승자를 죽인다

## 1. 공통 조건 (고정)

- 진입 = 기준가(신호일 종가) — 현행 채점과 동일 기준 (R57 즉시 진입은
  전방 통과 전이므로 섞지 않는다)
- 모든 후보는 **현행 손절(원장 stop)** 을 재난 하한으로 공유. 같은 봉
  목표·손절 동시 도달은 손절 우선(보수 — 현행 KPI 정의와 동일)
- 청산가 근사: 목표/트레일 수준가 체결. 갭 하향 통과 시 그 봉 종가 체결
  (불리한 쪽으로 근사 — 유리하게 근사하지 않는다)
- 지평 20봉 · 비용 0.36%p · 부분 청산은 가중 평균 수익으로 집계

## 2. 후보 (고정 — 표준 형태만)

| 후보 | 규칙 |
|---|---|
| 현행(기준선) | 원장 채점 결과 그대로 (목표=손절거리 0.7배 · 20봉) |
| 고정 +3 / +5 / +7 / +10 | 고가 도달 시 전량 |
| A: +4 전량 | |
| B: +4 에 50% → 잔여 2ATR 트레일링 | ATR = 신호일 ATR14(%) |
| C: +5 에 30% → +8 에 30% → 잔여 2ATR 트레일링 | |
| ATR 트레일링 단독 | 피크 대비 2×ATR14 하회 시 전량 |
| 저점 트레일링 | 직전 5봉 최저 low 하회 시 전량 |
| MA10 이탈 | 경로 내 종가 10봉 평균 하회 시 전량 (10봉 전엔 보유) |
| 타임스탑 10봉 | 10봉째 종가 전량 |

트레일링 배수는 2×ATR14 하나만 — 배수 훑기(0.5~3.0 스캔)는 하지 않는다.
R36 목표 배수 스캔의 교훈: 훑으면 우연을 줍는다.

## 3. 측정·게이트 (고정)

- train 비교표 → 챔피언(순EV 최고) → **valid 1회** 기준선 대조
- 채택 게이트 (전부): valid 에서 ① 순EV > 기준선 ② PF > 기준선
  ③ 승률(양수 마감) ≥ 기준선 − 3%p ④ train 에서도 같은 방향
- blind 미사용. 통과 시 박제 후 **8/23 전방 재평가** (R55·R57과 동일)
- 미달이면 기각·현행 유지
