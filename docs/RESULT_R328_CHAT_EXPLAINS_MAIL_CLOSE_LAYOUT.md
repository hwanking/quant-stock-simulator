# 결과 R328 — 가늠 AI 가 말뜻을 설명한다 · 메일로 물어보기 · 창 닫기/최소화 · 오른쪽 바와 본문 (2026-09-17)

사용자: *"챗봇처럼 나와야 하니깐 바로 말처럼 써 주면서 대답해 줘. 시스템 안쪽에 수정은 안 되지만, 너의 지식 안에서
전체적인 거 다 설명할 수 있게 해 주고, 이게 이해가 안 되면 메일 보내기로 (주소)로 보낼 수 있게 해. 챗봇에 닫기 버튼 혹은
최소화 버튼도 넣어 주고. 전체적으로 오른쪽 바와 왼쪽 글의 위치도 맞춰 주고."*

## ① 말뜻을 설명한다 — `gaeum_glossary.py`

- 챗은 **종목 질문**(사도 돼 · 얼마에 · 왜 막았어 …)만 알았다. *"적정가가 뭐야?"* 는 적정가 **값** 답으로 갔다.
- 설명 사전 항목 **22개**(적정가 · 모델 적용 범위 밖 · 물타기 · 신규 매수 판정 · 비용 차감 기대값과 왜 추천이 없나 ·
  표본외 성적 미달 · 표본 대기 · 유사패턴·유효표본 · rho · 계층 보정 확률 · 원장 · 판정 창 20봉 · 손절/버틸 수 없는 가격 ·
  1차 목표 · 진입가 · 보유 유지/정리 · 국면 · DeMARK · 신뢰도 · 거래 시간·시간외 · 전방 재평가 · 사용법). 설명은
  **이 저장소가 잰 것과 규칙**만 말로 풀었다 — 이 종목의 값은 만들지 않는다(값은 종목 답이 중앙 판정에서 옮긴다 · §4).
- 신호 가르기: **강한 신호**(뭐야·뜻·의미·설명·모르겠…)는 종목 질문보다 먼저 사전을 찾는다(*"물타기가 뭐야?"* 는 보유자
  질문이 아니다). **약한 신호**(알려줘…)는 종목 질문으로 못 알아들었을 때만 — *"진입가 알려줘"* 는 가격 질문이다.
- 검사가 한 번 잡았다: *"적정가 산출 불가는 무슨 뜻이야?"* 가 낱말 차례가 달라 '적정가' 일반 항목으로 갔다 — 표현을 더했다.
- 외부 LLM 은 여전히 없다(§9). 사전에 없는 말이면 못 알아들었다고 하고 메일 길을 안내한다.

## ② 말처럼 시작한다

종목 답이 값 목록으로 시작했다 — 의도별 **말머리 한 줄**(*"결론부터 말씀드릴게요."* · *"갖고 계신 입장에서 보면요."* …)을
붙였다. 값·판정 문장은 그 아래에 그대로다(유도 저항 검사 §317 그대로 통과).

## ③ 메일로 물어보기

창 안에 *"이해가 안 되면 메일로 물어보기"* — 누르면 **사용자의 메일 프로그램**이 받는 사람(사용자가 정한 주소)·제목(종목)·
본문(종목·마지막 질문)이 채워진 새 메일을 연다. **앱은 메일을 보내지 않는다.** 답은 싣지 않는다 — 보유자 답에는 평단이
들어갈 수 있다(§9). 보내기 전에 사용자가 고칠 수 있다.

## ④ 창 닫기 · 최소화

창 머리에 제목 · **최소화(—)** · **닫기(×)**. 최소화하면 머리만 남아 오른쪽 아래에 앉고 입력바가 숨는다 — 머리를 누르면
다시 편다. 닫으면 알약이 돌아온다. 페이지 안 구역일 때는 머리가 안 보인다(절 제목이 이미 있다).
브라우저 실측(1920px 탭): 열림 328px → 최소화 52px · 입력바 숨김 · 머리 누름 → 복원 · 닫기 → 알약 복귀.

## ⑤ 오른쪽 바와 왼쪽 글

실측(1920px): 오른쪽 고정 요약 패널이 x 1650~1898 에 떠 있는데 본문 글이 1870 까지 뻗어 **패널이 본문 오른쪽 약 220px 를
덮었다.** 패널이 보이는 폭(1761px 이상)에서만 본문 오른쪽을 *패널 폭 248 + 오른쪽 여백 22 + 간격 32* 만큼 비운다(패널 규칙의
수 그대로). 고친 뒤 본문 글 오른쪽 끝 1608 < 패널 왼쪽 1650.

## ⚠️ 곁들여 — 돌고 있던 서버가 옛 챗 모듈을 들고 있었다

브라우저로 확인하는데 창에 메일 링크도 인사 말풍선도 없었다. 대화 구역 전체가 `try/except: pass` 안이라 **조용히** 비었고,
원인은 서버가 R324 **전**(어제 21:15)에 떠서 `gaeum_chat` 옛 모듈(새 함수 없음)을 들고 있던 것이었다 — 화면 코드(web_app)는
다시 읽혀도 가져온 모듈은 안 바뀐다(memory: running-server-keeps-old-modules). 서버를 다시 띄우고 확인했다. 즉 **R324 의
인사·감사 답도 로컬 화면에서는 지금까지 옛 모듈로 돌고 있었다**(배포 쪽은 새로 뜨므로 해당 없음).

판정·값·문턱·산식 · 외부 전송 없음 · 메일 자동 발송 없음. 검사 §334(8건).
