# R221 — "진짜 다 물타기 불가야?" — 계산은 맞고, '불가' 한 낱말이 셋을 뭉뚱그렸다 (2026-09-04)

**상태**: 화면 분류 수정 · **문턱·규칙 변화 없음** · 계산 파일 불변(§1).

## 물음

사용자: *"진짜 다 물타기 불가이던데 진짜 맞아? 엔진들 다 체크 해주고."*

R214 가 관심종목 보유 행에 물타기 판정을 붙였는데 16행이 **전부 불가**였다.
전 종목이 같은 답이면 R37(유동성 미수신으로 2,997종목 전부 탈락)처럼 조건
하나가 통째로 막고 있는 것일 수 있다. 세어 봤다.

## 실측 ① — 보유 16행, 조건별 실패 (`_probe/r221_avgdown_audit.py`)

물타기는 `personalize_for_position` 의 **6조건을 전부** 통과해야 한다.

| 조건 | 실패 | |
|---|---:|---|
| **신규 진입 조건 통과** (`eligible_for_top3`) | **16/16** | ← 전부 여기 |
| 거래비용 차감 후 기대수익 양수 | 10/16 | 행마다 다름 |
| 중기 추세 유지 | 4/16 | 행마다 다름 |
| 데이터·표본 게이트 통과 | 4/16 | = PENDING 4행 |
| 손익비(현재가·2차) 기준 통과 | 1/16 | 행마다 다름 |
| 포트폴리오 비중 상한 미초과 | 0/16 | |

행당 실패 조건 수: **1개뿐인 행이 6** · 2개 4 · 3개 4 · 4개 1 · 5개 1.
즉 **6행은 포지션 조건 5개를 전부 통과하고 시장 게이트 하나에만 막혔다.**

## 실측 ② — 그 게이트는 역사적으로 얼마나 열렸나 (`_probe/r221_ledger_baserate.py`)

원장 250,725건의 행동 제목:

| 제목 | 건 | 비율 |
|---|---:|---:|
| 신규 매수 보류 | 132,788 | 53.0% |
| 조건 확인·관망 | 108,800 | 43.4% |
| 비중축소 검토 | 9,080 | 3.6% |
| 제한적 진입 | 52 | 0.0% |
| **분할매수 검토** | **4** | **0.0%** |

구간별 '매수' 제목: train 3 · valid 1 · **blind 0**. 비용 차감 기대수익이 양수인
행은 55.4% 인데 매수 제목은 0.0% — 게이트가 그 위에 있다(R183·R185 의
`OUT_OF_DOMAIN` 차단, R191 비용 통일 등). 오늘 스캔도 *"최종 행동 필수조건
통과: 0개"* 다.

## 답 — 엔진은 맞다. 화면이 덜 말했다

- **계산은 맞다.** 물타기의 첫 조건이 신규 진입 게이트이고, 그 게이트는
  사실상 늘 닫혀 있다(250,725건 중 4건). 신규 매수를 안 내는 엔진이 같은
  종목의 추가 매수만 허락할 수는 없다 — 일관된 답이다. 이것은 §9 의 서
  있는 결론("매수권 신호에 재현되는 우위가 없다")의 직접 귀결이다.
- **그러나 '불가' 한 낱말이 셋을 뭉뚱그렸다.**
  ① 시장 게이트 하나에만 막힘 — 포지션 조건 5개는 통과 (6행)
  ② 포지션 조건 미달 — 기대수익·추세·손익비 (6행)
  ③ 표본·데이터 게이트를 못 넘어 **판단하지 않음** (4행 · PENDING)
  ③을 '불가'라고 적은 것은 §3 위반이다 — *못 잰 것 ≠ 판단*. 그리고 ①을
  ②와 같은 말로 적으면 사용자는 엔진이 틀린 줄 안다(R214 — *"같은 종목이
  두 이름표를 달 때는 그 이유가 같은 줄에 있어야 한다"*).

## 고침 — 판별 함수 하나, 문턱 없음

`ui_kit.avg_down_class(ok, fails)` 가 스냅샷에 찍힌 **실패 목록의 이름**만
읽어 넷으로 가른다: `가능` · `보류`(미판정 · 회색) · `시장게이트`("물타기
불가 · 시장 게이트만") · `포지션미달`("물타기 불가" + 미충족 목록). 값을 다시
계산하지 않고 새 숫자도 없다. 두 조건 이름은 `quant_indicators` 의 리터럴과
같아야 하므로 §238 이 그 리터럴을 잠근다(두 벌 금지 · §4).

## 검사 — §238 (심어서 양방향)

| 심은 것 | 기대 |
|---|---|
| 실패 = [신규 진입] | `시장게이트` |
| 실패에 데이터·표본 게이트 포함 | `보류` |
| 실패에 포지션 조건 포함 | `포지션미달` |
| 통과 / 미측정 | `가능` / `None` |
| 미충족 4개 | 앞 셋 + '외 1' (R214 규칙 유지) |

그리고 구조 — 엔진의 조건이 여전히 6개이고 첫째가 신규 진입 게이트인가(규칙
불변) · 화면이 '불가' 리터럴을 직접 찍지 않고 킷의 라벨을 읽는가 · 미판정은
회색인가 · 관심종목 보유 행 전부가 넷 중 하나로 갈리는가(항등식 · 이름은
안 찍는다 · 파일 없으면 건너뜀).
