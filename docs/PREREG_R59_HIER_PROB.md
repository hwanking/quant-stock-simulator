# 사전등록 — 라운드 59: 계층 혼합 확률 (측정 전 고정)

작성: 2026-08-09. 이 문서 저장 후에 측정한다.

## 0. 배경과 경계

R58 화면 개선으로 계층 실측(L5~L2)을 **이름표와 함께 병기**하게 됐다.
다음 단계 후보는 층들을 섞은 하나의 보정확률(Empirical Bayes /
Beta-Binomial shrinkage)이다. 단, **운영 확률은 게이트 통과 전에 바꾸지
않는다** — 지금 화면의 '산출 불가'(초근접 층)와 계층 병기가 현행이다.

**기각해 둔 접근 (측정 없이 금지):**
- 유사도 문턱을 0.8→0.7→0.6 으로 낮춰 표본 15건을 "강제 확보" —
  측정 후 기준 인하(§2)다. 낮춘 문턱의 표본은 다른 모집단이다
- 동종 업계 표본을 이 종목 확률로 둔갑 (§3) — 계층 이름표 없이 섞는 것
- n=5 의 4/5 를 80%로 출력 — 소표본 점추정 금지

## 1. 후보 산식 (고정)

Beta-Binomial shrinkage, 층 순서 L5 → L4 → L4b/L3 → L2:
  p_k = (k_g + m · p_{k-1}) / (n_g + m)
  (p_{k-1} = 상위층 추정, n_g·k_g = 이 층 표본·성공, m = 사전 강도)

m ∈ {10, 30, 100} 세 후보만 시험한다. m 을 데이터 보고 고르는 것을
막기 위해 **선택은 train 내부(2024-09-01 이후를 내부 검증)** 로만 하고
valid 는 한 번만 본다.

## 2. 평가 (고정)

- 데이터: 개발 구간 판정완료 · 블라인드 미접촉
- 기준선 2종: ① L5 점수대 prior 단독 ② 현행 유사사례 확률
  (표본 기준 충족 시에만 산출되는 값 — 미산출 행은 ①로 폴백)
- 지표: Brier score · log loss · 보정도(10분위 신뢰도 곡선의 최대 이탈)
  · 상위/하위 10분위 실측 적중 차 (변별력)
- valid 1회. 채택 게이트: Brier **와** log loss 둘 다 기준선 ② 대비
  개선 **이고** 보정도 이탈 ≤ 기준선. 하나라도 미달이면 기각·현행 유지

## 3. 채택 시 표시 (미리 고정)

- "약 56% · 신뢰도 낮음" 형식 + **근거 계층·유효 n·신뢰구간 병기**
- 초근접 n 이 기준 미달인 사실은 계속 그대로 적는다
- 전 계층이 비어 있는 종목만 '산출 불가'로 남는다
- versioning.release(axis='model', kind='algorithm') 후 적용
