# 라운드 443 — 외부 검토 15항목을 코드로 가렸다

2026-10-08 · 사용자가 다른 AI 의 검토문(10/7 화면 · P0 7개 · P1 다섯 · UI 제안 넷)을 붙이고 *"계속 진행해줘 못다한 작업 찾아서
해주고"* 라 했다. 지난 검토 라운드(382·386·405~409)와 같은 방식 — **주장마다 코드와 실제 값으로 확인하고, 참인 것 중 값을 안
바꾸는 것만 고쳤다.** 값·문턱·판정이 바뀌는 것은 사람이 정하거나 11-16 뒤의 일로 적었다.

검토문이 든 종목(코드만 · 이름은 적지 않는다)을 같은 날 파이프라인으로 다시 돌려(`_probe/r443_one_stock.py`) 숫자의 출처를 갈랐다.

## 이미 있던 것

- **P0-6 (중앙 판정 11개 vs 스캔 목록 15개)** — 라운드 405·435 가 이미 *"시장 스캔 목록(다른 묶음)"* 으로 갈랐다.
- **P0-7 (전방 기록부 누락 감시)** — 라운드 272(거래일 0건이면 실패) · 275(화면에 기록/전체·빠진 날) · 430(판정일 · 아직 기록 전인 날은
  결손이 아니다)이 이미 한다. 지난 결손은 **다시 만들 수 없다**(라운드 253).
- **12 (계층 확률을 기본값과 못 가림)** — 라운드 401·405 가 카드에 *"기본값과 못 가린다"* 를 이미 같이 적는다.

## 고치지 않은 것 — 사람이 정하거나 나중

- **P0-5 (적정가 위치 점수가 신뢰도 낮으면 0 쪽으로 깎인다)** — 참이다(라운드 409 가 이미 그 사실을 근거 줄에 적었다). 그 점수는 관점
  간 이견에 들어가 매수 결론을 낮출 수 있으므로 **식을 바꾸는 것은 판정 변경**이다 — 11-16 동결 중 · 사람의 결정.
- **두 비용(0.41 · 0.30)** — 같은 유사패턴 평균에 비용이 둘인 것은 사실이다. 0.30 을 0.41 로 맞추면 그 조건의 통과가 바뀌는 **게이트
  변경**이라 이름만 고쳤다.
- **1 · 10 (추천 깔때기 · PROOF 안 산 성적의 날짜별·자본 기준 재집계)** — 연구 거리. 막는 것이 '비용 차감 기대값'이라는 것과 그 거리는
  라운드 316·317·433 이 이미 화면·문서에 있다. 날짜로 묶은 구간을 '안 산 성적'에도 붙이는 것은 다음 라운드.
- **9 ('큰 저평가 가능성 90점')** — 엔진의 위치 구분 낱말이다. 자산 모형만 선 경우는 라운드 359 가 이미 같은 자리에 적는다.
- **UI 제안(이모지 신호등 · 면책 문구 숨기기 · 강제 청산 유도)** — §5(이모지 금지) · §9(한계를 감추지 않는다)와 충돌하고, 매도를 화면이
  재촉하는 것은 판정이 하는 일이 아니다. 받지 않았다.

## 업황 매핑을 지금 고친 까닭

세는 연결 행 수는 이번에 줄어든다(라운드 343 의 29.2% 는 이 고침 전 셈이다).
