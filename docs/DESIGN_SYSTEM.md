**v2 사용자 지정 토큰으로 전면 교체**한다 — hex는 브리프 값 그대로.

## 2. 5색 의미 체계

| 의미 | 토큰 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|
| 브랜드·선택 | `--brand` | 선택 탭·링크·주 버튼·차트 기준선 | 장식·제목 색 |
| 긍정·매수 | `--positive` | 매수 계열 결론·상승·통과 | 일반 강조 |
| 관망·주의 | `--warning` | 관망 결론·지연·경고 게이트 | — |
| 매도·위험 | `--negative` | 매도·손절·차단·오류 | 일반 강조 |
| 일반 정보 | 회색 계열(text/border) | 상태 없는 모든 것 | — |

- **보라는 예측·모델 정보에만** (별도 보조 변수 `--model`로 선언해 사용처를 격리;
  값은 채도 낮춘 보라 1종만 허용).
- 형광(#00f0ff류)·무지개 테두리·과도한 그라데이션 **제거**.
- 색 단독 구분 금지 — 부호(+/−)·아이콘·텍스트 병행.
- 현 코드의 파랑 4종(#64d2ff·#2997ff·#0a84ff·#00f0ff)은 `--brand` 하나로,
  초록 2종·빨강 2종·주황·노랑·연두는 위 4색으로 수렴 (CURRENT_UI_AUDIT §3).

## 3. 타이포그래피

- 한국어 **Pretendard**(또는 SUIT), 영문·숫자 **Inter** + `tabular-nums`.
  로컬 서빙(외부 CDN 의존 금지).

| 위계 | 크기 | 용도 |
|---|---|---|
| 핵심 행동 결론 | **28–32px** | 화면당 1곳 (한 줄 행동) |
| 현재가 | **30–36px** | 종목 분석 헤더 1곳 |
| 페이지 제목 | 24–28px | 화면당 1개 |
| 카드 제목 | **15–17px** | 카드 헤더 |
| 본문 | **15px+** | 설명·근거 |
| 보조 | **13px+** | 기준일·출처·단위 (13px 미만 금지) |

- **모든 숫자를 30px 이상으로 만들지 말 것** — 30px+ 허용은 행동 결론·현재가뿐.
- 같은 수준 정보는 같은 크기·굵기. 한 카드 안 크기 위계 3단 이하.
- 현 코드의 3.4rem 종목명·3rem 점수·1.8rem×4 전광판은 전부 위 표로 축소
  (CURRENT_UI_AUDIT §5의 처분 목록 참조).

## 4. 카드 규칙

- radius **10–12px** · 내부 여백 **20–24px** · 카드 간격 **16–20px** · 그림자 최소.
- **한 카드 한 목적, 동일 정보 반복 금지.**
- 카드 테두리는 **중립 회색(`--border`) 통일** — 컬러 테두리는
  **최종 행동 카드 1곳에만** 허용 (행동의 의미 색).
- 의미 색 배경 틴트는 8–12% 투명 오버레이로만
  (`color-mix(in srgb, var(--positive) 10%, var(--surface))`).
- 모든 데이터 카드에 기준일 스탬프(13px, `--text-secondary`).
- hover: `--surface-hover` 전환 + 1px 상승만. 반짝임·게임화 금지.

## 5. 이모지 → 선형 아이콘 전환 규칙

1. 제목·라벨·expander·버튼의 이모지는 **전부 제거**하고 단일 선형(line) 아이콘
   세트(예: Lucide, 로컬 포함) 16/20/24px로 교체한다.
2. 이모지 허용은 단 한 곳 — **최종 행동 결론**(아주 쉬운 결론의 easy_emoji).
3. 상태 점(🟢🟡🔴 등)은 아이콘+텍스트 칩(● 정상 / ◐ 지연 / ✕ 오류)으로.
4. 본문·캡션의 장식성 이모지(🔥🚀💎 등)는 제거, 의미 전달용(⚠ 경고)은 아이콘으로.
5. 전환 시 test_pipeline_fixes.py의 소스 문자열 검사와 동기화할 것
   (NEW_INFORMATION_ARCHITECTURE §4-A).
6. 감사 시점 잔량: 제목형 72개(39종), 파일 전체 약 358개 — CURRENT_UI_AUDIT §4.

## 6. 점수 표현 위계

| 단계 | 내용 | 표현 |
|---|---|---|
| 1 | 최종 행동 | 결론 카드 28–32px, 의미 색 (가장 크게 — 유일) |
| 2 | 종합점수·신뢰도·유사 사례 실제 성공률 | 큰 숫자(30px 미만) + n 병기 |
| 3 | 추세·모멘텀·거래량·뉴스·위험·전략 품질 | **작은 수평 막대 + 한 줄 설명** |
| 4 | 나머지 산식·기여도 | '상세 근거' 탭 |

- **원형 게이지 최대 1개** (종합점수, 선택적). 나머지는 수평 막대.
- 적중률·확률은 항상 표본 수(n) 병기.

## 7. 레이아웃

- 데스크톱 최대 폭 **1440px**. 종목 분석: **중앙 9열 + 우측 고정 요약 3열**
  (SCREEN_SPECIFICATIONS §3 명세).
- 섹션 사이 32px 이상 — 여백이 구조를 만든다.
- 한 화면에 의미 색 동시 4종 이상 보이면 과다 — 상태 없는 요소는 무채색.
- 모바일: 결론·가격 우선, 하단 고정 메뉴, 표→카드 전환.

## 8. Streamlit 적용 방법

- 토큰은 `st.markdown` 주입 단일 `<style>` 블록의 `:root {}` +
  테마 클래스 전환으로 선언 — 현 산재 인라인 스타일을 이 블록으로 수렴.
  (감사 시점에 v2 토큰 주입 블록이 코드에 착수됨 — web_app.py 168 인근 `_TOK`.)
- st.metric·st.tabs·expander 오버라이드는 CSS 변수 참조로만 하고, 셀렉터
  목록을 본 문서 하단에 유지(버전 업그레이드 파손 대비).
- 커스텀 카드(결론 카드·우측 패널·추천 카드)는 컴포넌트 함수로 작성하고 토큰만
  참조 — 하드코딩 색 금지 (COMPONENT_MAP 참조).
- 마이크로 인터랙션 허용 목록: hover 미세 상승 120ms · 숫자 전환 150ms ·
  탭 fade 120ms · 갱신 스피너 · 오류 배너 1회 slide-in · 포커스 링.
  금지: 반짝임·펄스·축하 효과·카운트업·무한 애니메이션.
