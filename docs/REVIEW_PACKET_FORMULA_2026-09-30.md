### 3.2 신뢰도 수축 (QI:3767-3791 · **직접 확인**)

```python
data_conf  = 100 − (30 if 적정가 못 씀) − (20 if 봉 < 250)
stat_conf  = {FORECAST_AVAILABLE:100, LIMITED:75, LOW_CONFIDENCE:50, OBSERVATION_ONLY:25, INSUFFICIENT:0}[표본 등급]
model_conf = 표본외 검증 품질 점수 (없으면 0)
conf = round(0.50·data_conf + 0.30·stat_conf + 0.20·model_conf)
CA   = 50 + (RQ − 50)·conf/100 ;  RQ < 50 이면 CA = min(RQ + 3, CA, 50)
```
비대칭이다 — RQ 가 50 아래면 올려 주는 폭이 최대 3점, 위면 conf 비율만큼 50 쪽으로 당긴다.

### 3.3 원점수 (QI:3857-3863 · 코드 인용)

```
RAW = 0.45·CA + 0.30·OPP + 0.15·EXE + 0.10·SC
OPP = 0.30·기대수익점수 + 0.20·손익비점수 + 0.20·확률우위(자르지 않음) + 0.15·과거패턴 + 0.10·상승여력 + 0.05·유동성
EXE = 0.35·진입구역 + 0.25·가격위치 + 0.20·유동성 + 0.10·손절구조(사실상 70) + 0.10·상수 60   → 구역 따라 ≤62 / ≤30
```

### 3.4 신호 합의 SC (QI:3284-3325 · 코드 인용)

7쌍(DeMARK 9/13 · TDST · 볼린저 재진입 · W%R · RSI · 거래량 흐름 · SMA60)의 강세·약세 수로
`SC = clip(50 + (강세 − 약세)·10, 0, 100)`. SC 는 RAW 에 0.10, TT 안에서 'DeMARK 결합'으로 한 번 더 들어간다.
⚠️ 신호 하나의 기여는 직접 경로 1.0점 + TT 경로 약 0.28·conf 점 + 간접(이벤트 위험·상한) (유도).
`TAB_WEIGHTS`(탭 가중치 표)는 **어떤 코드도 곱하지 않는다** (코드 인용 · 회귀가 잠근다).

## 4. 적정가 (QI `evaluate_valuation_metric` · 코드 인용, 표시한 곳만 직접 확인)

### 4.1 모형

| 모형 | 값 (정상화 EPS=nEPS) | 유효 조건 | 종류 |
|---|---|---|---|
| PER | nEPS × (12 / 안정형 17.5 / 경기형 8.15) | EPS·PER 수신 · 적자 아님 | 이익 |
| EV/EBITDA | ≈ 10.875·nEPS + 0.45·BPS (경기형 7.25·nEPS+0.35·BPS) | 적자 아님 · 금융 아님 | 이익 |
| FCFF | ≈ 8.755·nEPS | 적자 아님 · 금융 아님 | 이익 |
| EV_GP | ≈ 14.5·nEPS + 2.2·BPS | 적자 아님 | 이익 |
| DCF 시나리오 | ≈ 21.09·nEPS + 1.382·BPS | 적자 아님 | 이익 |
| rNPV | BPS·8.5 + nEPS·15 | 파이프라인 자료 — **늘 없음** | 이익 |
| PBR_ROE | ROE>7 이면 BPS·(1+(ROE−7)/10), 아니면 BPS·max(0.4, PBR) | BPS·ROE>0 | 자산 |
| DDM | ≈ 1.2735·BPS | BPS·ROE>0 | 자산 |
| SOTP | 1.0625·BPS (경기형 1.275) | BPS>0 | 자산 |

- 모든 모형이 **같은 여섯 칸**에서 파생된다(이름이 FCFF·EV/EBITDA 여도 현금흐름·EBITDA 를 받지 않는다).
- 기업 유형 확률(업종 키워드 70% + 재무 특징 30%)로 모형 가중치를 섞는다.
- EPS 가 음수거나 없으면 이익 모형 다섯이 무효(라운드 358·381) → 적자 기업은 **자산 모형만**(ROE 음수면 SOTP 하나).

### 4.2 결합과 최종값

```
유효 모형 3개 이상이면: 가중 없는 중앙값에서 100% 넘게 벗어나면 제외, 50% 넘으면 가중 절반
가중 중앙값 → × 0.98 (근거 없는 고정 보정 · 라운드 251·267 이 재고 '효과 0 근처 · 현행 유지')
상승여력 윈저화 (직접 확인 · QI:2922-2931):
   raw > +45%  → 25 + (raw − 25)^0.45 · 2.5  (최대 48)
   raw < −35%  → −15 − (|raw| − 15)^0.45 · 2.0 (최소 −40)
   그 사이     → raw
→ 모형 출력의 10~90분위 안으로 되돌림 (벗어나면 되돌리고 '중심 잘림' 표시)
```
- 업황 조정은 규칙집이 0 이라 **늘 0**. 신뢰도로 값을 수축하지 **않는다**(신뢰도는 표시 여부만 정한다).
- **상태**: 괴리 < −70% → OUT_OF_DOMAIN(적정가 안 냄) · 신뢰도 ≥70 CALIBRATED · ≥55 CAUTION · ≥45 참고 범위만 · 미만 미산출.

### 4.3 적정가 신뢰도 (QI:2955-2976 · 직접 확인)

```
0.20·데이터완전성(100−16·결측수) + 0.15·유형분류(80/40/≤45) + 0.20·모형수({0:0,1:35,2:60,3:78,4+:90})
+ 0.15·합의도(100 − 평균편차·180 − 중앙·평균괴리·100) + 0.10·안정성(100 − max(0,|raw|−40)·1.2 − 중심잘림 25)
+ 0.10·단위검증 + 0.10·표본외 보정 성능     → 0~95 로 자름
```

### 4.4 권장 매수가

`적정가 × (1 − 안전마진)` · 마진 25%(바이오·적자형) / 20%(플랫폼·턴어라운드) / 12%(안정·금융) / 15%(그 외).
신뢰도 ≥60 · 유효 모형 ≥2 · 모형 편차 ≤0.60 · 결측 ≤2 일 때만 낸다. **지금은 실행 진입가가 아니라 '장기 가치 참고선'이다.**

## 5. 실행 가격 (코드 인용)

`P` = 현재가(기준일 종가), `σ` = 20일 일간수익률 표준편차(연율 아님), `m` = 국면 손절 배수(≤1 · 정상 1.0 · 제한 0.8 · 강한 제한 0.7 · 표본 없음 0.9).

```
손절    = P − P·max(3%·m, 2σ·m)        TDST 지지가 0.5R~1.5R 안이면 그 지지선
1차 목표 = P + max(0.7R, 0.8σP), 구조 저항 이하로       (R = P − 손절)
2차 목표 = [P+1R, P+3R] 안 가장 가까운 저항(TDST·20일 고가·60일 고가), 없으면 P+2R
진입가   = P·(1 − σ)          ← 신규 매수자 값은 이 진입가 기준으로 같은 식을 다시 적용
비중    = 20% ÷ 실현 연변동성 (10~100%) × 국면 배수 × (레버리지·인버스 0.5)
```

| | 신규 매수자 | 보유자 |
|---|---|---|
| 손절 | 진입가 기준 `new_stop` | 현재가 기준 `hold_stop` (선택: 거리 ×0.6) |
| 목표 | 진입가 기준 `new_target` | 현재가 기준 `hold_trim` |
| 고정 | 매 분석 새로 | 보유 계획은 **잰 날에 고정**, 1차 매도가 닿음·20봉 경과에 다시 잼 · 손절선 아래는 사람이 다시 잼 |

**(유도)** 1차 목표 거리가 손절 거리의 0.7배라서, 추세 없는 가격(무작위 보행)에서도 목표가 먼저 닿을 확률이
`1 / (1 + 0.7) = 58.8%` 다.

## 6. 중앙 판정 (VC `build` · 코드 인용, 비용은 직접 확인)

### 6.1 비용 차감 기대값

```python
p   = 점수대 적중률 (calibration.json, 그 점수대 n ≥ 30)
exp_ret = p·(목표/진입 − 1) + (1 − p)·(손절/진입 − 1) − COST_PCT      # COST_PCT = 0.41 (%)
```
0.41 = 수수료 0.03 + 증권거래세 0.20(2026년 세율) + 슬리피지 0.18.

**(유도)** 목표 = 0.7 × 손절거리(d%) 이면 `exp_ret > 0` ⇔ `p > (d + 0.41) / (1.7·d)` — d=3% 면 p>66.9%,
d=10% 면 p>61.2%. 지금 점수대 적중률 58.9~60.4% 로는 **구조적으로 거의 통과할 수 없다.**

### 6.2 추천 11조건 (전부 통과해야 `recommended`)

| # | 이름 | 조건 |
|---|---|---|
| 0 | 권장 매수가 산출 | 진입가 있음 |
| 1 | 진입 깊이 현실적 | \|진입가 괴리\| / σ ≤ 2.1 |
| 2 | 보유기간 안 도달 가능 | #1 과 같은 식 |
| 3 | 목표·손절 산출 | 둘 다 있음 |
| 4 | 손익비 기준 | 진입가 기준 RR ≥ 0.5 |
| 5 | 비용 차감 기대값 양수 | `exp_ret > 0` |
| 6 | 신뢰도·전략품질 | 분석 신뢰도 ≥45 · 전략 품질 ≥40 |
| 7 | 과열·저유동성 아님 | 과열 지표 3개 중 2개 이상 아님 · 20일 거래대금 ≥ 3억 |

미통과 종목은 막힌 조건에 따라 이름을 받는다(데이터 부족 · 과열 해소 대기 · 거래량 회복 대기 · 국면 회복 대기 ·
표본 확보 대기 · 표본외 성적 미달 · 권장가 괴리 과다 · 추천 제외). **손익비·기대값이 잰 값으로 미달이면 기다려도
안 풀리므로 '대기' 이름을 주지 않고 '추천 제외'** 다(진입가·목표·손절이 현재가를 따라 같은 비율로 다시 잡힌다).

개장 전 리포트 94개·후보 433개(2026-09-24 실측)에서 11조건을 **전부 통과한 후보는 0개**이고, 가장 자주 막는
조건은 #5 — 433개 중 432개(99.8%)를 막았다.

### 6.3 국면 게이트 (RP)

국면 = 지수 종가 vs SMA20·SMA60 (강세 둘 · 약세 · 횡보) × 종목 변동성 σ20 ≥3% 여부 = 6칸.
칸마다 원장 적중률의 Wilson 하한(전체와 블라인드 중 작은 값)으로:
≥50 정상 · ≥40 주의(점수 ≤62 · 비중 0.7) · ≥30 제한(≤55 · 비중 0.5 · 손절 0.8) · <30 강한 제한(≤45 · 신규 차단).
2026-09-30 실측: 강세·저변동 칸과 횡보·고변동 칸이 '주의', 나머지 정상, 차단 없음 (코드 인용).

## 7. 확률

### 7.1 유사패턴 (QI `run_self_similarity_backtest` · 코드 인용)

- 지평 5·10·20·40·60·120봉. 최근 H봉을 z-정규화하고 과거 모든 H봉 창과 비교.
- Pearson ρ ≥ 0.80 필수 · H≤40 은 `0.7·ρ + 0.3·DTW유사도 ≥ 0.80` 추가 · 매치끼리 H봉 이상 떨어지게.
- 승률 = 매치 뒤 수익 >0 비율(베타 사전 α5.5·β4.5 사후평균) · 기대수익 = 매치 뒤 평균 수익.
- 표본 등급: <5 미산출 · <10 관찰값만 · 10부터 확률 · ≥30 예측 가능.

### 7.2 계층 보정 확률 (화면 표시 전용 · CLY `blended_prob`)

점수대 → +국면 → +자리(눌림·돌파) → +시장×변동성 → +업종×국면 순서로 베타-이항 축소(m=100).
표는 2026-08-09 판 315칸(개발 구간 적합). 라운드 397 이 오늘 원장(1,187칸)으로 다시 적합해 블라인드
17,663행에서 견줬고 **더 맞지 않았다**(Brier 0.2416 vs 0.2432). 두 판 모두 60점+ 에서 약 6%p 높게 낸다.
