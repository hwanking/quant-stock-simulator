# 공시 분류 세분화 — 라운드 140 (연구 전용)

**'기타' 74.8% → 9.8%. 운영 판정은 하나도 안 바뀌었다.**

라운드 139 가 잰 숫자에서 출발했다 — 운영 분류기가 공시의 대부분을
'기타'로 보낸다. 라운드 124 §3.1 이 *"태깅 정확도를 모른 채 이벤트
통계를 내면 그 통계는 태깅 오류의 통계다"* 라고 경고한 그 자리다.

측정일 **2026-08-20** · 표본 **189,959건** (2025-07-17 ~ 2026-08-20).
근거: `disclosure_types.py` · `.portfolio/disclosures_daily.jsonl`

---

## 1. 결과

| | '기타' |
|---|---:|
| 운영 분류 (`market_attention._classify_disclosure`) | 142,030 (**74.8%**) |
| 연구 분류 (`disclosure_types.classify`) | 18,627 (**9.8%**) |

**65.0%p 줄었다.**

**정기·형식 공시가 90,869건 → 이제 104,049건(54.8%)** 으로 이름이 붙었다.
전체의 **절반 이상이 의무 제출물**이고, 이름이 없으면 '기타'에 섞여
이벤트 통계를 오염시킨다. 이것이 이 라운드의 실제 값어치다 —
**'기타'를 줄인 것이 아니라 제외할 것을 제외할 수 있게 된 것**이다.

## 2. 동결을 어떻게 지켰나 — 이것이 설계의 핵심이다

`_classify_disclosure` 는 관심점수로 흘러가고, 관심점수 **상위 5개만
정밀분석**된다. 즉 분류를 바꾸면 **어떤 종목이 스캔되는지가 바뀐다.**
지금 R55·R57·R66 전방 표본이 2026-08-09 부터 쌓이는 중이라, 후보 풀
구성이 도중에 바뀌면 **그 표본이 오염된다.**

그래서 이렇게 했다:

```python
def classify(title):
    base = _ma._classify_disclosure(title)   # 운영 분류를 먼저 부른다
    if base != '기타':
        return base                          # 8종은 그대로 존중
    return _extended(title)                  # '기타'였던 것만 세분
```

→ **운영 8종에는 두 번째 판단이 존재하지 않는다.** 갈라질 여지가 없다(§4).
→ 실측으로 확인했다: **운영 8종 판정이 바뀐 건 189,959건 중 0건.**

## 3. 작은 표본이 나를 두 번 속였다

**① '기타' 비율 자체가 틀렸다.**

| 표본 | '기타' |
|---|---:|
| 819건 (3일) | 57.8% |
| **189,959건 (268일)** | **74.8%** |

3일치가 우연히 사건성 공시가 많은 날들이었다. **작은 표본으로 낸 58% 는
잘못된 안심이었다.** 이 저장소가 반복해서 겪은 그 함정이다.

**② 가장 흔한 덩어리를 못 봤다.**

3일 표본으로 규칙을 짜고 재니 '기타'가 13.0% 로 줄었다. 그런데 19만
건에서는 **16.7%** 였고, 남은 것의 **38%(12,065건)가 `대규모기업집단
현황공시` 한 줄**이었다. 3일 표본에는 72건뿐이라 눈에 안 띄었다.

그 규칙 하나를 더하니 **16.7% → 9.8%** 가 됐다.

→ **규칙은 작은 표본으로 정하지 않는다.** 가장 흔한 것을 놓친다.

## 5. 남은 '기타' 9.8% 에 **고치면 안 되는 것**이 있다

```
2,203  연결재무제표기준영업(잠정)실적
  740  영업(잠정)실적
```

**실적 공시 2,943건이 '기타'에 빠져 있다.** 운영 분류기의 `'실적'`
키워드에 `영업실적` 은 있는데 실제 제목은 **`영업(잠정)실적`** 이라
괄호 때문에 안 맞는다. 세분화 문제가 아니라 **운영 분류기의 누락**이다.

그런데 지금은 **둘 다 못 한다**:

| 어디서 고치나 | 무슨 일이 나나 |
|---|---|
| 운영 분류기 | 관심점수 변경 → 스캔 종목 변경 → **전방 표본 오염** |
| 연구 분류기 | 8종 중 하나를 두 곳에서 판단 → **§4 위반** |

→ **기록만 하고 2026-11-16 이후로 넘긴다.** 실적은 R124 의 핵심 이벤트
  후보다. 이걸 모르고 이벤트 연구를 열면 **2,943건을 놓친 채** 시작한다.

남은 '기타'의 다른 덩어리(독립이사 선임 1,795 · 주요사항보고서 1,038 ·
투자판단관련 809 · 기업가치제고계획 705 · 전환청구권 680)도 그대로
적어 둔다 — 지금 억지로 채우지 않는다 (§3).
