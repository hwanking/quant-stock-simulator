# 사전등록 R148 — 공시 자체에 알파가 있는가 (순수 이벤트 창 · 7유형 일괄)

**등록일 2026-08-22. 이 문서는 측정 전에 커밋된다 — 커밋 해시가 증거다.**

## 0. 왜 이 질문인가 — R147 과 다른 질문이다

R147 은 *"추천 목록 안에서"* 주주환원 공시가 종목을 가르는가를 물었고
기각됐다. 이 문서는 원장과 무관하게 **공시 발표 직후 종목 수익이 시장을
이기는가**를 묻는다 — R124 §3.2 가 처음부터 적어 둔 순수 이벤트 창이다.

R147 §5 의 약속대로 **유형을 골라잡지 않는다.** 이번 결과를 보고 유형을
고르는 것은 사후선택이므로, 연구 분류기 7유형을 **일괄**로 열고
Bonferroni 로 문턱을 올린다.

## 2. 이벤트 정의 (측정 전에 고정)

- 유형: 연구 분류기(`disclosure_types.classify`) 8종 중 **'기타'·'실적'
  제외 7종** — 자사주·배당 / 수주·공급계약 / 증자·CB·BW / 투자·설비 /
  M&A·분할 / IR·안내 / 인허가·임상. 실적은 R147 §6 과 같은 이유로
  2026-11-16 이후.
- 이벤트 = (종목, D0, 유형). 같은 종목·같은 날·같은 유형의 복수 공시는
  **1건**이다.
- D0 = 접수일. 접수일이 그 종목의 거래일이 아니면 **다음 거래일**이 D0.
- 창: **진입 D+1 시가 → 청산 D+5 종가** (주 시험). 접수 시각이 장중이든
  장후든 D+1 시가 진입이면 미래 정보가 새지 않는다 — D0 종가 진입은
  쓰지 않는다.
- 부 시험(기술 통계만): 청산 D+1 / D+3 / D+10 / D+20 종가.
- 창이 일봉 끝을 넘는 이벤트는 제외한다(마지막 D0 는 수집일 −5 거래일).

## 3. 잣대

이벤트 초과수익(%) = (청산/진입 − 1)×100 − 같은 날짜쌍의 지수 수익(%)
− **비용 0.41%** (저장소 채택값: 수수료 0.03 + 거래세 0.20 + 슬리피지
0.18, `quant_indicators.TOTAL_COST_PCT`). 지수는 무비용 벤치마크다.

**표본 단위는 날짜다** (시장 수준 축은 날짜가 표본 — 같은 날 이벤트는
상관된다). D0 날짜별로 그 유형의 이벤트 초과수익을 평균한 뒤, 날짜별
값의 **부호검정**(0 제외 · 양측)을 한다 — R110·R147 과 같은 잣대 계열.

## 4. 판정 기준 (측정 전에 고정 — 측정 후 내리지 않는다)

| 기준 | 값 |
|---|---|
| 시험 수 | 7 (유형별 주 창 하나씩) |
| 문턱 | Bonferroni 7 · 양측 α=0.05/7 → z=2.690 → **올림 2.70** (R113 규율 ②) |
| 방향 | 양측 — 증자·CB·BW 는 희석이라 음의 방향이 나올 수 있다 |
| 표본 조건 | 유형별 이벤트 **≥ 1,000** 그리고 날짜 **≥ 300** — 함께 건다 (R113 규율 ①). 미달 유형은 "표본 미달"로 적고 판정하지 않는다 |
| 구간 | **원장 분할의 날짜 경계를 재사용** — 개발 = D0 ≤ 2026-01-30 (train+valid), blind = 2026-02-03 ~ 2026-07-15. 개발에서 판정, blind 는 **통과한 유형만** 한 번 |
| 커버리지 | 유형별 (창이 온전한 이벤트 / 기간 안 조인 이벤트) 를 적는다. **70% 미만이면 '부분 표본' 딱지** |
| 미달 시 | 기각, 현행 유지. 창·비용·잣대를 바꿔 재시도하려면 새 사전등록 |

## 5. 검정력을 미리 적는다

부호검정이 z ≥ 2.70 을 내려면 날짜 n 에서 양수 날짜 비율이
**p ≥ 0.5 + 2.70 / (2√n)** 이어야 한다 — n=300 이면 57.8%, n=1,000 이면
54.3%, n=2,000 이면 53.0%. 결과 문서에는 유형별로 이 **필요 승률**과
관측 승률을 나란히 적어 "못 본 크기"를 숫자로 남긴다 (R113 두 문장).

## 6. 이 측정이 하지 않는 것

- 운영 반영 없음 — 점수·게이트·문턱·화면 무변경. 통과한 유형이 있어도
  **표시 전용** 이고, 게이트 반영은 2026-11-16 이후 별도 사전등록.
- 원장 mfe/mae 미사용 (청산 봉 함정). 원장 케이스와 조인하지 않는다.
- 겹침(여러 유형 동시) 미측정 — R124 §4 (개별이 먼저다).
- 업종조정 미측정 — 업종 매핑이 없다. 시장조정만.
- 유형 안의 세부(배당 증액 vs 자사주 소각 등) 미구분 — 제목 태깅의 한계.
