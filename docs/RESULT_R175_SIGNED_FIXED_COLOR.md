# 라운드 175 — 부호가 있는데 색이 고정이었다 (그리고 우리 전략만 초록이었다)

**날짜** 2026-08-25 · **분류** 화면 결함 (§5 · **§9**)

## 1. 라운드 174 의 **반대편**을 안 봤다

174 는 *"두 색 중 고르는"* 줄을 고쳤다 —
`"#35C98B" if 양수 else "#ff453a"` 같은 것들. 그러면서 화면을 다시 보다가
**항상 초록인 `+24.3%`** 가 눈에 걸렸다.

```html
<b style='color:#35C98B;'>{fmt_pct(per_upside['upside_room_pct'])}</b>
```

**부호가 붙는 값에 한 색을 박아 두면 음수일 때도 그 색이 나온다.** 174 가
고친 것의 거울상이고, 174 의 검사로는 안 잡힌다(두 색이 아니라 한 색이라).

전수로 훑으니(`_probe/fixed_color_signed_r175.py`) 다섯 자리였고 그중
**둘이 진짜 결함**이었다.

| 자리 | 값 | 판정 |
|---|---|---|
| `:8538` 상대적 밸류에이션 룸 | 음수 가능 | **결함** — 고평가여도 초록 |
| `:9720` 패턴 조건부 전략 성과 | 음수 가능 | **결함** — 아래 참조 |
| `:5799` 배당금·배당수익률 | 항상 ≥ 0 | 정상 |
| `:8632` 베이지안 사후확률 | `signed=False`, 0~100% | 정상 |
| `:9782` 과거 최대낙폭 | 정의상 손실 | 정상(빨강이 맞다) |

## 2. 두 번째가 §9 다 — **우리 전략만** 색이 있었다

```html
<p>- <b>패턴 조건부 전략 (20일)</b>: <b style='color:#35C98B;'>…</b></p>   ← 초록
<p>- <b>동일 종목 무조건 보유</b>: <b>…</b></p>                            ← 무채색
<p>- <b>20일선 위에서만 보유</b>: <b>…</b></p>                             ← 무채색
<p>- <b>KOSPI200 지수</b>: <b>…</b></p>                                    ← 무채색
```

같은 카드에서 **비교 대상 셋은 무채색인데 우리 전략만 초록**이다. 그리고
그 초록은 **부호와 무관하다** — 전략이 −5% 여도 초록으로 나간다.

§9 — *"성과를 좋게 보이게 쓰지 않는다. 우위가 없으면 없다고 적는다."*
숫자를 바꾼 것은 아니지만 **읽는 사람에게는 우위처럼 보인다.**

→ 넷 다 **같은 잣대**로 칠한다. 전략이 음수면 빨강, 벤치마크가 양수면
초록이다. 비교가 눈으로도 공정해진다.

## 3. 무엇을 넣었나

```python
def _signed_col(v, kind='price'):
    """부호에 따른 색. price=한국 관행(오르면 빨강) · perf=좋다/나쁘다."""
    try:
        x = float(v)
    except (TypeError, ValueError):
        return _TOK['tx2']          # 없는 값을 색으로 판단하지 않는다 (§3)
    if kind == 'perf':
        return _TOK['pos'] if x >= 0 else _TOK['neg']
    return _TOK['up'] if x >= 0 else _TOK['down']
```

- **밸류에이션 룸** → `_signed_col` (가격 방향 — 오를 여지)
- **전략·벤치마크 넷** → `_perf_col` (좋다/나쁘다)
- **값이 없으면 방향색을 안 준다** — `미산출` 에 초록/빨강을 칠하면 없는
  값을 판단한 것이 된다 (§3)

## 4. 회귀 — §209, 그리고 **함수를 실제로 돌려서** 잰다

논리를 검사에 베끼면 아무것도 증명하지 못한다. `web_app.py` 는 스트림릿
스크립트라 import 가 안 되므로, **AST 로 그 두 함수의 원문만 떼어** 스텁
토큰 위에서 실행한다.

| 검사 | |
|---|---|
| 양수 → `up` · 음수 → `down` · 0 → `up` | 한국 관행 |
| 성과는 `pos`/`neg` | 다른 축 |
| `None` · `'미산출'` → 방향색 없음 | §3 |
| **전략과 벤치마크를 같은 잣대로** | **§9** — 넷 다 `_perf_col` 을 쓰는지 이름으로 확인 |
| 부호 있는 값에 고정색이 남지 않았다 | 유도 37개 전체 |
| **심어서 확인** | 고정색을 만들어 넣으면 잡히는가 (§6) |
