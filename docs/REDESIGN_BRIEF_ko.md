# UI/UX 전면 재설계 브리프 (사용자 명세 원문 요약 — 2026-08-01)

> 이 문서는 사용자가 대화로 전달한 재설계 명세를 저장소에 박제한 것이다.
> 설계 문서 7종(docs/UI_UX_BENCHMARK.md 등)은 이 브리프를 기준으로 작성한다.

## 핵심 문장
"Bloomberg처럼 깊고, TradingView처럼 직관적이며, Koyfin처럼 전체 시장을 보여주고,
Finviz처럼 빠르게 비교하되, 최종적으로는 사용자가 지금 무엇을 해야 하는지 가장
쉽게 설명하는 분석 중심 퀀트 플랫폼."

톤: 핫셀블라드(hasselblad.com)처럼 깔끔하고 절제된 프리미엄 — 여백, 정돈, 신뢰감.

## 벤치마크 10개 플랫폼과 가져올 장점
1. **Bloomberg Terminal** — 정보 통합 작업공간, 데이터 기준시각·출처 명시,
   시장→종목 하향 구조, 신뢰감. (조밀함·난해함은 배제)
2. **TradingView** — 차트 중심성·기간/지표 전환 직관성·검색/비교 편의.
   (단, 우리는 퀀트 결론이 먼저, 차트는 검증 수단)
3. **Koyfin** — 시장 전체 대시보드, 정돈된 자산별 표현. → 개장 전 브리핑·오늘의 추천에 반영
4. **IBKR TWS** — 종목 중심 패널 연동. → 제한적 사용자 설정(카드 순서, 탭 고정,
   관심 지표 선택, 간단/전문가 보기, 패널 접기)
5. **thinkorswim** — 다중기간·시나리오·위험 동시 확인. → 다중기간 분석, 상승/중립/하락
   시나리오, 목표·손절 경로, 신규/보유 비교
6. **Webull Desktop** — 현대적 레이아웃, 카드 간격, 반응형 그리드, 다크 완성도
7. **Finviz** — 빠른 비교·스크리너 가독성. → 표 보기+카드 보기 모두 제공 (깨알글씨 금지)
8. **Robinhood Legend** — 큰 숫자·분명한 위계·행동 명확성. (게임화·과도한 애니메이션 금지)
9. **eToro** — 미보유/보유 분리, 평단가 입력, 가상 결과 추적, 케이스 스터디 확인
10. **TrendSpider** — 자동 탐색·게이트·지지/저항 자동 계산·다중기간 합의·전략별 성능

## 우리 앱의 4대 가치 (디자인이 종속되는 기준)
1. 데이터가 정확한가  2. 왜 이런 점수/결론인가
3. 사야/기다려야/보유/팔아야 하는가  4. 과거 독립 사례에서 실제로 얼마나 맞았는가

## 독자 디자인 원칙
- 원칙 1: **결론 먼저** (사도 되는가/기다려라/보유/추가매수/일부·전량 매도/손절)
- 원칙 2: 결론 아래 **가격** (현재가·신규 검토가·1/2차 분할매수가·추격금지가·
  1/2차 목표가·손절가·보유자 대응가)
- 원칙 3: 그다음 **이유** (올린 요인 3·내린 요인 3·차단 게이트·데이터 신뢰도·
  유사 사례 적중률·최대 위험)
- 원칙 4: 상세 계산은 **탭 안으로** (기술지표/뉴스/자기유사/백테스트/케이스 스터디/
  점수 산식/데이터 출처/모델 검증)
- 원칙 5: 정보 5단계 — ①무엇을 해야 ②왜 ③계산·근거 ④과거 적중 ⑤원천 데이터

## 정보구조 (글로벌 메뉴)
홈 / 개장 전 브리핑 / 오늘의 추천 / 종목 분석 / 내 보유종목 / 시장 스캐너 /
케이스 스터디 / 모델 성과 / 설정  (모바일: 하단 메뉴 또는 햄버거)

## 화면별 요약
- **홈**: 지휘센터 — 시장 카드 4~6(KOSPI·KOSDAQ·KOSPI200·USD/KRW·미국지수·변동성,
  각각 값·전일비·기준일·추세·정상 여부), 개장 전 한 줄 결론, 추천 1~5위 카드,
  보유종목 위험 알림, 모델 상태(버전·케이스 수·표본외 적중률·고신뢰 적중률·
  최근 30건·손익비·MDD·데이터 정상률)
- **개장 전 브리핑**: 전일 확정 데이터만, 생성 시각·기준일·모델 버전 박제.
  탭: 시장 요약/주요 뉴스(방향·강도·신뢰도·기반영 표시)/오늘의 전략/추천 후보(표+카드)/
  제외 종목(과열·유동성·뉴스 위험·손익비 부족·데이터 오류·표본 부족·출처 불일치)
- **오늘의 추천**: 히어로("전일 확정 데이터 기준 고신뢰 후보")+기준일·버전·후보/통과 수.
  카드: 순위·종목·점수·신뢰도 등급 / 행동 문구 / 가격(종가·권장매수·추격금지·목표·손절·
  기간·손익비) / 근거(긍정3·위험2·뉴스·유사사례·조건 충족 수) / 액션(상세·관심·가상매매·보유 등록).
  점수 표현: 큰 숫자+수평 막대(원형 게이지 남발 금지), 게이트 체크/경고, 적중률은 표본 수와 함께
- **종목 분석**: 3단 — 헤더(종목·현재가·기준일·정상 여부) / 행동 판단 패널
  (미보유·보유 모드 즉시 전환) / 분석 탭 9개: 핵심 요약·가격 차트·퀀트 점수·뉴스 이벤트·
  매매 시나리오·자기유사 예측·백테스트·케이스 스터디·데이터 감사
- **내 보유종목**: 행동 우선순위 화면 — 상단 요약(평가액·손익·위험 노출·근접 카운트),
  행동별 그룹(즉시 확인/일부 매도/보유/추가매수 가능/금지/손절 근접/데이터 부족)
- **시장 스캐너**: 카드/표/히트맵 보기, 필터(시장·유형·시총·거래대금·점수·추세·모멘텀·
  변동성·뉴스·신뢰도·전략·국면 적합·추천 가능), 결과 열(종목·가격·등락·점수·행동·추세·
  거래량 배수·뉴스·신뢰도·권장매수·목표·손절·손익비)
- **케이스 스터디**: 성과 요약·필터·실패 분석(빈번 원인·최대 손실 원인·최근 증가 유형·
  개선 전후·미해결)·사례 상세(당시 재현·실제 경로·개선 반영 여부)
- **모델 성과**: 감사 화면 — 적중률(전체/표본외/블라인드/고신뢰)·신뢰구간·신호율·손익비·
  비용 차감 기대값 + 경고(표본 부족·장세 편중·성능 저하·신뢰구간 확대·과최적화 위험)

## 디자인 시스템
- 라이트: 회백 배경(#f4f6fa대)·순백 카드·옅은 경계선. 주색 네이비/딥블루,
  긍정 절제 녹색, 경고 앰버, 위험 절제 빨강
- 다크: 짙은 차콜/네이비(순검정 금지), 카드 미세 명도차, 낮은 대비 경계선.
  블루/시안 강조, 민트 긍정, 골드 경고, 코랄 위험. 형광 남발 금지
- 폰트: Pretendard(한) + tabular numbers(숫자). 크기: 페이지 제목 28-32 /
  행동 결론 24-30 / 점수·현재가 26-36 / 섹션 18-22 / 카드 제목 14-16 /
  본문 14-16 / 보조 12-13px
- 카드: radius 10-14px, 매우 약한 그림자, 충분한 여백, 정보 3단계 이하,
  중요 카드만 강조 테두리, 전 카드 채색 금지
- 아이콘: 단일 세트, 이모지 최소화(행동 결론에만), 전문 화면은 선형 아이콘
- 그래프: 양 테마 동일 의미 색, 색맹 친화, 그라데이션/3D 금지

## 점수 카드 위계
1단계 최종 행동(가장 크게) → 2단계 종합점수·신뢰도·표본·적중률 →
3단계 핵심 세부점수(추세·모멘텀·거래량·뉴스·위험·전략 품질, 수평 막대) →
4단계 기타 상세(펼쳐보기). 원형 게이지는 종합점수 한 곳만 선택적.

## 반응형
- 데스크톱: 좌/상단 탐색, 최대 콘텐츠 폭, 우측 보조 패널 선택
- 태블릿: 2열 카드, 탭 가로 스크롤 / 모바일: 결론·가격 우선, 표→카드, 하단 고정 메뉴

## 마이크로 인터랙션 (절제)
hover 미세 상승, 숫자 부드러운 전환, 탭 짧은 fade, 갱신 상태 표시, 오류 배너.
반짝임·게임화·축하 효과 금지.

## 접근성·신뢰성
색상 단독 구분 금지(아이콘+텍스트 병행), 양 테마 대비 확보, 키보드 탐색,
포커스 표시, 데이터 오류 은폐 금지, 예상/확정 구분, 생성 시각·기준일 표시,
불확실성 표시.

## 구현 우선순위 (사용자 지정)
1 현재 구조 파악 → 2 정보구조 → 3 디자인 토큰 → 4 라이트·다크 테마 →
5 글로벌 내비 → 6 홈 → 7 개장 전 브리핑 → 8 오늘의 추천 → 9 종목 분석 →
10 내 보유종목 → 11 시장 스캐너 → 12 케이스 스터디 → 13 모델 성과 →
14 모바일 → 15 접근성 → 16 전체 회귀 테스트

**제약**: 계산 로직 임의 변경 금지. UI에 필요한 필드가 없으면 임의 값을 만들지 말고
데이터 인터페이스를 정의만 한다.

## 완료 기준 (발췌)
5초 안에 행동 결론 이해 / 신규·보유 분리 / 전일 확정 명확 / 산식·게이트 추적 가능 /
케이스 스터디 확인 용이 / 기준일·출처 명확 / 양 테마 완성 / 3디바이스 정상 /
대기업 금융·테크 수준 정돈감 / 복제 아닌 독자 구조.
