# 라운드 501 — 실전 시작을 한 번에: 문장 한 번 + 버튼 하나 · 조건은 하나도 안 뺀다

2026-10-12(월) 밤 · 화면(설정 칸) · 판정·점수·문턱·주문 규칙 불변 · 버전 없음

## 무엇을 보고

사용자: *"선택지를 어렵게 주지 마 · 실제 시작도 3개 누르게 하지 맙시다."* 실전을 켜려면 ① 위험 한도 여섯 ② 실전 잠금 문장 ③ 운용 모드
'실전'을 따로 해야 했고, 설정 화면의 차례도 거꾸로였다(모드 라디오가 위에 있는데 고르면 *"잠금은 아래에서 풀고 다시 고르세요"*).

## 한 것

- **위험 한도** — 숫자는 고르지 않았다(실제 돈의 위험을 정하는 것은 투자 판단이다). 사용자가 붙여 온 안들 중에서 **사용자가 대화에서
  하나를 골랐고**, 그 값을 화면과 같은 형식으로 이 PC 장부에 넣었다(`by='user-chat'` · 바뀐 설정은 `limits` 하나 · 값은 저장소에 적지 않는다 ·
  개인 설정). 첫 거래 1주 제한은 사용자가 고르지 않았다(*"처음부터 한도대로"*) — 만들지 않았다.
- **설정 맨 위 '실전 시작 — 한 번에'** (`swing_view._live_start`) — 문장을 한 번 입력하고 '실전 시작'을 누르면 잠금을 풀고 모드를 '실전'으로
  같이 바꾼다. 누르는 사람은 사용자다. 조건(실전 자격증명 · 위험 한도 여섯 · 긴급정지 꺼짐 · 증권사 관문)은 그대로이고, 아직 안 된 것이
  있으면 그 이름만 적고 켜는 칸을 안 그린다(`live_start_missing` — `live_readiness`·`broker_gate` 를 잠금만 채운 설정으로 부른다 · 새 규칙 없음).
  누르는 순간 장부 설정을 다시 읽어 다시 본다. 실전이면 이 칸을 안 그린다(끄기는 종전대로 모드 '꺼짐' · 긴급정지).

## 그러다 화면이 죽었다 — 화면 자신이 저장하는 모양을 그 화면이 못 그렸다

한도를 넣은 직후 사용자 화면의 설정 칸이 *"ValueError: Unknown format code 'g' for object of type 'str'"* 로 통째로 죽었다. 입력 칸이 저장된
값을 `f'{cur:g}'`(숫자 서식)로 그리는데, **이 화면의 '위험 한도 저장' 자신이 text_input 그대로 글자로 저장한다**(라운드 446 부터). 한도를
한 번이라도 저장하면 다음 그리기에서 죽는 자리였고, 그 전엔 아무도 한도를 저장한 적이 없어 안 보였다. 그리기 검사(§432 ⑲)는 장부를
**숫자로** 심어서 통과했다 — *가짜가 진짜의 모양이 아니면 시험은 초록이다*(라운드 494 의 'STOCK' 과 같은 모양 · 같은 날 두 번째).
`lim_text` 가 글자·숫자를 다 받고(정수는 지수 표기 없이) 못 읽으면 받은 글자 그대로. 마감 뒤라 바로 서버를 다시 띄워 고쳤다.

## 확인

회귀 §480 — 준비 셈 네 갈래(다 됨 · 한도 없음 · 긴급정지 · 모의투자 자격증명) · 버튼은 문장이 같을 때만 · 누르는 순간 다시 읽기 · 잠금 →
모드 차례로 두 번만 적기 · 실전이 아닐 때만 그리기(AST). 설정 화면을 그리는 앞 절들(§432 ⑲ · §437 · §439 · §440)도 그대로 통과. §481 — 화면이 저장하는 모양(글자)으로 한도를 심은 장부로 '시스템' 갈래를 실제로 그려 예외 0 · 입력 칸 '30000' · '실전 시작' 칸.
