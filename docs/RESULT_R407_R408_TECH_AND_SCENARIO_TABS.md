# 라운드 407·408 — '차트와 거래량'·'대응 시나리오' 탭: 계산보다 넓던 낱말, 판정처럼 읽히던 상태

2026-10-01 · model **v2026.10.01.5** (`kind='ui'`) · 값·문턱·판정·산식 **불변**

사용자가 외부 분석 넷을 붙였다(차트와 거래량 탭 둘 · 대응 시나리오 탭 둘). 지시문은 없었고, 이 저장소의
방식대로 **주장마다 코드를 열어** 참·거짓을 가르고, 값을 안 바꾸는 표시·이름 고침만 했다. 분석문이 함께
요구한 것 중 손으로 고른 문턱·이모지·면책 숨기기는 받지 않았다(아래 '받지 않은 것').

## R407 — 차트와 거래량 탭

### 주장별 확인

| 주장 | 코드에서 본 것 | 판정 |
|---|---|---|
| 탭 머리 '비우호적 38'과 같은 화면 '20일선 안착 4/4'가 모순 | 탭 점수는 볼린저 위치·RSI 로 만든 **눌린 정도**(평균회귀 점수)인데 탭 공통 문턱(40/60)에 대 우호/비우호 낱말을 붙였다. 안착은 추세 조건이다 — 다른 것을 잰 둘이 한 낱말로 겨뤘다 | 참 — 낱말을 엔진의 볼린저 위치 구분(`bb_state`)에서, 수의 이름은 **'눌림 지수'** |
| 시장 국면은 점수에 안 들어간다 | 국면은 사유 줄에만 있고 점수 식에 없다 | 참 — 사유가 *"시장 국면 (점수 밖 참고)"* 라 적는다 |
| '안착 성공'은 이후 상승을 약속하는 말로 읽힌다 | `check_20sma_settlement` 는 **테스트만** 부르고 `settlement_report` 는 **web_app 만** 부른다 — 중앙 판정에 영향 없음 | 참 — *"안착 조건 충족 (지금 상태이지 이후 상승을 뜻하지 않습니다)"* · 조건·문턱·`settled` 불변 |
| 수급 절이 비어 있다 | 뜬 입력 30개(라운드 406 의 스냅샷)에서 외국인·기관 칸이 **한 봉이라도 찬 것 0/30** — DeMARK 의 수급 가점도 한 번도 안 붙었다 | 참 — 빈 제목+안내 상자 대신 **캡션 한 줄**(연결되어 있지 않아 그리지 않는다) |
| 결측 대체값이 판정에 닿는다 | 마지막 봉에서 원 계산이 NaN 인 입력 **0/30**(RSI·20일 변동성) — 채움값이 오늘 판정에 닿지 않는다 | 거짓(오늘 입력에서) — 안 고쳤다 |
| '수정종가'라 부르면 안 된다 | 엔진은 가격을 조정하지 않는다(`adj_close` = 원시 종가 · 라운드 364) | 참 — 범례를 *"(종목) 종가"* 로 |
| RSI 방식이 안 적혀 있다 | 평균이 **단순 이동평균**(Wilder 지수평활이 아니다) | 참 — 범례 *"RSI 14 (단순 평균 방식)"* |
| 볼린저 선에 파라미터가 없다 | 20일 · 2σ | 참 — *"볼린저 상·하단 (20일 · 2σ)"* |
| 이 탭이 중앙 판정에 영향을 주는지 안 적혀 있다 | 위 셋(안착·눌림·국면) 모두 중앙 판정 입력이 아니다 | 참 — 캡션이 *"중앙 판정 영향: **없음**"* 으로 시작 |

그리고 흩어져 있던 네 상태(추세·볼린저 위치·RSI·거래량)를 **한 판**에 모았다 — 제목 *"지금 기술 상태 — 네 가지를
따로 봅니다 (판정 아님)"*. 안착 판정은 그 판에서 **한 번만** 부른다.

### 곁들여 본 것

판에 *"거래량 20일 평균의 0.05배"* 가 찍혔다. 장중에 연 화면이라 마지막 봉이 **장중 누적 거래량**일 수 있다 —
**갈라 보지 않았다**(§3 · 추정이다). 값은 엔진의 `volume_ratio` 그대로다.

## R408 — 대응 시나리오 탭

| 주장 | 코드에서 본 것 | 고친 것 |
|---|---|---|
| 조건 줄이 '지금 충족인가'를 안 말한다 | 이동평균 조건은 이름만 있고 현재가가 그 선의 어느 쪽인지 안 적었다 | 같은 줄에 **지금 충족 / 아직 아님** — '이탈' 조건은 아래일 때 충족(뒤집어 읽는다) |
| 거래량 조건을 화면이 다시 계산한다 | 엔진이 이미 `vol_confirmed`(같은 문턱)를 낸다 | 그것을 **읽는다**(새 계산 없음 · §4) |
| 세 가격대가 무엇으로 만든 수인지 모른다 | 현재가 ± 하루 변동성 × 배수 | 칸에 배수를 적는다(값 불변) |
| 가격대 사이가 비어 있다 | 배수가 0.75·1·1.5 로 떨어져 **어느 시나리오에도 안 드는 구간이 둘** | 표 아래 한 줄로 그 두 구간을 적는다 |
| 상승 무효화선과 진입가의 관계 | 상승 무효화선 = **실행 진입가를 잡는 식과 같은 선**(현재가 × (1 − 하루 변동성)) — 진입가까지 내려오면 이 표의 상승 시나리오는 무효 | 같은 줄에 그 사실과 *"무효화선은 손절선이 아닙니다(청산은 중앙 판정의 손절)"* |
| 횡보·하락 조건이 판정되지 않는다 | 횡보의 '거래량 감소'는 기준이 없다 · 하락 시나리오는 거두는 조건이 없다 | 그렇다고 적는다(기준을 만들지 않았다 · §2) |
| '4. 기술적 2차 목표가' 의 기준 | 현재가 기준 · 1R~3R 안 최근접 저항, 없으면 2R | 이름 *"(현재가 기준)"* · 엔진 설명도 식 그대로 |
| '6. ATR / DeMARK 구조적 위험선' | 실제 식은 `현재가 − 손절 거리 × 2` — **ATR 도 DeMARK 도 안 쓴다** | *"6. 변동성 위험선 (손절 거리의 2배)"* · 엔진 설명 *"ATR·DeMARK 를 쓰지 않습니다"* |
| '시장조정 펀더멘털 적정가' | 시장조정 상수는 라운드 44 가 걷었고 이름만 남았다 — **조정 대상이 없는 이름** | '펀더멘털 적정가'(화면 다섯 자리 · 레포트 · 엔진 설명) |

이름이 계산보다 넓은 것은 라운드 237(관점 이름)·239(모형 이름)·359(축 설명)에 이어 또 나왔다 — **'ATR / DeMARK'
는 그 둘을 안 쓰는 식의 이름이었다.**

### 첫 렌더에서 잡은 것

표 아래의 빈 구간 캡션이 범위 둘(`~` 두 개)을 담는데, 첫 렌더에서 마크다운이 두 물결표를 **취소선**으로 묶어
두 범위의 숫자가 붙은 채 나갔다 — 라운드 44·295·337 의 그 사고가 **네 번째**다. 막는 자리(`_md_safe`)를 지나게
했고, §397 이 그 문장을 품은 f-string 이 `_md_safe` 호출 **안**에 있는지를 구조로 본다(글자를 못 박지 않는다).
고친 뒤 렌더: 취소선 0 · 범위 두 개 그대로. 곁들여 *"…원 와"* 조사를 *"…원 구간과 … 구간은"* 으로 고쳤다.

## 받지 않은 것

- **이모지 배지**(§5).
- **면책·경계 문구 숨기기** — 참인 경고는 길다고 빼지 않는다(라운드 226·302).
- **ADX 20 미만 경고 · 새 과열/침체 문턱** — 손으로 고른 수다(§2).
- **RSI 를 Wilder 방식으로 교체** — 값이 바뀌는 계산부 변경이고 전방 평가 동결 중이다. 방식을 **적는 것**까지만 했다.
- **안착 규칙의 기여 제거 실험(ablation)** — 안착은 중앙 판정에 들어가지 않으므로 **이득 상한이 0** 이다(§2-7).
- **수급 시계열 연결** — 수급 기록기는 연구용 소급 수집이다(라운드 284). 화면에 잇는 것은 별도 결정이다.
