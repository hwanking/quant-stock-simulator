# 라운드 449 — 한국투자 계좌 연동: 자격증명은 사용자가 가려진 칸에 직접, 계좌 보유는 앱 보유종목으로

2026-10-08 · 사용자: *"한국투자계좌 연동해줘."* 요청에 앞서 채팅에 앱 키·시크릿·계좌번호 원문이 붙어 있었다.

## 제가 하지 않은 것 — 키를 대신 넣기

실계좌 자격증명을 제가 파일·환경변수·화면 어디에든 넣는 것은 안 한다 — 이 저장소의 규칙(§9 · 자격증명을 저장소에 두지 않는다)이고,
제 운영 규칙(금융 자격증명은 소유자가 직접)이기도 하다. 채팅에 남은 키는 대화 기록에 남으므로 **재발급**을 권했다(이번이 세 번째다).

## 대신 만든 것 — 넣는 길을 앱 안에

1. **연결 정보 입력칸**(스윙 탭 ⑥ 설정) — 계좌 종류(실전·모의투자) · 앱 키 · 앱 시크릿 · 계좌번호(10자리 또는 8-2) 를 **가려진 칸**
   (`type='password'`)으로 받아 `broker_kis.save_config` 가 **저장소 밖** `~/.gaeum/kis.env` 에만 쓴다. 저장소 안 경로는 거부한다.
   값은 돌려주지도 찍지도 않는다 — 화면에는 가린 요약(앞뒤 두세 글자만 남기고 `***`)만. 제출 뒤 입력값을 세션에서 지운다. 환경변수로 이미 넣었으면
   그쪽이 먼저다(파일은 빈 칸만 채운다). '저장된 연결 정보 지우기'로 파일을 지운다. 원격 접속 화면에서는 입력칸이 안 나온다.
2. **연결 확인** — 토큰을 받고 잔고를 한 번 읽는다(주문 없음). 앱을 다시 띄우지 않아도 된다.
3. **계좌 보유 가져오기**(① 계좌) — 한국투자 잔고를 앱의 '내 보유종목'(`.portfolio/positions.json` · 이 PC 에만)으로 옮긴다. CSV 가져오기와
   **같은 함수**(`portfolio.rows_to_positions`)가 먹는다 — 수량 0 은 빼고, 평단이 없는 행은 사유와 함께 제외하고(지어내지 않는다 · §3), 시장
   접미사는 종목코드 반영 버튼과 같은 판별(`resolve_symbol` → 단일 진입점 `market_of`)로 정하며 못 읽으면 시장 미지정으로 넣고 경고한다.
   ⚠️ 첫 판은 web_app 안에서 `.KQ`/`.KS` 접미사를 **직접** 읽어 시장을 정했다 — 라운드 159 가 열두 자리에서 걷어낸 그 모양이고
   회귀 §207 이 *"시장 유도가 소유 모듈 밖으로 새지 않는다"* 로 잡았다(이 라운드 전체 회귀 1건 실패). 단일 진입점으로 고쳤다. 지금 보유종목은 덮이고 **되돌리기**
   한 번이 있다. 관심종목 표의 매입가·수량은 건드리지 않는다.

## 파일 권한 — 첫 판의 결함

첫 판은 저장한 뒤 `icacls` 로 파일 권한을 이 사용자에게만 주려 했다. 이 PC 는 사용자 이름과 컴퓨터 이름이 같아(`HWAN-9800X3D`) 권한
부여 대상이 엉뚱하게 풀렸고, **사용자 자신이 자기 자격증명 파일을 못 읽는** 파일이 됐다(§435 가 `PermissionError` 로 잡았다). 뺐다 —
사용자 프로필 폴더는 Windows 가 이미 그 사용자·관리자에게만 열어 둔다. 자기 자신을 잠그는 장치는 없는 편이 낫다.

## 덤 — '실전으로 바꾸지 않았습니다'에 사유가 없었다

사용자가 *"실전 조건이 다 통과하지 않아 실전으로 바꾸지 않았습니다."* 를 그대로 붙여 왔다 — 경고가 **무엇이** 미달인지 안 적어 무엇을
채워야 하는지 알 수 없었다(라운드 322·298 의 모양 — 상태 낱말은 사유가 아니다). 준비 상태 네 항목(실전 자격증명 · 위험 한도 여섯 · 실전 잠금
해제 · 긴급정지 꺼짐)은 이미 세어져 있었으므로 경고가 미달 항목의 **이름과 채우는 자리**(연결 정보 칸 · 위험 한도 여섯 칸 · 잠금 문장 ·
긴급정지 토글)를 같은 줄에 적는다. 회귀 §435 ⑥ 이 네 항목이 전부 미달인 경우와 하나만 미달인 경우를 심어서 본다.

## 확인

회귀 §435(8건 · 네트워크 0 · 사용자 파일 0): 저장소 안 경로 거부 · 저장소 밖(시스템 임시 폴더)에 쓰고 읽기(10자리 → 8+2 · 요약에 원문
없음 · 임시 파일 안 남음) · 종류·빈 칸 거부 · 지우기 · 잔고 → 보유종목 행(수량 0 제외 · 평단 없음은 같은 함수가 사유와 함께 제외 · 접미사·
수량·평단·출처) · 화면의 가려진 칸 셋과 세션 지우기 · `cfg` 원문을 그리지 않음 · 가져오기·되돌리기 · web_app 이 시장 판별을 넘김 · 실전 전환 거부 경고가 미달 항목 이름과 채우는 자리를 같이 적음.
화면은 임시 장부로 렌더(예외 0 · 입력칸과 가져오기 버튼이 뜬다).

**실제 연결은 아직 안 했다** — 사용자가 키를 넣고 '연결 확인'을 누르는 것이 첫 연결이다. 그 응답이 공식 샘플과 다르면 어댑터가 실패로
멈추고 화면이 사유를 적는다.
