# 결과 R298 — '표본 대기'가 **얼마나 더 있어야 하는지**를 말한다 (2026-09-15)

사용자: *"표본대기가 나오면 개선해줘야지."*

라운드 128 이 이 자리의 **사유**를 둘로 갈랐고, 라운드 292 가 그중 *"기다려도 안 풀리는"*
쪽의 **이름**을 갈랐다('표본외 성적 미달'). 남은 것은 **기다리면 풀리는 쪽의 문장**이다 —
그 문장은 여전히 *"거래일이 쌓이면 다시 봅니다"* 라고만 하고, **얼마나** 는 안 말했다.

## 1. 열어 보니 갈래가 셋이었다

`run_blind_oos_backtest` 가 '검증 못 함'을 내는 자리는 세 곳이고, **사유에 수까지 싣고
있었다**:

| | 엔진 사유 | 뜻 | 기다리면 풀리나 |
|---|---|---|---|
| ⓐ | `봉 수 부족 (n < 490)` | 일봉이 모자라다 | **그렇다 — 셀 수 있다** |
| ⓑ | `표본외 구간이 확보되지 않음` | 봉은 있는데 구간이 안 나뉜다 | 그렇다 |
| ⓒ | `표본외 예측 건수 부족 (N건 < 20건)` | **일봉은 충분하다.** 닮은 구간이 적다 | 늘 수는 있으나 **언제인지는 못 잰다** |

화면은 셋을 한 문장으로 말했다:

> *"일봉이 모자라 학습·검증 구간을 나눌 수 없습니다. 거래일이 쌓이면 다시 봅니다."*

**ⓒ 에서 이 문장은 거짓이다** — 일봉은 충분하다(아래 실측은 694봉 · 기준 490봉). 그리고
어느 갈래든 *"얼마나"* 를 안 말했다.

**재료가 없어서가 아니었다.** 엔진은 사유를 내는데 `compute_strategy_quality` 가 `reason`
만 남기고 수를 버렸고, 스냅샷(`four_scores`)은 `blind_test_status = '미수행'` 이라는 **상태
한 낱말**만 실었다. 라운드 289 와 같은 자리다 — *사유는 엔진이 내는데 소비자까지 오지
않는다.*

## 2. 실측 — 어느 갈래가 실제로 나오나 (2026-09-15 · 표본 40종목)

유니버스 2,448종목에서 시총 순으로 고르게 40종목을 뽑아 실제 일봉으로 돌렸다
(전수가 아니다 — 종목당 일봉을 통째로 받아야 한다):

| 갈래 | 종목 수 |
|---|---:|
| 검증 수행(통과) | **39** |
| ⓒ 예측 건수 부족 | **1** (봉 694 · 예측 **19건** < 20건) |
| ⓐ 봉 수 부족 | 0 |
| ⓑ 구간 미확보 | 0 |

ⓐ·ⓑ 가 **0 인 것은 "없다"가 아니라 이 40종목에서 안 나왔다**는 뜻이다(§3 · R113).
그러나 실제로 나온 **한 건이 하필 ⓒ** 다 — 종전 화면이 *"일봉이 모자라"* 라고 거짓을
말했을 바로 그 갈래이고, 기준까지 **1건** 모자란 종목이었다.

## 3. 고침 — 새 문턱 없음 · 엔진의 수를 옮겼을 뿐

- `run_blind_oos_backtest` 의 세 반환에 **갈래와 수를 칸으로** 싣는다
  (`gap_kind` · `bars` · `bars_need` · `preds` · `preds_need`). 문장을 되파싱하지 않는다 —
  되파싱하면 문장을 고칠 때마다 화면이 낡는다(§4).
- `compute_strategy_quality` 가 그 칸을 **버리지 않고** 옮기고, 스냅샷이
  `blind_test_gap` 으로 싣는다(검증을 마쳤으면 `None`).
- 문장은 `verdict_core.oos_wait_line` **한 곳**이 만든다:
  - ⓐ — *"일봉이 300봉으로 검증에 필요한 490봉에 못 미칩니다. **190거래일**(약 266일)
    더 쌓이면 검증을 시작합니다."* 봉→달력일 환산은 **이미 채택된**
    `ledger_view.bars_to_days`(20봉 = 28일) 하나를 부른다 — 새 숫자가 아니다(§2-6).
  - ⓑ — *"일봉은 있으나 학습 구간을 떼고 나면 검증 구간이 남지 않습니다."*
  - ⓒ — *"**일봉은 충분합니다.** … 19건뿐이라 기준 20건에 못 미칩니다. 거래일이 쌓이면
    늘 수 있지만 **얼마나 걸릴지는 못 잽니다** — 닮은 구간이 나오는 빈도에 달렸습니다."*
  - 사유를 못 받으면 *"사유를 받지 못했습니다"* — 옛 문장을 기본값으로 쓰지 않는다(§3).
- 덤 — '판정 근거 상세'의 `- Blind Test: 미수행` 줄에도 사유를 같이 적는다. **상태는
  사유가 아니다**(§3 · R274 가 센 그 모양).

**칸 이름·문턱·게이트·판정은 하나도 안 바꿨다.** 성적 미달 쪽 문장도 한 글자도 안
건드렸다. 회귀 §310 이 세 갈래가 서로 다른 말을 하는지, ⓒ 가 *"일봉이 모자라"* 를 말하지
않는지, 사유 미수신에 지어내지 않는지를 **값으로** 본다.

## 4. 규칙으로 남기는 것

- **"기다리세요"라고 적을 거면 얼마나인지도 적는다.** 못 세면 *못 센다고* 적는다 —
  기한 없는 기다림은 라운드 47 이 걷어낸 '장기 관찰'과 같은 자리다.
- **상태 낱말('미수행')은 사유가 아니다.** 사유를 내는 쪽이 이미 있는데 소비자가 못
  받고 있는 경우가 이 저장소에서 반복된다(R240·R241·R289·R298) — 고침은 늘 같다:
  **버리지 말고 옮긴다.**
- **한 문장이 갈래 여럿을 덮으면, 그중 하나에서는 대개 거짓이다.** R221('불가') ·
  R236('미충족') · R128 과 같은 계열이고, 이번에는 **실측에서 나온 한 건이 하필 그
  거짓 갈래**였다.
