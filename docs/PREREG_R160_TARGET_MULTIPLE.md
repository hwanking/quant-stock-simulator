# 사전등록 R160 — 목표를 손절보다 멀리 두면 성과가 나아지는가

**등록일 2026-08-23. 이 문서는 측정 전에 커밋된다 — 커밋 해시가 증거다.**

## 0. 왜 이 질문인가

R159 전수 조사가 구조 문제를 하나 짚었다.

> 목표/손절 비 **0.70 : 1** · 손절폭 중앙 4.90%
> → **본전 적중률 63.7%** 인데 실전(blind) 적중률은 **50.4%**.
> 1을 걸고 0.7을 먹는 구조라 **진입이 완벽히 중립이어도 구조만으로 진다.**

그러면 **목표를 손절보다 멀리 두면 어떻게 되나.** 이기는 횟수는 줄지만
이길 때 더 먹는다. 어느 쪽이 큰지는 **재 봐야 안다.**

**질문**: 목표를 손절폭의 M배(M = 1.0 / 1.5 / 2.0 / 3.0)로 두면
**비용후 기대값**이 현행보다 나아지는가.

## 1. 이 저장소가 이미 겪은 함정 — 그리고 왜 지금은 열려 있나

원장의 `mfe_pct`/`mae_pct` 는 **청산 봉까지만** 잰 값이라 *"목표를
넓히면 어땠을까"* 를 원리적으로 물을 수 없었다(오래 열려 있던 이슈).

**R85 가 그것을 닫았다** — `bar_paths_s*.jsonl` 에 신호 다음 봉부터
**21봉**의 고·저·종·시가가 **청산 여부와 무관하게** 들어 있고, 표본
60,000건이 100% 21봉을 갖고 있음을 실측했다.
경로 열: `[날짜, 고가%, 저가%, 종가%, 거래량배율, 시가%]`.

**그래서 이 라운드는 원장 mfe/mae 를 쓰지 않는다.** 경로를 다시 밟는다.

R85 는 *"목표 배수를 여기서 고르지 않는다"* 고 적었다 — 고르는 것은
이 사전등록이 하는 일이고, **고른 뒤 재는 것이 아니라 재기 전에
고정한다.**

## 2. 재시뮬레이션 규칙 — `prediction_log.grade_prediction` 과 같게

한 글자도 바꾸지 않는다:

- 신호 다음 봉부터 `horizon_days`(기본 20) 봉까지 훑는다
- **손절 먼저**: `저가 ≤ 손절` 이면 STOP — 같은 봉에서 둘 다 닿아도
  **보수적으로 손절**로 본다(유리하게 가정하면 성적이 부풀려진다)
- 아니고 `고가 ≥ 목표` 면 TARGET
- 수익: TARGET 이면 목표가, STOP 이면 손절가, 아니면 **마지막 종가**
- 비용 **0.41%** 차감 (채택값 `TOTAL_COST_PCT`)

**손절은 건드리지 않는다.** 목표만 민다:

    위험 = (진입 − 손절) / 진입
    목표(M) = 진입 × (1 + M × 위험)

손절이 진입 이상인 케이스(위험 ≤ 0)는 **제외**하고 그 수를 적는다.

## 3. 시험 (측정 전에 고정)

대상 = 매수권(**58점+**, R49 채택값) · 경로가 온전한 케이스.

| # | M | 뜻 |
|---|---|---|
| T1 | **1.0** | 목표 = 손절폭 (1 : 1) |
| T2 | **1.5** | |
| T3 | **2.0** | |
| T4 | **3.0** | |

**잣대는 비용후 기대값이다 — 적중률이 아니다.** 목표를 밀면 적중률은
당연히 떨어지므로 적중률로 판단하면 반드시 틀린다. 적중률은 함께
적되 **판정에 쓰지 않는다.**

날짜 D 마다
`ΔEV(M, D) = 평균(비용후 수익 | M) − 평균(비용후 수익 | 현행 목표)`
를 **같은 케이스 집합**에서 구하고, **ΔEV 의 부호검정**(0 제외 · 양측)
을 한다 — R110 이래 써 온 잣대 계열이다.

## 4. 판정 기준 (측정 전에 고정 — 측정 후 내리지 않는다)

| 기준 | 값 |
|---|---|
| 시험 수 | 4 |
| 문턱 | Bonferroni 4 · 양측 α=0.05/4 → z=2.498 → **올림 2.50** |
| 표본 조건 | M 별 케이스 **≥ 1,000** 그리고 날짜 **≥ 300** (채택값) |
| 구간 | 개발 = train+valid 에서 판정 · blind 는 **통과한 M 만** 한 번 |
| 미달 시 | 기각하고 현행 유지. M 목록·잣대를 바꿔 재시도하려면 새 사전등록 |

**해석을 미리 적는다.**

| 결과 | 뜻 |
|---|---|
| 어떤 M 이 양으로 유의 | 목표를 멀리 두는 것이 **낫다** — 다만 채택은 아니다(§6) |
| 전부 미달 | 목표 배수로는 못 고친다. R159 의 구조 문제는 **다른 곳**에 있다 |
| 음으로 유의 | 목표를 멀리 두면 **더 나쁘다** — 현행이 그중 낫다는 뜻 |

**어떤 결과든 이 라운드에서 운영을 바꾸지 않는다**(§6).

## 5. 자기검사 (측정 전에 정한 통과 조건)

**원래 목표·손절 그대로** 재시뮬레이션했을 때 원장의 `outcome`
(TARGET/STOP/OPEN)을 **95% 이상** 재현해야 한다. 못 하면 **측정을
중단한다.**

이 검사는 경로 열 순서·채점 규칙·봉 수를 한꺼번에 지킨다. 재현율은
결과에 **숫자로** 적는다(0건이 '없다'인지 '안 봤다'인지 구분되게).

R149·R150·R153·R156·R158 에서 이 종류의 검사가 **일곱 번** 실제 결함을
잡았다. 허용 문턱은 늘리지 않는다.

## 6. 이 측정이 하지 않는 것

- **운영 반영 없음.** 통과하는 M 이 있어도 이 라운드에서 목표 산식을
  바꾸지 않는다. 실행 레벨 변경은 **2026-11-16 이후** 별도 사전등록
  이다 — R55/R57/R66 전방 동결과 같은 자리다.
- 손절을 건드리지 않는다 · 진입가·지평·매수권 문턱을 건드리지 않는다
- 원장 mfe/mae 미사용(§1) · 새 문턱을 만들지 않음(전부 채택값)
- 슬리피지·체결 가능성 재모형화 없음 — 비용은 채택값 0.41% 그대로
