## 왜인가 — 추정이지 측정이 아니다

네 세션 모두 **첫 셸 명령**에서 멈춘다. 무인 실행에는 승인할 사람이 없으므로 권한 확인에서 서는 것으로 추정한다. 세션
메타(`get_session`)는 이 세션이 시작하지 않은 세션의 권한 모드를 **안 내준다** — 그래서 추정이라 적는다(§3). 예약 작업 갱신
도구에는 권한 모드 칸이 없다 — 코드나 지시문으로 고칠 자리가 아니고 **사용자가 앱 쪽에서** 푼다(그 작업의 명령을 승인하거나
무인 권한을 주는 설정).

25시간째 '실행 중'인 세션은 **그대로 두었다** — 다른 세션을 멈추는 것은 사용자 몫이고, 오늘 밤 21:09 의 새 실행과 같은
작업 트리를 쓰지만 둘 다 첫 명령에서 서므로 충돌할 것이 없다.
