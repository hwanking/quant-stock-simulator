# UI/UX 재설계 브리프 v2 — 냉정한 평가와 최종 지시 (2026-08-01)

> 사용자 평가: 종합 완성도 58점. "좋은 분석 자료를 한 페이지에 너무 많이 펼쳐놓아,
> 강점이 오히려 복잡함에 가려진 상태." 이번 작업의 제1원칙은
> **더 예쁘게 만드는 것보다 먼저 덜 보여주는 것**이다.
> 정보 순서: **결론 → 행동 가격 → 이유 → 과거 검증 → 상세 산식**.

## 평가표 (사용자)
분석 깊이 88 / 데이터 투명성 82 / 첫인상 55 / 디자인 일관성 48 /
사용자 친화성 42 / 대기업 서비스 느낌 50 / **종합 58**

## 지적된 문제 8가지
1. 첫 화면에서 무엇을 봐야 하는지 모름 — 개발자용 정보가 사용자 결론보다 먼저 나옴.
   사용자의 첫 질문은 셋뿐: ①오늘 시장이 좋은가 ②지금 살 종목이 있는가
   ③내가 가진 종목을 팔아야 하는가.
2. 모든 것이 크게 강조됨 — 결과적으로 정작 결론이 특별해 보이지 않음.
3. 색상 과다(파랑·청록·녹색·빨강·주황·노랑·보라·분홍) — 게임 대시보드처럼 보임.
4. 이모지 남발 — 제목 위계가 흐려지고 신뢰감 저하. 선형 아이콘으로 통일,
   이모지는 최종 행동 결론에만.
5. 한 페이지가 지나치게 긺 — 유사 정보 반복. 삭제가 아니라 **단계적으로 숨기기**.
6. 탭이 내부 시스템 용어 — 사용자 언어로: 자기유사 예측→과거 비슷한 사례 /
   밸류에이션→현재 가격 위치 / 대응 시나리오→오르면·횡보하면·내리면 /
   DeMARK→추세 소진 신호 / 수급·기술→차트와 거래량 / SR 11-7→모델 신뢰도 /
   교차검증→데이터 검사.
7. 기업 분석(기업 유형·기본 매력도·퀀터멘털·DCF·EV/EBITDA·SOTP·RIM·PER/PBR/ROE
   적정가)이 첫 화면에서 과대 — ETF 공통 흐름과 충돌. 전문가 옵션으로 격리,
   ETF에서는 표시하지 않음. 진짜 강점(케이스 스터디·표본외 적중률·매수 차단·
   신규/보유 행동·뉴스·실패 원인·무결성)이 뒤로 밀림.
8. 숫자가 너무 많은데 "어떤 점수를 믿어야 하지?"가 해소 안 됨.

## 포지셔닝
"차트를 보여주는 플랫폼이 아니라, **지금 무엇을 해야 하는지 과거 사례로 검증해
주는 의사결정 플랫폼**." 강점 4축: ①아주 쉬운 결론 ②사용자별 맞춤 대응
③과거 실제 사례 검증 ④분석의 투명성.

## 전역 메뉴 — 6개로 통합
1. 홈  2. 개장 전 추천  3. 종목 분석  4. 내 보유종목  5. 시장·뉴스  6. 모델 검증
- 종합 결론·차트·퀀트 점수는 종목 분석 내부로. 케이스 스터디는 모델 검증 내부로.

## 종목 분석 내부 탭 — 6개로 제한
1. 요약(결론·가격·핵심 근거·유사 사례)  2. 차트  3. 뉴스
4. 시나리오(오르면·횡보하면·내리면)  5. 과거 검증(자기유사·백테스트·케이스)
6. 상세 근거(점수 산식·모델 정보·데이터 출처·감사)

## 종목 분석 첫 화면 — 스크롤 없이 판단 완료
순서: ①종목명·현재가·기준일·데이터 상태 ②한 줄 행동 결론
③사용자 상태 선택(미보유/보유 중 — 보유 선택 시 평단가·수량 입력)
④신규 또는 보유자 대응 ⑤진입가·목표가·손절가·보유기간
⑥긍정 요인 3 ⑦위험 요인 3 ⑧유사 사례 수·실제 성공률 ⑨신뢰도·가장 큰 한계

한 줄 결론 어휘: 지금 사도 됩니다 / 이 가격 이하에서만 사세요 / 지금은 기다리세요 /
계속 보유하세요 / 일부 매도하세요 / 추가매수하지 마세요 /
종가가 이 가격 아래면 정리하세요 / 데이터가 부족해 판단을 보류합니다

## 점수 위계
1단계 최종 행동(가장 크게) → 2단계 종합점수·신뢰도·유사 사례 실제 성공률 →
3단계 추세·모멘텀·거래량·뉴스·위험·전략 품질(작은 수평 막대+한 줄 설명) →
나머지는 상세 근거 탭. 원형 게이지 최대 1개.

일반 정보=회색. 보라는 예측·모델 정보에만. 형광·무지개 테두리·과도한 그라데이션 제거.

## 홈 화면 순서
①오늘의 시장 한 줄 브리핑(큰 문장 하나) ②개장 전 추천 1~3위(행동 우선 카드)
③내 보유종목 긴급 알림(행동별 건수) ④시장지수 요약(작게 — 배경정보)
⑤모델 상태 요약. 지수·모델 숫자를 첫 화면 최대 요소로 만들지 말 것.

핵심 근거 2·위험 1·유사 사례 적중률(표본 수). 장중 재계산 금지,
생성 시각·기준일·모델 버전 표시.

## 뉴스

## 보유자 화면
평단가·수량 입력 시 즉시 전환. 현재 손익 → 보유/일부/전량/추가매수 가부 →
반등 시 매도가·보유자 손절가·추적손절가. 신규 매수가와 보유자 손절가 혼용 금지.

## 제거·축소 (ETF 공통 흐름)
기업 유형·기본 매력도·퀀터멘털·프로필·DCF·EV/EBITDA·SOTP·RIM·PER/PBR/ROE 적정가는
첫 화면에서 제거 — 전문가 옵션(펼쳐보기)으로 격리, ETF에서는 미표시.
점수 반영 시 자산 유형별 적용 여부·가중치 분리 명시.
