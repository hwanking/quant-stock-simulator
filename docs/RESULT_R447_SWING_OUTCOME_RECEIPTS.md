# 라운드 447 — 스윙 자동매매 결과 영수증: 계획 vs 실제 체결

2026-10-08 · 라운드 446 이 남긴 마지막 고리. 사용자가 붙인 두 번째 검토문도 같은 것을 짚었다 — *"가늠 → 스윙 계획 → 한국투자 주문 →
실제 체결 → PROOF 채점 이 연결이 완성되면 연구가 처음으로 실계좌 실행과 하나의 폐쇄 루프가 된다."* 가늠 PROOF(라운드 418)는 **판정**을
영수증으로 남겼고, 자동매매는 그 판정을 **실행**한다. 실행의 결과를 같은 자리에 같은 규칙으로 적는 것이 이 라운드다.

## 무엇을 적나 — 전부 장부의 사건에서 셈한다 (새 값 없음)

자동매매가 열고 닫은 보유 한 번(OPENED/ADOPTED → … → CLOSED)이 영수증 한 장이다(`swing_proof.receipts` · `SWR-닫은날-코드-해시6`).

| 칸 | 어디서 | 못 셈하면 |
|---|---|---|
| 계획 진입가 · 실제 평균 체결가 · 진입 슬리피지 | 계획(`plans`) · 체결 사건의 수량·가격 가중 평균 | 체결가가 없으면 None + 사유 |
| 청산 사유(목표 · 손절 · 기간 만료 · 밖에서 팔림 · 되돌려 받음) | 매도 사건의 사유 | — |
| 계획 청산가 · 실제 평균 청산가 · 청산 슬리피지 | 목표면 계획 목표 · 손절이면 계획(또는 넘긴 종목의) 손절선 | 기간 만료는 계획 가격이 없다 |
| 총수익률 · 순수익률 | 실제 진입·청산 체결가 · 운영 왕복 비용 `verdict_core.COST_PCT` 하나 | 밖에서 팔려 청산가를 모르면 None |
| 보유 거래일 | 산 날 → 닫은 날의 거래일 수(휴장일 제외) | |
| 같은 계획의 모의 결과 | 기록만 모드와 같은 채점기(`shadow_outcomes`) | 모의가 안 끝났으면 비움 |

요약은 닫히고 순수익이 있는 것만 — 수 · 평균과 중앙(부호가 갈리면 갈린다고) · 사유별 수 · 평균 진입·청산 슬리피지 · 모의와의 차이.
**좋고 나쁨을 말하지 않는다**(문턱이 없다). 30건 미만이면 *"표본이 작아 무엇을 가를 수 있는 수가 아닙니다"* 를 같은 줄에.

## 하지 않는 것

- 실제 수수료·세금을 증권사에서 읽지 않는다 — 비용은 연구·PROOF 와 같은 운영 상수로 뺀다(화면이 그렇다고 적는다).
- `data/` 에 싣지 않는다 — 어느 종목을 몇 주 샀는지는 개인 자료다(§9). 이 PC 의 스윙 탭 ⑤에서만 본다.
- 배당·권리락·거래정지는 다루지 않는다(라운드 446 의 한계 그대로) — 그런 날의 영수증은 수가 어긋날 수 있고 메모에 수량 불일치가 남는다.

## 확인

회귀 §433(7건 · 합성 장부): 나눠 체결한 매수의 가중 평균 · 진입·청산 슬리피지 · 비용 뺀 순수익 · 보유 거래일(한글날 제외 3일) · 모의 결과
옆에 · 넘긴 종목(계획 없음) · 밖에서 팔린 보유(청산가 None + 사유) · 열린 보유 · 요약과 문장 · 빈 장부. 화면은 임시 장부로 렌더(예외 0).
⚠️ 첫 판 시험이 보유 거래일을 4 라 적었다 — 10-09 한글날을 안 뺐다(코드가 맞고 시험이 틀렸다 · R113 의 그 모양).

실제 영수증은 아직 0장이다 — 자동매매가 실제로 열고 닫은 보유가 없다(한국투자 서버에 닿은 적이 없다 · 라운드 446).
