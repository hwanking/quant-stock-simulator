# 결과 R233 — 자기유사 예측 탭: 한 조건에 알림 셋 · '0건'과 '12건'이 한 화면 (2026-09-07)

R229 가 남긴 *"다음은 차트 절과 점수 요인 절 — 같은 방법(세고 묶고 접기)"* 의 자리. 절 지도를
다시 재니(2026-09-07 20:50 · 기본 종목 삼성전자 · 렌더 안정 뒤) 차트 절은 1,070px 로 이미
짧고, 긴 것은 **점수 요인 3,672px** · 판정 3,124 · 관심종목 4,621(R229 뒤 그대로)이었다.

## 1. 무엇이 있었나 — 점수 요인 절의 기본 탭 '자기유사 예측'

- **한 조건에 알림이 셋.** 20일 지평의 표본이 부족하다는 한 조건에 '퀀트 리스크 관리 알림'
  (거래 회피) · '표본 통제' · '예측 확률 미표시' 세 알림이 같은 문장("20일 유효표본 0건 —
  미산출 (유효표본 5건 미만)")을 되풀이했다 — 합쳐 약 300px.
- **'0건'과 '12건'이 한 화면.** 엔진의 `match_count` 는 **20일 지평**의 수다. 화면은 그것을
  '유사패턴 표본 0건'이라 세 번 말한 뒤, 아래 '기간별 경로 분포'는 기본 지평(40일은 0건이라 60일)의 표본
  **12건**으로 그래프를 그리고 선도달 33.3% / 66.7% 를 냈다. 둘 다 맞는 수인데 어느 지평의
  수인지를 화면이 말하지 않아 모순으로 읽혔다(같은 종목에 두 이름표 — 이름표 옆에 이유가
  있어야 한다는 R214 의 그 모양).
- **빈 타일 여섯.** '과거 관찰 성과 세부 분리 지표 (20일)'가 20일 표본 0건일 때 여섯 칸 전부
  '0건 · 산출 불가'를 띄웠다(약 330px).
- **같은 값 두 번.** '기간 간 방향 일치도 67점'이 확률 대시보드와 다중기간 표 아래 타일에
  두 번.
- 7단계 설명 상자(약 230px)는 값이 아니라 설명인데 늘 펼쳐져 있었다.

## 2. 고친 것 (표시 전용 · 값·판정 불변)

- **지평별로 먼저 센다.** `ui_kit.horizon_counts_line(hz)` 가 "5일 195 · 10일 11 · 20일 0 ·
  40일 0 · 60일 12 · 120일 3" 한 줄을 만든다(2026-09-07 삼성전자 실측)(엔진 값의 나열 · 없으면 빈 문자열).
- **게이트는 한 번만 말한다.** 알림 하나: "확률 미표시 — {엔진의 사유}. 확률은 20일 지평의
  유사패턴 표본으로 내며 … 과거 관찰값만 제공합니다 … 지평별 유사패턴 표본: {한 줄}."
  거래 회피 권고는 같은 알림의 마지막 문장으로. 확률이 표시되는데 회피만 권고되는 경우는
  종전 문장 그대로 따로.
- **7단계 설명은 접는다** (`ui_kit.disclose` · 내용 그대로 — ⑦ 표본 통제 줄과 "앙상블은 구현되어
  있지 않습니다"까지).
- **빈 타일 여섯은 한 문장으로.** 20일 표본이 0건이면 "20일 지평은 유사패턴 표본이 0건이라 관찰
  성과를 낼 수 없습니다. 지평별 유사패턴 표본: … — 표본이 있는 지평은 아래 '기간별 경로 분포'
  에서 고를 수 있습니다." 표본이 있으면 타일 그대로.
- **중복 타일 제거.** '기간 간 방향 일치도'는 확률 대시보드 한 곳.

## 4. 덤 — §249·§250 은 전체 회귀에서 한 번도 안 돌았다

이 라운드의 전체 회귀가 §250(7건)을 더했는데도 **4,522건 그대로**였다. 로그에 §250 이 없었고,
찾아보니 요약과 `sys.exit(0)` 블록이 §248 뒤에 있어 **파일 끝에 붙인 §249(R232 · 19건)와
§250 은 그 뒤에 있었다.** 사전 점검(`scripts/preflight.py`)은 절을 마커로 떼어 돌리므로 둘 다
초록불이었다 — 존재는 실행이 아니다(R195). 즉 R232 의 회귀 §249 도 이날 처음으로 전체
회귀에서 돈다.

고침: 요약 블록을 파일 끝으로 옮기고, 그 블록이 **자기 뒤에 절 머리가 있는지 스스로 본다**
(있으면 실패 · "그 절은 안 돌았다" · 본 절 머리 수를 `scanned=` 로 같이 찍는다). 규칙은
CLAUDE.md §6 에 — **새 절을 붙였으면 전체 실행 수가 그만큼 늘었는지 본다.**
