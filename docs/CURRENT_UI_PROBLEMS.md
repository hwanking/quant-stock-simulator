## 대기업 서비스처럼 보이지 않는 이유 3축
1. **정보 우선순위 약함** — 결론보다 세부 데이터가 먼저 눈에 들어옴.
   → 해결 진행: 결론 배너 최상단(79051f7), 지수·metric 26px 제한(b194937),
   홈 순서 브리핑 최우선(661c582). 잔여: 종목 헤더 아래 재무 격자가 여전히
   결론보다 위에 있음(STOCK 격리 필요).
2. **디자인 일관성 약함** — 카드·색·테두리·강조 방식 과다.
   → 해결 진행: 토큰 접합 오버라이드(0e99b2b), 전광판 수평 막대(79051f7).
   잔여: 인라인 색 표기가 아직 다수(예: #86868b 105회 → tx2 토큰 미치환),
   이모지 본문 잔여 ~280개.
3. **운영 제품 느낌 부족** — 업데이트·이슈·전체 보기 UX 부재.
   → 해결: v4에서 주요 이슈·업데이트 패널·고객센터 탑재(998100d).
