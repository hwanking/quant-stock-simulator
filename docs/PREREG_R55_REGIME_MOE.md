# 사전등록 — 라운드 55: 국면 라우팅 (측정 전 고정)

작성: 2026-08-09 (측정 전). 이 문서 저장 후에 측정을 시작한다.

## 0. 원칙

- 가중치를 손으로 정하지 않는다. "추세 30%·뉴스 10%" 같은 사전 배분은
  후보 서술일 뿐이며, **국면별 성적은 전부 원장에서 나온다**
- 기준선 = 현행 엔진(2026-08-09 동결분). 못 이기면 현행 유지
- blind 는 쓰지 않는다 — R54 에서 소진 상태로 선언했다. 확인은
  **전방 축적분**(2026-08-09 이후 신규 케이스)으로만 한다

## 1. 국면 정의 (기존 채택 규칙 재사용 — 새 문턱 없음)

추세 축: 코스피 4상태(trade_plan.market_state — R52 실측 채택)
변동성 축: 코스피 20일 변동성의 개발 구간 중앙값 기준 상/하
  (중앙값 분할은 표본을 반씩 나누는 정의적 분할이다 — 고른 숫자가 아니다)
→ 4 × 2 = 8칸. 60일선 기울기는 4상태 안에 이미 반영돼 있다.

## 2. 전략 프록시 (원장 기록 필드로만 정의)

| 프록시 | 정의 (결정 시점 필드) |
|---|---|
| 눌림(Pullback) | m10_above=True and range_pos ≤ 50 |
| 돌파(Breakout) | range_pos ≥ 80 |
| 평균회귀(MeanRev) | bb_pos ≤ 20 |
| DeMARK 매수 | demark_state 가 매수 계열 |
| 과열회피(RSI) | rsi < 70 |

프록시는 서로 배타적이지 않다 — 각각을 조건부 부분집합으로 본다.

## 3. 측정

train 에서 8칸 × 5프록시의 적중·비용후EV·n 을 잰다. 각 칸에서
**순EV 최고 프록시**를 라우팅 후보로 뽑되, 칸 n < 200 이면 라우팅하지
않고 현행 유지로 둔다 (200은 사전 고정 — Wilson 폭 ±7%p 수준).

valid 에서 라우팅 정책 전체를 **한 번** 평가한다:
기준선(현행 매수권 전체) 대비 순EV·적중·PF·커버리지·월신호.

## 4. 채택 게이트 (전부 충족)

1. valid 순EV > 기준선 순EV **이고** 순EV > 0
2. valid 적중 ≥ 기준선 − 1.0%p (적중을 크게 희생한 EV 개선은 채택 안 함)
3. 커버리지 ≥ 30% · 월평균 ≥ 10건
4. PF > 기준선 PF
5. 채택 시에도 **표시 전용 2주 전방 병행** 후 versioning.release

미달이면 기각하고 현행 유지. 문턱을 내리지 않는다.

## 5. 메타 라벨과의 관계 (R54 후속)

R54 기각 모델(logit abstain)은 폐기하지 않고 **Entry Quality Filter
후보**로 이 라운드의 비교군에 넣는다: 국면 라우팅 vs 메타 abstain vs
둘의 결합, 셋을 같은 valid 로 1회씩만 비교한다. 조언 문서의 경고
(국면 전환 시 메타 모델 붕괴)를 반영해 국면 피처 포함/제외 두 벌을
train 안에서만 비교해 한 벌을 고른 뒤 valid 로 간다.
