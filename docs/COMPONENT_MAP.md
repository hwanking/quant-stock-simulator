# 컴포넌트 맵 v2 — 재사용 컴포넌트 명세

기준: docs/REDESIGN_BRIEF_v2_ko.md (2026-08-01)

> 규칙: ① 입력은 파이프라인이 이미 산출한 값만 — 컴포넌트 내부 계산·추정 금지.
> ② 모든 컴포넌트는 로딩·오류·빈 상태를 스스로 처리. ③ 색은 v2 토큰만
> (DESIGN_SYSTEM v2). ④ 각 입력의 **데이터 가용성**을 표기한다:
> **[있음]** = 현 파이프라인 산출물에 존재 / **[정의 필요]** = 인터페이스 정의만
> 남기고 임의 생성 금지.
>
> 구현 위치 제안: `ui_components.py` (신규, UI 계층 — 계산 모듈 임포트 금지).

## 1. 행동 결론 카드 (action_card)

- **목적**: "지금 무엇을 해야 하는가" 한 줄 — 화면에서 유일하게 28–32px이고
  유일하게 컬러 테두리가 허용되는 카드.
- **입력**: action_label(한 줄 어휘 8종) [있음 — build_easy_advice line],
  final_action_score [있음], vetoes[] [있음 — verdict.vetoes],
  deferred 사유 [있음].
- **표시**: 결론 문구 28–32px + 의미 색 테두리·틴트. veto 존재 시 "매수를 막는
  조건 N건" 병기. 이모지는 easy_emoji 1개만 허용.
- **상태**: 빈 — "데이터가 부족해 판단을 보류합니다" (사유 병기).
- **사용 화면**: 종목 분석 요약(②), 개장 전 추천 카드, 홈 추천 카드, 보유 그룹 카드(축약).

## 2. 실행 가격 행 (price_row)

- **목적**: 진입가·목표가·손절가·보유기간을 한 줄로 — 결론 카드 바로 아래(⑤).
- **입력**: recommended_buy_price [있음], target_tech_1st [있음],
  stop_loss_price [있음], holding_period [있음 — optimal_holding_period_str],
  rr(손익비) [있음], holder_levels(보유자 대응가) [있음 — easy_advice holder].
- **표시**: tabular-nums, 미산출은 "산출 불가 (모델 범위 밖/신뢰도 미달)" 그대로.
  미보유/보유 모드에 따라 레벨 세트 전환 — 신규 매수가와 보유자 손절가 혼용 금지.
- **사용 화면**: 종목 분석 요약, 추천 카드, 우측 요약 패널(축약), 차트 오버레이(동일 값).

## 3. 점수 위계 카드 (score_hierarchy_card)

- **목적**: 점수 4단계 위계 (DESIGN_SYSTEM §6).
- **입력**: final_action_score·analysis_confidence [있음],
  calibration_band{hit_rate, n, lo, hi} [있음], sub_scores 6종(추세·모멘텀·
  거래량·뉴스·위험·전략 품질) [있음 — four_scores 분해·verdict.composition],
  산식 상세 [있음 — verdict.composition/cap_applied].
- **표시**: 2단(종합점수+신뢰도+성공률, 30px 미만) → 3단 작은 수평 막대 6개 +
  한 줄 설명 → 4단 '상세 근거' 탭. **원형 게이지 최대 1개.**
- **사용 화면**: 종목 분석 '상세 근거' 탭 상단(3단까지는 요약 축약 가능), 추천 카드(2단).

## 4. 게이트 체크리스트 (gate_checklist)

- **목적**: 상한 게이트·거부권의 통과/발동/비적용 일람 — "왜 깎였나" 단일 뷰.
- **입력**: gates[{name, status, cap_value, reason}] [있음 — verdict.gate_reason·
  vetoes 및 스냅샷 게이트 결과], applied_cap [있음 — cap_applied·raw_weighted_sum].
- **표시**: 통과 ✓(positive) / 상한 ▼(warning) / 거부 ✕(negative) /
  비적용 —(회색, ETF 적정가 게이트 등). 최종 상한을 결정한 게이트를 굵게.
- **사용 화면**: '상세 근거' 탭, 개장 전 추천 제외 그룹, 모델 검증.

## 5. 뉴스 카드 (news_card)

- **목적**: 뉴스 1건 + 점수 반영 여부 명시.
- **입력**: title·press·published_at·related_count·url [있음],
  risk_hit·score_delta [있음 — 낱말 감점],
  direction·strength·horizon·priced_in [**정의 필요** — 현 파이프라인은 낱말
  감점만. "미분석" 고정 표기, 감성 라벨 임의 생성 금지].
- **표시**: 반복·저품질 기사는 related_count로 묶음. 출처·게시시각 필수.
- **사용 화면**: 종목 분석 '뉴스' 탭, 시장·뉴스 메뉴.

## 6. 시나리오 3분할 (scenario_triptych)

- **목적**: 오르면·횡보하면·내리면 세 경로를 같은 크기로.
- **입력**: up/mid/down 레벨·% [있음 — 가격 레벨·tab_scen 산출],
  선도달 확률·관찰 승률 {value, n} [있음 — sim_res tp/sl_first_prob·win/loss].
- **표시**: 3열 동일 폭, 확률은 n 병기, 하락 카드 축소·연회색 처리 금지.
- **사용 화면**: 종목 분석 '시나리오' 탭 (요약 탭에는 넣지 않음 — 한 화면 원칙).

## 7. 신뢰도 수평 막대 (confidence_bar)

- **목적**: 신뢰도·세부 점수·적중률의 통일 표현 (게이지 남발 방지).
- **입력**: {label, value 0–100, available, caption} [있음].
- **표시**: 트랙 회색, 채움 의미 색(구간 규칙은 호출부 전달), 값 라벨 병기.
  available=False → 회색 빗금 + "산출 불가".
- **사용 화면**: 전 화면.

## 8. 데이터 기준일 스탬프 (data_stamp)

- **목적**: 모든 데이터 표면에 "언제·어디서".
- **입력**: as_of·generated_at·sources[]·model_version [있음],
  is_estimate [있음 — 배당락 관례 추정 등].
- **표시**: 13px `--text-secondary` 1줄. 기준일 불명은 "기준일 미상" 명시.
- **사용 화면**: 전 카드·전 표. 개장 전 추천은 박제 강조형.

## 9. 상태 배지 (status_badge)

- **목적**: 정상/지연/오류(+미연동·비적용)를 아이콘+텍스트 칩으로 — 이모지 대체.
- **입력**: {status: ok|stale|error|not_linked|na, detail} [있음 — 교차검증·
  수집 결과 플래그. 단, 카드별 노출 규격은 **정의 필요**].
- **사용 화면**: 홈, 종목 분석 헤더(①), 모델 검증, 보유 카드.

## 10. 종합 차트 패널 (pro_chart_panel)

- **목적**: chart_pro.py + 지표 선택 패널 + 가격선 오버레이 단일 컴포넌트.
- **입력**: ohlcv [있음], indicators_selected[] [있음 — chart_pro 지표 선택 패널
  구현됨], price_levels [있음 — price_row와 동일 값], DeMARK·수급 오버레이
  [있음 — tab_demark·tab_flow 산출물 이동].
- **표시**: 양 테마 동일 의미 색, 그라데이션 금지, 순검정 배경 금지(#000000 →
  `--bg-primary`).
- **사용 화면**: 종목 분석 '차트' 탭, 홈 미니 스파크라인(변형).

## 11. 우측 고정 요약 패널 (side_summary_panel) — v2 신규

- **목적**: 긴 분석을 읽는 동안 핵심 판단이 계속 보이게 — 종목 분석 우측 3열 고정.
- **입력** (전부 [있음] — web_app.py 2662–2693에 1차 구현 확인):
  action_label(verdict.headline), final_score, 현재가(realtime_price),
  진입가·목표가·손절가(four_scores), analysis_confidence,
  calibration_band{hit_rate, n}. 보유 모드 시 내 평단·손익 [있음 — easy_advice].
- **표시**: 행동 1줄(의미 색) + 7행 표(13px, tabular-nums 우측 정렬).
  미산출 "산출 불가" 그대로. 탭 전환·스크롤에도 상시 노출.
- **상태**: 태블릿 이하 — 패널 숨김, 본문 상단 요약 스트립으로 대체.
  (현 구현은 1760px 미만 숨김 — v2 목표는 1440px 레이아웃 내 3열 확보.)
- **사용 화면**: 종목 분석 전용.

## 12. 사용자 상태 선택기 (user_state_selector) — v2 신규

- **목적**: [미보유 | 보유 중] 즉시 전환 — 보유 선택 시 평단가·수량 입력 노출,
  화면 전체가 보유자 기준으로 전환.
- **입력**: 저장된 보유 여부·평단·수량 [있음 — portfolio 저장분 + 사이드바
  임시 입력(user_entry_price·user_quantity)의 이동],
  전환 시 재판정 [있음 — build_easy_advice(user_avg, user_qty) 재호출뿐,
  새 계산 없음].
- **표시**: 세그먼트 토글 + 조건부 입력 2칸. "평단가는 보유 판단에만 사용,
  예측·점수에 미반영" 캡션 유지.
- **상태**: 보유 등록이 이미 있으면 자동으로 '보유 중' 선택 + 저장값 프리필.
- **사용 화면**: 종목 분석 요약(③). 보유종목 카드에서 딥링크 시 보유 모드로 열림.

## 13. 행동별 보유종목 그룹 카드 (holdings_action_group) — v2 신규

- **목적**: 내 보유종목을 행동별 그룹(정리/일부 매도/보유/추가매수 금지/
  데이터 부족)으로 묶어 위험 우선 정렬.
- **입력**: 종목별 보유 판정 [있음 — build_easy_advice holder·portfolio 뷰
  (web_app.py 2163–2200 산출물)], 손익·평단·현재가 [있음],
  그룹 enum 매핑표 [**정의 필요** — 판정 문구→{IMMEDIATE_CHECK, NEAR_STOP,
  PARTIAL_SELL, HOLD, ADD_OK, ADD_FORBIDDEN, DATA_SHORT} UI 상수],
  "손절 근접" 임계 [**정의 필요** — UI 상수, 화면에 임계 명시].
- **표시**: 그룹 제목은 한 줄 결론 어휘, 건수 병기, 접이식. 카드: 종목명·
  손익(부호+색+아이콘)·대응가 1줄·[상세].
- **상태**: 평단 미입력 — "손익 계산 불가"(0 취급 금지). 시세 실패 — 마지막
  성공값+날짜.
- **사용 화면**: 내 보유종목 '보기' 탭, 홈 긴급 알림(건수 집계형).
