# 컴포넌트 맵 — 재사용 컴포넌트 명세

기준: docs/REDESIGN_BRIEF_ko.md (2026-08-01)

> 여러 화면에서 반복되는 UI 조각을 컴포넌트 함수(st.markdown HTML + 토큰 참조)로
> 통일한다. 규칙: ① 입력은 파이프라인이 이미 산출한 값만 받는다 — 컴포넌트
> 내부에서 계산·추정 금지. ② 모든 컴포넌트는 로딩·오류·빈 상태를 스스로
> 처리한다(호출부가 상태 분기를 반복하지 않게). ③ 색은 토큰만 사용.
>
> 구현 위치 제안: `ui_components.py` (신규, UI 계층 — 계산 모듈 임포트 금지,
> 값은 인자로만 받는다).

---

## 1. 행동 결론 배너 (action_banner)

- **목적**: 화면 최상단에서 "지금 무엇을 해야 하는가"를 5초 안에 전달.
- **입력**: {action_label(7단계 판정 문구), final_action_score, mode(신규/보유),
  vetoes[], deferred(판정 보류 여부·사유)}
  — 원천: build_final_verdict / build_easy_advice. UI에서 문구 재작성 금지.
- **표시**: 판정 문구 24–30px + 의미 색 틴트 배경(매수 계열 positive /
  관망 warning / 축소·회피 danger / 보류 neutral) + 아이콘. veto 존재 시
  "⛔ 매수 차단: {사유}"를 배너 안에 병기.
- **상태**: 로딩 — 스켈레톤 바 1줄 / 오류 — "판정을 불러올 수 없음 (사유)" /
  빈 — "산출 불가 — {사유(표본 부족 등)}" (숨기지 않고 이유 표기).
- **사용 화면**: 종목 분석(패널 상단), 오늘의 추천 카드, 내 보유종목 카드(축약형),
  홈 추천 미니 카드(배지형).

## 2. 가격 사다리 (price_ladder)

- **목적**: 결론 바로 아래에서 실행 가격 전체(현재가·신규 검토가·1/2차 분할매수가·
  추격금지가·1/2차 목표가·손절가·보유자 대응가)를 세로 사다리로 배치 —
  현재가 위치를 사다리 위에 마커로 표시.
- **입력**: {current, entry_review, buy1, buy2, no_chase, target1, target2,
  stop, holder_levels{add_ok, partial_sell, full_sell}, rr, horizon_days,
  currency_unit} — 원천: 스냅샷 가격 레벨(SYSTEM_MAP §3). **None은 None대로
  받아 "미산출" 렌더** (기존 fmt_num na="미산출" 관례 유지).
- **표시**: 값은 tabular-nums, 레벨명+아이콘, 현재가 대비 % 병기. 위→아래
  가격 내림차순. 미보유/보유 모드에 따라 노출 레벨 세트 전환.
- **상태**: 로딩 — 사다리 스켈레톤 / 오류 — 사다리 자리에 오류 카드 /
  빈 — 신뢰도 미달로 권장매수가 미산출 시 해당 칸에 "미산출 (신뢰도 미달)".
- **사용 화면**: 종목 분석(행동 판단 패널), 오늘의 추천 카드(축약 5레벨),
  시장 스캐너 행 확장.

## 3. 점수 위계 카드 (score_hierarchy_card)

- **목적**: 점수를 4단계 위계로 표현 (브리프 §점수 카드 위계).
- **입력**: {final_action_score, action_label, confidence, sample_n, hit_rate
  {value, n}, sub_scores[{name, value, available}], details_renderer(4단계 콜백)}
  — 원천: four_scores·build_tab_verdicts·calibration.json.
- **표시**: 1단 행동(배너 재사용) → 2단 종합점수 큰 숫자 + 신뢰도 수평 막대 +
  "n=표본" → 3단 세부점수 수평 막대(추세·모멘텀·거래량·뉴스·위험·전략 품질,
  available=False는 "산출 불가" 회색 막대) → 4단 expander. 원형 게이지는
  종합점수 1곳만 선택적.
- **상태**: 하위 점수 일부 미산출이어도 나머지 렌더(재정규화 사실을 캡션 표기).
- **사용 화면**: 종목 분석(퀀트 점수 탭·핵심 요약), 오늘의 추천 카드(2단까지).

## 4. 게이트 체크리스트 (gate_checklist)

- **목적**: 16개 상한 게이트 + 거부권(veto)의 통과/발동/해당없음을 일람 —
  "점수가 왜 깎였는가"의 단일 뷰.
- **입력**: {gates[{name, status(pass|capped|veto|na), cap_value, reason}],
  applied_cap(실제 발동한 최저 상한)} — 원천: 스냅샷 게이트 결과(SYSTEM_MAP §5).
- **표시**: 통과 ✓(positive) / 상한 발동 ▼+상한값(warning) / 거부권 ⛔(danger) /
  해당없음 —(neutral, 예: ETF의 적정가 게이트 "비적용"). 실제 min()으로 이긴
  게이트를 굵게 + "이 게이트가 최종 점수를 {cap}으로 제한" 문구.
- **상태**: 게이트 결과 부재 시 "게이트 평가 전" (통과로 위장 금지).
- **사용 화면**: 종목 분석(핵심 요약·퀀트 점수 탭), 오늘의 추천 카드(충족 k/전체
  축약), 개장 전 브리핑 제외 탭(발동 게이트 = 제외 사유).

## 5. 뉴스 카드 (news_card)

- **목적**: 종목 뉴스 1건을 출처·시각과 함께 표시하고, 점수 반영 여부를 명시.
- **입력**: {title, press, published_at, related_count, risk_hit(위험 낱말 여부),
  score_delta, url} — 원천: 네이버 종목뉴스 수집 결과 + 뉴스 위험 감점.
- **표시**: 제목·언론사·시각, 위험 낱말 감지 시 "위험 낱말 감지 → −N점" 배지.
  방향(호재/악재)·강도·기반영 칸은 **파이프라인이 낱말 일치만 하므로 "미분석"
  고정** — 감성 라벨을 임의 생성하지 않는다 (SCREEN_SPECIFICATIONS §2 인터페이스
  정의 참조).
- **상태**: 뉴스 0건 — "수집된 뉴스 없음 (기준: 네이버 종목뉴스)" / 수집 실패 —
  오류 표기 (감점 0점과 구분).
- **사용 화면**: 종목 분석(뉴스 이벤트 탭), 개장 전 브리핑(주요 뉴스 탭).

## 6. 시나리오 3분할 (scenario_triptych)

- **목적**: 상승(2차 목표)/중립(기간 만료)/하락(손절) 세 경로를 나란히 —
  기대와 위험을 같은 크기로 보여준다.
- **입력**: {up{level, pct, prob_observed{value, n}}, mid{horizon_days, expected},
  down{level, pct}, rr, cost_adjusted_ev} — 원천: 가격 레벨 + 리플레이 실측
  (이론 선도달확률·관찰 승률은 산출된 값만, 새 확률 계산 금지).
- **표시**: 3열 동일 폭 카드, 확률은 항상 n 병기, 하락 카드를 축소·연회색
  처리하지 않는다(위험 축소 금지).
- **상태**: 확률 표본 부족 시 해당 칸 "표본 부족 (n={n})".
- **사용 화면**: 종목 분석(매매 시나리오 탭·핵심 요약 축약형).

## 7. 신뢰도 수평 막대 (confidence_bar)

- **목적**: 신뢰도·세부 점수·적중률을 통일된 수평 막대로 (원형 게이지 남발 방지).
- **입력**: {label, value(0~100), threshold_marks[], available, caption}
- **표시**: 트랙 `--bg-inset`, 채움은 값 구간별 의미 색(구간 규칙은 호출부가
  명시 전달 — 컴포넌트가 임의 판정하지 않음), 값 라벨 숫자 병기(색 단독 금지),
  기준선 마크(예: veto 50선) 표시 가능. available=False면 회색 빗금 + "산출 불가".
- **상태**: 값 None — "미산출" 텍스트만.
- **사용 화면**: 전 화면 (점수 위계 카드 내부, 추천 카드, 모델 성과).

## 8. 데이터 기준일 스탬프 (data_stamp)

- **목적**: 모든 데이터 표면에 "언제·어디서" 명시 — Bloomberg식 출처 문화.
- **입력**: {as_of(기준일), generated_at(생성 시각, 선택), sources[], is_estimate
  (예상/확정 구분), model_version(선택)}
- **표시**: 12–13px `--text-3` 1줄: "기준 2026-07-31 종가 · 네이버(교차: 다음) ·
  v{버전}". is_estimate=True면 "추정" 배지 병기(예: 배당락일 관례 추정).
- **상태**: 기준일 불명이면 "기준일 미상" 명시 (생략 금지 — 생략은 은폐다).
- **사용 화면**: 전 카드·전 표 공통 (개장 전 브리핑은 박제 스탬프 강조형).

## 9. 상태 배지 (status_badge)

- **목적**: 데이터·판정의 상태를 3값으로 즉시 전달: 정상 / 지연 / 오류
  (+ 보조: 미연동·산출 불가·비적용).
- **입력**: {status(ok|stale|error|not_linked|na), detail}
- **표시**: 아이콘+텍스트 칩 — ● 정상(positive) / ◐ 지연 N일(warning) /
  ✕ 오류(danger) / − 미연동·비적용(neutral). 색 단독 금지, 텍스트 필수.
- **상태**: 자체가 상태 표시이므로 로딩 상태 없음 (모르면 "확인 중" 아님 —
  "미확인"으로).
- **사용 화면**: 홈 시장 카드, 종목 분석 헤더, 설정(데이터 연동 현황),
  시장 스캐너(행 단위).

## 10. 종합 차트 (chart_pro.py 래핑: pro_chart_panel)

- **목적**: 기존 chart_pro.py 차트에 지표 선택 패널과 가격 레벨 오버레이를 결합한
  단일 차트 컴포넌트.
- **입력**: {ohlcv_df, indicators_selected[](MA5/20/60/120·볼린저·RSI·거래량·
  DeMARK·지지/저항), price_levels(가격 사다리와 동일 입력), period(3M/6M/1Y/전체),
  theme}
- **표시**: 지표 토글 패널(선택 상태는 ui_prefs 저장) + 수평선 오버레이
  (권장매수 accent · 목표 positive · 손절 danger, 라벨 텍스트 병기) +
  기간 세그먼트. 양 테마 동일 의미 색, 그라데이션 금지.
- **상태**: 로딩 — 차트 영역 스켈레톤 / 봉 수 부족 — "표시 가능 봉 n개
  (요청 기간 미달)" 캡션과 함께 가능한 만큼 표시 / OHLCV 실패 — 오류 카드.
- **사용 화면**: 종목 분석(가격 차트 탭), 홈 시장 카드(미니 스파크라인 변형).
