#

# 라운드 42에서 뉴스에 쓴 것과 같은 역할 분리다. 재는 쪽과 쓰는 쪽을

#
#    사전등록(docs/PREREG_R44_SECTOR_OVERLAY.md)의 게이트 0을 두 지표 모두
#    넘지 못했다. 원장 16,805건에 시점 복원으로 업황을 붙여 실측한 결과다.

#      rs60 (프록시 − S&P500 상대강도)
#        G1 lift ≥5.0%p   통과 (+7.6%p)
#        G2 Wilson 비중첩  미달 (호황 하한 47.7% vs 침체 상한 60.8%)
#        G3 방향 일치      미달 (train +5.2 · valid −5.0 · blind +7.6)
#        G4 표본 ≥100      미달 (호황 99 · 침체 78)
#
#      mom60 (프록시 절대 모멘텀)
#        G1 미달 (−14.8%p) — 블라인드에서 **호황 구간이 더 나빴다**
#                            (호황 적중 50.0% EV −2.467)
#
#    valid 에서 방향이 뒤집힌다(G3). 이건 표본 문제가 아니라 신호가
#    일관되지 않다는 뜻이다. "미국 섹터가 좋으면 국내 적정가를 올린다"는
#    가설은 이 원장에서 재현되지 않았다.
#
# 그래서 섹터 엔진은 **표시 전용**으로 출시한다. 화면에는 업황을 보여 주되
